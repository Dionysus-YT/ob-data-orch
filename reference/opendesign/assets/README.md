## 运行时素材

- 产品图标：生产项目继续使用现有 `@lucide/vue`，不从原型复制内联 SVG 图标系统。
- 字体：使用 `DESIGN.md` 中的系统字体栈，不下载或打包外部字体。
- 品牌标记：当前 `OB / ORCH` 为排版式标记，不包含独立 Logo 文件。
- 图表：由真实数据和 SVG/CSS 组件绘制，不使用截图。
