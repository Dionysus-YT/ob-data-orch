# OB Data Orch 前端验收清单

状态：Codex 迁移质量门槛  
P0 必须全部通过；P1 应在当前迭代完成或记录明确原因。

## P0：工程与安全

- [ ] 生产页面由 Vue SFC 和 Vue Router 渲染，不使用原型 HTML/脚本注入。
- [ ] 所有请求复用 `browserApi()`，没有业务页面裸 `fetch`。
- [ ] 未改变后端枚举、权限、revision、幂等和 CSRF 契约。
- [ ] 未暴露密码、令牌、注册码、完整连接凭据或未脱敏命令。
- [ ] 当前工作树已有改动全部保留，没有 reset 或覆盖。
- [ ] `typecheck`、`lint`、`test`、`build` 全部通过。

## P0：全局视觉与交互

- [ ] `operator-signal.css` 是唯一根 Token 入口。
- [ ] 页面只有一个实心主操作；相邻按钮组最多一个主按钮。
- [ ] 主按钮默认、悬停、焦点和禁用状态前景/背景成对定义。
- [ ] 所有可聚焦元素具有清晰 `:focus-visible`。
- [ ] 状态不只依赖颜色，均包含文字标签。
- [ ] 任务、数据源、节点和日志共用 StatusSummary/StatusProgress。
- [ ] 刷新按钮与结果区域同步设置 `aria-busy`。
- [ ] 首次空、筛选空、加载、请求错误和业务失败状态均可到达。
- [ ] 错误在上下文位置提供恢复或重试，不只使用短暂 Toast。

## P0：页面流程

### 运行概览

- [ ] 可从概览进入数据源、导出任务和任务详情。
- [ ] 演示或 Fixture 数据有明确标注，不伪装生产快照。
- [ ] 无权限或无快照时显示真实空态。

### 数据源

- [ ] 搜索、环境、兼容模式、连接状态和启用状态可组合筛选。
- [ ] 可排序列提供正确 `aria-sort`。
- [ ] 新增/编辑抽屉支持连接测试、保存互斥、脏数据确认和焦点返回。
- [ ] 连接字段变化后测试结果立即失效。
- [ ] 禁用和删除/归档具有影响说明，最终结果以后端为准。

### 导出向导

- [ ] 六步顺序固定，已完成步骤可回退，未来步骤不可跳转。
- [ ] 字段修改使预检查失效。
- [ ] MySQL/Oracle 敏感参数在显示、残留值、校验和命令四层一致。
- [ ] 第五步执行节点、输出目录和日志目录布局与门禁事实一致。
- [ ] 目录非空策略是明确选择，并正确映射 `--skip-check-dir`。
- [ ] 第六步只有预检查通过且用户确认后才能提交。
- [ ] 命令预览脱敏且使用当前所选数据源与节点。

### 任务中心与详情

- [ ] 任务中心是一级列表入口，详情可返回原筛选上下文。
- [ ] 运行、等待、失败、成功摘要与实际列表计算一致。
- [ ] 失败详情呈现原因、影响、建议动作和检查点资格。
- [ ] 取消、派生和检查点继续沿用真实 API，不覆盖原任务。

### 执行节点

- [ ] 列表与独立详情路由分离，不使用长详情常驻侧栏。
- [ ] 管理、Agent、心跳、环境、容量和可调度结论分层表达。
- [ ] 只有全部门禁通过的节点进入新任务候选。
- [ ] 注册、关联、环境检查、启用、维护、禁用、删除/归档逻辑连续。
- [ ] 关联任务、事件和审计均保留节点上下文。

### 日志中心

- [ ] 节点、级别、时间和内容筛选可组合使用。
- [ ] 日志行保留时间、级别、节点、来源和事件。
- [ ] 不提供任意路径读取、Shell 或远程终端。

## P0：响应式

逐一验证：360、390、430、600、768、820、1024、1366、1440、1920px。

- [ ] 页面无横向滚动。
- [ ] 1920px 下内容有效使用宽度，不退回 1360px 窄栏。
- [ ] 920px 以下具有真实移动导航，而非完整侧栏纵向堆叠。
- [ ] 640px 以下任务、数据源、节点和日志改为信息卡，不横向滚表。
- [ ] 抽屉、对话框、菜单和 Toast 不遮挡主要操作。
- [ ] 长 ID、路径、命令和错误信息不溢出或裁切。

## P0：可访问性

- [ ] 页面一个 `h1`，标题层级连续，包含 main/nav/header 等地标。
- [ ] 所有表单字段有持久 label；错误通过 `aria-describedby` 关联。
- [ ] 所有图标按钮具有可访问名称。
- [ ] 对话框支持 Escape、焦点约束和关闭后焦点返回。
- [ ] Tab 顺序符合视觉阅读顺序，没有正值 tabindex。
- [ ] 正文对比至少 4.5:1，控件和焦点指示至少 3:1。
- [ ] 进度条具有名称、最小值、最大值和当前值。
- [ ] `prefers-reduced-motion` 下移除位移、缩放和旋转动画。
