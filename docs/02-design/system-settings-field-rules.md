# 系统设置字段与条件矩阵

> 文档状态：字段与条件规则已确认  
> 模块：平台基础、调度、安全、工具与兼容设置  
> 目标工具版本：OB Loader/Dumper 4.3.5-RELEASE  
> 更新日期：2026-07-18  
> 模块方案依据：[系统设置模块专项评审稿](system-settings-module.md)

## 1. 目的与边界

将系统设置的生效值、来源、编辑、校验、影响、权限和异常落实为可逐项评审的字段规则。本文不定义数据库表、配置中心、密钥系统、调度算法、清理作业、参数元数据发布服务或 API。

## 2. 通用字段状态

| 状态 | 含义 | 页面处理 |
|---|---|---|
| 生效 | 当前平台正在使用且可核对 | 展示值、来源和生效时间 |
| 待修改 | 用户在当前分区修改但尚未保存 | 显示旧值/新值差异和未保存标识 |
| 无效 | 值不满足类型、范围或依赖 | 阻断分区保存并定位字段 |
| 待确认 | 高影响变更已校验但尚未确认 | 展示影响和二次确认入口 |
| 未知 | 当前生效值或依赖无法核对 | 不使用猜测值，阻断相关编辑/保存 |
| 敏感 | 密钥或安全材料 | 不展示原值，只展示状态和不可逆摘要 |

## 10. 已确认字段与条件规则

SS-FR01～SS-FR16 已于 2026-07-18 全部确认。确认的是系统设置分区保存、生效值来源、历史对象、基础默认、保留、调度、安全、工具版本、参数元数据、高影响变更和审计的字段语义；具体数值范围、调度算法、密钥流程和权限实现仍属于后续设计项。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| SS-FR01 | 分区与保存 | 四分区独立编辑并原子保存，单个字段失败时整区不生效 |
| SS-FR02 | 值与来源 | 所有设置展示真实生效值、来源、更新时间和状态，未知时不填充猜测默认值 |
| SS-FR03 | 历史边界 | 设置变化不回写已提交任务、历史命令和快照；新建或重编辑对象使用当前基线 |
| SS-FR04 | 基础默认 | 时区、语言、分页和任务名称规则只影响相应展示/新建校验，不进入工具命令 |
| SS-FR05 | 保留策略 | 任务、普通日志、审计日志独立；降低保留期二次确认，精确清理留待技术设计 |
| SS-FR06 | 单节点并发 | 系统值只作为新节点默认，节点实际值独立保存且不被批量覆盖 |
| SS-FR07 | 平台并发 | 作为硬上限；低于当前运行数时不取消任务，只阻止新增启动 |
| SS-FR08 | 超时 | 心跳超时只派生失联，启动超时触发状态核对，不直接判定任务失败 |
| SS-FR09 | 节点策略 | 只排序或给出可解释推荐，不自动选中、提交或改派节点 |
| SS-FR10 | 脱敏 | 内置脱敏不可关闭，扩展规则未通过安全设计前不作为确定能力 |
| SS-FR11 | 密钥 | 只显示状态和不可逆摘要，页面不接收、展示、复制或下载密钥材料 |

| SS-FR14 | 元数据 | 只激活受控版本；草稿和模板重校验，历史任务保持原快照，不提供绕过策略 |
| SS-FR15 | 高影响变更 | 保存前展示旧值、新值、可靠影响范围并二次确认；数量未知时明确未知 |
| SS-FR16 | 权限与审计 | 编辑限系统设置权限；关键保存、失败、确认和安全/工具变化均审计且不记录敏感值 |

## 11. 字段覆盖验收

1. SS-F001～SS-F080 覆盖四个设置分区、编辑保存、影响比较、权限和异常。
2. 平台设置不会承载三类任务参数、数据源连接或节点环境字段。
3. 新建默认、调度硬约束、安全策略和历史快照具有不同生效边界。
4. 降低保留期、并发或超时以及修改安全/工具基线都有明确影响提示。
5. 密钥和敏感配置不会以明文进入页面、差异或审计摘要。
6. 工具版本和参数元数据变化不会自动安装工具、迁移模板或修改历史任务。
7. 未确认的数值范围、调度算法、扩展脱敏和密钥流程保持待设计状态。
8. V1.0 不引入配置发布、导入导出、环境覆盖、继承、回滚、脚本或审批中心。
