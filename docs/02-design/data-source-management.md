> 文档状态：产品决策已确认，官方参数映射待补齐  
> 模块优先级：P0  
> 依据：[总体 PRD第 6 章](../01-product/PRD.md)

> 评审结论：DS-R01～DS-R11 全部确认（2026-07-17）  
> 视觉与页面架构：遵循 [P0 MASTER](../../design-system/MASTER.md)；本文只维护数据源业务、资格与连接测试事实。
> 更新日期：2026-08-13

> 本文维护数据源产品语义和业务边界；Table、Drawer、响应式与全局视觉规则以 [P0 MASTER](../../design-system/MASTER.md) 为准，不得反向覆盖业务或安全契约。

## 1. 评审目标

确认数据源字段、连接方式、基础连接测试、状态与删除/禁用规则，使其能够作为导出、普通导入和旁路导入向导的稳定公共入口。本稿只定义产品与交互，不定义 API、数据库表或实现方案。

## 2. 模块边界

### 包含

- 数据源列表。
- 新增、查看和编辑数据源。
- 删除或禁用数据源。
- 基础连接信息。
- 测试连接。
- 连接状态和最近测试时间。

### 不包含

- 导入权限检查或导出权限检查。
- 对象级权限诊断和数据库对象扫描。
- 性能、容量或数据库资源诊断。
- 文件、格式、目标对象或任务执行可行性分析。
- 自动授权、自动建表或数据库对象管理。

上述检查属于对应任务的预执行检查，不应回写为“数据源适合导入/导出”等综合结论。

## 3. 数据源列表

### 页面目标

让用户快速找到数据源、了解是否可用，并完成测试、编辑、禁用或删除等管理操作。

### 筛选

- 关键字：名称、地址等可检索字段的最终范围待评审。
- 环境。
- 兼容模式。
- 连接状态。
- 启用状态。
- 创建人。

### 列表字段

| 字段 | 展示规则 |
|---|---|
| 数据源名称 | 用户自定义名称；唯一性规则待确认 |
| 环境 | 开发、测试、预生产、生产等；枚举由系统设置或固定配置提供，待确认 |
| 连接方式 | 私有 ODP（当前切片固定） |
| 地址 | 主机名、IP 或 VIP；敏感场景可脱敏 |
| SQL 端口 | 基础数据库连接端口 |
| 集群 / 租户 | 按连接方式展示适用信息 |
| 兼容模式 | MySQL 或 Oracle |
| 连接状态 | 未测试、可连接、连接失败 |
| 启用状态 | 已启用、已禁用；与连接状态分开表达 |
| 最近测试时间 | 最近一次测试完成时间；从未测试显示“尚未测试” |
| 创建人 | 数据源创建者 |
| 操作 | 查看、测试、编辑、禁用/启用、永久删除或显式归档 |

### 默认排序与状态提示

- 默认排序规则待评审；建议优先确保异常和禁用状态清晰可见，不在本稿锁定排序结论。
- “连接失败”展示最近一次失败类别与时间入口，不在列表展开敏感原始信息。
- “已禁用”不能被任务向导选择，即使最近测试成功。
- 连接状态只代表最近一次基础测试结果，不代表当前实时状态或任务可执行性。

### 空状态

- 无任何数据源：说明数据源会被任务向导复用，并为有权限用户提供“新增数据源”。
- 筛选无结果：保留筛选条件并提供“清除筛选”。
- 无新增权限：不展示误导性的主按钮，说明需联系数据源管理员。

## 4. 新增 / 编辑数据源

### 4.1 F1 ODC 智能解析与结构化编辑覆盖

本节覆盖本模块先前关于连接字段展示和兼容模式回填的 F1 实现口径：

- 数据源类型固定为 **OceanBase MySQL** 或 **OceanBase Oracle**，不把“待校验”作为新建或更新的可保存类型；
- 页面提供智能解析输入框，原始连接串仅保留在当前浏览器页面以便用户修改；控制面、SQLite、审计和响应均不保存或返回原始连接串，保存和测试请求只提交结构化字段；
- OceanBase MySQL 连接串必须以 `mysql` 开头，OceanBase Oracle 连接串必须以 `obclient` 开头；当前切片接受私有 ODP 的 `用户@租户`、`用户@租户#集群` 与服务名形式 `用户@租户:集群` 身份，解析只回填结构化字段且不改写原始连接串；
- 解析并回填主机、端口、可选集群、租户、用户名、密码和 MySQL 默认数据库后，用户仍可结构化编辑这些字段；`-p` 可为空并由用户随后在结构化密码字段补填；
- Oracle 类型不展示或保存默认数据库字段。连接测试、权限、性能和任务可行性边界不因解析能力而改变。

该口径参考 [ODC 公共连接管理](https://www.oceanbase.com/docs/enterprise-odc-doc-cn-10000000000834079) 的智能解析和 OceanBase MySQL/Oracle 模式字段布局；连接串前缀规则由本次产品确认固定。

### 基础信息

| 字段 | 必填 | 规则 |
|---|---:|---|
| 数据源名称 | 是 | 全局唯一或按环境唯一：待确认 |
| 环境 | 是 | 枚举及管理方式待确认 |
| 描述 | 否 | 说明用途和业务范围 |
| 连接方式 | 是 | 私有 ODP（固定，不提供切换） |

### 连接信息

| 字段 | 必填条件 | 规则 |
|---|---|---|
| 主机地址 | 是 | IP、域名或 VIP；支持格式边界待实现前确认 |
| SQL 端口 | 是 | 只接受合法端口值 |
| 集群名 | 否 | ODP 身份可不含集群；填写时参与组合身份，不生成额外命令参数 |
| 租户名 | 是 | OceanBase 租户；当前私有 ODP 切片必须从结构化输入或智能解析获得 |
| 用户名 | 是 | 业务租户用户；连接字符串组合规则待官方参数映射确认 |
| 密码 | 新增时是 | 加密存储；页面不可明文回显 |
| sys 账号 / sys 密码 | 否 | 高级设置可选项（参考 ODC）：成对填写，拥有 sys 租户视图查看权限的账号（如 root，勿填 @sys#集群 后缀）；密码加密信封存储，页面不回显，摘要只派生可用/不可用 |
| 默认数据库 / Schema | 否 | 只供任务向导默认回填，不是基础连接测试必填项 |

### 数据源类型

- 新建先选择 OceanBase MySQL 或 OceanBase Oracle，再进入对应固定模式表单；编辑按已保存类型进入，表单内不切换模式。智能解析只接受当前类型对应的 `mysql` 或 `obclient` 前缀，模式不符时拒绝整次回填并保留草稿（2026-09-10 用户确认）。
- 不以未验证的连接测试结果推断、改写或伪造数据源类型。

### 编辑规则

- 密码字段默认留空；未修改则保留原密码。
- 用户输入新密码后才替换；失败的连接测试不自动回滚其他未保存字段。
- 修改地址、端口、集群、租户、用户名、密码或连接方式后，原测试结果标记为已失效，保存前是否强制重新测试：待评审。
- 编辑不会改变历史任务中的数据源快照。

## 5. 测试连接

### 测试范围

连接测试只验证：

1. 地址和端口是否可连接；
2. 用户名和密码是否能够认证；
3. 基础数据库连接是否成功；
4. 能够直接获得的基础连接信息。

### 触发位置

- 新增 / 编辑表单中的“测试连接”。
- 数据源列表单行“测试”。
- 任务向导数据源摘要中的“重新测试”，但仍调用同一基础测试语义。

### 前置校验

- 地址、SQL 端口、用户名、密码及当前连接方式要求的字段完整且格式合法后才发起。
- 编辑旧数据源时未填写新密码，使用已保存凭据测试；界面不回显密码。

### 进行中

- 按钮显示“测试中”并避免重复请求。
- 不承诺无法准确计算的进度百分比。
- 用户可继续查看表单，但测试涉及的连接字段在进行中不可修改，或修改后明确使结果失效；最终行为待交互评审统一。

### 保存与测试的副作用

- “保存数据源”只持久化当前结构化配置，不发起真实连接测试。新记录保存后显示“未测试”，不得作为新任务候选。
- “保存并测试连接”必须在动作前说明：先持久化保存，再从所选在线且有权限的执行节点发起真实基础测试。
- 地址、端口、集群、租户、用户名、密码或连接方式变更后，旧测试结果失效并重置为“未测试”；既有记录保留管理 Enable 意图，但新任务选择资格在当前配置重新测试成功前失效。

### 成功结果

- 连接成功。
- 响应耗时。
- 数据库版本（能够获取时）。
- 兼容模式（能够获取时）。
- 当前租户 / 用户等基础信息（能够获取时）。
- 测试完成时间。

未能获得某项基础信息不等同于连接失败，应显示“未获取”，并避免推导权限结论。

### 失败结果

| 分类 | 用户提示重点 |
|---|---|
| 网络不可达 | 检查地址、网络和访问路径 |
| 端口连接失败 | 检查端口、监听和网络策略 |
| 认证失败 | 检查用户名、密码、租户和集群格式 |
| 连接超时 | 展示耗时与超时类别；具体阈值待确认 |
| 数据库错误 | 展示脱敏后的原始错误和可定位的基础字段 |
| 未知错误 | 提供可追踪标识，不给出未经验证的修复建议 |

### 明确禁止的结果文案

- “适合导入”或“导入权限完整”。
- “适合导出”或“导出权限完整”。
- “对象权限正常”。
- “性能良好”或“建议并发度”。
- “任务一定可以执行”。

## 6. 状态模型

连接状态与启用状态分别维护和展示：

| 连接状态 | 含义 |
|---|---|
| 未测试 | 从未完成基础连接测试，或关键连接信息修改后原结果失效 |
| 可连接 | 最近一次基础连接测试成功 |
| 连接失败 | 最近一次基础连接测试失败 |

| 启用状态 | 含义 |
|---|---|
| 已启用 | 在用户有权限且满足向导规则时可供选择 |
| 已禁用 | 不可创建新任务；历史任务仍保留数据源快照和名称 |

连接成功结果是否随时间自动过期、过期后在向导中警告还是阻断：待评审。

## 7. 启用、禁用与删除

### 禁用

- 需二次确认，并说明禁用后不能创建新任务。
- 不改变已提交任务的参数快照。
- 对等待中或运行中任务的影响规则需要与任务语义共同确认，本稿不自行决定取消任务。

### 启用

- 恢复新任务选择资格。
- 是否要求最近一次测试成功后才能启用：待评审。

### 永久删除或显式归档

- 已被导出草稿、预检查、连接测试或任务引用时不得破坏历史记录；当前模板不直接引用数据源，不能作为资格规则。
- 列表在展示 Lifecycle Action 前必须由服务端计算 `lifecycleEligibility.disable`、`lifecycleEligibility.delete`、`lifecycleEligibility.archive` 及其原因。无引用时 Delete 可执行；存在历史引用时 Delete 不可执行，Archive 才是可执行危险操作。
- Delete 与 Archive 不得合并成不确定的动作，也不得在用户点击 Delete 后改为 Archive。Confirm Dialog 必须在操作前明确写出本次将删除或本次将归档及其原因。
- 高风险操作需二次确认并记录审计。

## 8. 与任务向导的关系

- 向导只列出用户有权限、已启用且满足最终可用规则的数据源。
- 选择后展示只读摘要：名称、环境、地址/端口、集群/租户、兼容模式、最近测试结果和时间。
- 向导不修改连接信息，不重复输入密码。
- 基础测试成功不替代具体任务的权限、对象、文件、版本、路径或执行节点检查。
- 新增数据源后返回原向导，应恢复草稿上下文、刷新列表并允许用户选择新数据源。

## 9. 安全与审计

- 密码加密存储，页面不回显原始密码，普通日志不得记录密码。
- 非授权用户不得查看生产数据源连接详情。
- 新增、编辑、测试、启用、禁用、永久删除和显式归档均记录审计日志。
- 测试错误和地址展示按权限脱敏，具体脱敏规则待安全评审。

## 10. 验收场景

1. 有权限用户可新增私有 ODP 连接信息并发起基础连接测试；非 ODP 类型不能保存。
2. 成功结果只展示连接事实和可直接获得的基础信息。
3. 失败结果能区分网络、端口、认证、超时和数据库错误等基础类别。
4. 编辑时密码不回显，未修改密码可继续使用已保存凭据测试。
5. 禁用的数据源不出现在新任务可选列表中。
6. 数据源页面不展示对象列表、导入/导出权限诊断、性能诊断或任务可行性结论。
7. 历史任务不因数据源后续编辑或删除/归档而改变。
8. 无数据源和筛选无结果有不同空状态。

### 11.2 字段映射结论

| 平台字段 | 官方依据 | 当前产品结论 |
|---|---|---|
| 主机地址 | `-h / --host` 为必选，可连接 ODP 或 OceanBase 物理节点；IPv6 使用中括号 | 数据源必填；平台保存原始地址，命令生成时按官方格式转义 |
| SQL 端口 | `-P / --port` 为必选 | 数据源必填；只表示 SQL 连接端口，不与旁路 RPC 端口混用 |
| 连接方式 | 官方主机参数同时覆盖 ODP 和 OceanBase 物理节点 | 当前切片固定私有 ODP；平台拒绝非 ODP，云 ODP 与 ODP Sharding 不在范围内 |
| 用户名、租户、集群 | 普通导入/导出命令的 `-u / --user` 采用 `<user>@<tenant>` 或 `<user>@<tenant>#<cluster>` 组合格式 | 当前实现保存已登记的连接标识；`--cluster` 等额外映射待官方参数映射确认，不自行生成 |
| 密码 | `-p / --password` 在官方命令行中为非必选 | V1.0 按产品决策要求新增时必填；不支持无密码账户 |
| 默认数据库 / Schema | 具体任务命令的 `-D / --database` 为必选 | 数据源中仍为可选默认值；实际来源/目标数据库由具体任务确定并校验 |
| 兼容模式 | 官方 `--compat-mode` 表示将 MySQL 表定义转换为 OceanBase MySQL 兼容定义 | 数据源的 MySQL / Oracle 兼容模式是租户属性，禁止直接映射为 `--compat-mode` |
| sys 用户凭据 | 官方命令存在 `--sys-user`、`--sys-password`，适用条件与版本相关 | 数据源高级设置可选字段（2026-08-10 实现，参考 ODC）：账号/密码成对提供，密码走加密信封；浏览器摘要只派生 AVAILABLE/UNAVAILABLE；导出能力是否使用由任务在 sysCredentialState=AVAILABLE 时考虑，当前仍保持关闭 |
| 连接配置文件 | `--session-config` 指向工具连接配置文件 | 不作为普通数据源字段；归属于执行节点或工具配置，具体边界待官方参数映射确认 |

### 11.3 已确认的边界

- 基础连接测试可以验证平台保存的地址、SQL 端口和业务用户凭据，但不能证明 OBLOADER/OBDUMPER 的具体任务参数合法。
- 旁路导入的 RPC 端口不属于普通 SQL 连接测试；在旁路任务流程中单独获取、确认和预检查。
- 平台可以将连接字段结构化保存，但最终命令中的用户名组合、转义和场景差异必须由任务参数映射决定。
- 数据源兼容模式不能因为名称相似而映射到官方 `--compat-mode` 参数。

### 11.4 发现的口径差异

1. **密码必填性**：PRD 要求密码必填，官方 `-p / --password` 为非必选。DS-R11 已确认 V1.0 继续遵循 PRD，不支持无密码账户；这是平台约束，不得误写为官方必选项。
2. **集群名条件**：按 2026-09-11 解析兼容性确认，集群名不是必填项；普通导入/导出命令按是否填写集群组合为 `<user>@<tenant>` 或 `<user>@<tenant>#<cluster>`。当前切片固定私有 ODP，`--cluster` 等额外映射仍标记为“待官方参数映射确认”。
3. **兼容模式命名**：数据源兼容模式与官方 `--compat-mode` 含义不同。后续参数映射表必须使用不同的内部字段和帮助文案，避免错误生成命令。

| 编号 | 议题 | 推荐方案 | 主要理由 |
|---|---|---|---|
| DS-R01 | 数据源名称唯一性 | V1.0 采用平台内全局唯一 | 任务、模板、日志和审计引用时更易识别，避免同名环境误选 |
| DS-R02 | 环境枚举 | V1.0 固定为开发、测试、预生产、生产，不新增环境管理页面 | 保持轻量；生产环境可稳定绑定风险样式和权限规则 |
| DS-R03 | 连接字段保存 | 用户名、租户、可选集群分别保存，命令生成时组合 | 降低组合字符串填写错误，支持不同连接场景的条件显示 |
| DS-R04 | 兼容模式 | 连接成功后自动识别；无法可靠识别时人工选择并标记“待校验” | 不因辅助信息获取失败误判连接失败，也不把未知模式默认为成功 |
| DS-R05 | 连接信息变更 | 地址、端口、连接方式、集群、租户、用户名或密码变化后，将连接状态重置为“未测试” | 旧测试结果不再代表当前配置 |
| DS-R06 | 测试结果有效期 | 数据源模块不设置硬过期时间，只展示最近测试时间；每个任务提交前重新检查 | 避免任意过期阈值，同时保证执行前使用当前事实 |
| DS-R07 | 启用条件 | 当前连接配置至少有一次成功测试后才能启用或被向导选择 | 避免未验证连接进入任务流程 |
| DS-R08 | 删除与归档 | 无引用可物理删除；存在任务或模板引用时只能归档 | 保留历史任务可追溯性，同时不无限保留无引用误建数据 |
| DS-R09 | 禁用影响 | 禁止新任务选择；不自动取消运行中任务；等待任务启动前重新检查并阻断 | 管理状态变更不能伪装成进程取消，也不能让新执行绕过禁用 |
| DS-R10 | 生产数据源 | 使用明确环境标识、角色权限、操作审计；任务提交风险确认不放进连接测试 | 把连接事实与生产操作风险分开 |
| DS-R11 | 密码必填性 | V1.0 暂按 PRD 保持必填，不支持无密码账户 | 保持当前需求基线；如需放宽，应单独确认安全与空密码语义 |
