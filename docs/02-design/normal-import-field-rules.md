## 1. 目的与边界

本文把普通导入参数落到字段层，明确字段位置、显示条件、必填条件、默认来源、清值方式、命令映射和预检查失效范围。字段可以承载一个互斥参数组或一组派生连接参数，但不能遗漏任何已确认有效的普通导入能力。

本文不定义 API、数据库表、前端组件、控制文件编辑器或命令生成代码。

## 2. 字段状态

| 状态 | 含义 | 生成命令 | 提交快照 |
|---|---|---:|---:|
| 未设置 | 用户未覆盖，沿用 OBLOADER 4.3.5 官方默认 | 否 | 记录默认来源或“官方默认” |
| 已显式设置 | 用户在当前适用条件下主动配置 | 是 | 是 |
| 非活动 | 因格式、内容、环境或模式不适用 | 否 | 否；草稿期可按命名空间暂存 |
| 派生 | 从数据源、执行节点、安全配置或确认结果计算 | 需要时 | 是，敏感值脱敏 |
| 阻断 | 映射不确定、依赖不满足或预检查失败 | 否 | 不允许提交 |

通用规则：

- 未设置的可选参数显示“沿用官方默认”，不为追求命令长度主动生成。
- 参数搜索必须能定位所有“可编辑”和“派生”字段，并显示为什么当前隐藏或只读。
- 格式切换只让不适用字段停止生效；草稿值按格式暂存，提交只保存活动值。
- 内容、数据源或兼容模式变化导致原值必然非法时，列出影响并在用户确认后清除。
- 任何影响实际文件集合、目标对象、命令或风险范围的变化都会使相应预检查失效。

`--storage-uri` 不生成。远程类型必须由结构化字段生成官方 `--file-path`，不得接受无法判断 scheme 和凭据边界的任意 URI。

## 12. 已确认字段规则

NI-FR01～NI-FR10 已于 2026-07-17 全部确认。字段规则确认不改变参数事实状态，未取得官方语义或受控验证证据的能力仍保持不展示、阻断或待验证。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| NI-FR01 | 全部参数入口 | 高级/专家区提供分类目录和参数搜索，能定位每个有效普通导入参数 |
| NI-FR02 | 官方默认 | 默认不主动生成；摘要标明“沿用官方默认”及已知值 |
| NI-FR03 | 格式草稿 | 各格式草稿值暂存但不生效，提交仅保存活动格式值 |
| NI-FR04 | 文件匹配预览 | 展示总数和有限样例；零匹配阻断，无法完全枚举时明确说明 |
| NI-FR05 | 连接派生 | 连接、租户、集群、sys 与会话路径由数据源/节点派生并只读展示 |
| NI-FR06 | 列映射入口 | 顺序、控制文件、自动映射、显式列名单按官方互斥关系呈现，不做智能映射 |
| NI-FR07 | 高风险确认 | replace/truncate/delete/replace-object 按实际影响范围确认，范围变化即失效 |
| NI-FR08 | yes 派生 | 用户不直接配置 `--yes`；平台完成等价确认后为非交互执行生成 |
| NI-FR09 | 性能参数 | 不给伪精确“推荐值”；显示官方默认、关系和节点风险 |
| NI-FR10 | 检查点继续 | 仅有效 load.ckpt、原输入路径和不可变快照条件满足时显示 |

## 13. 字段覆盖验收

1. 参数搜索能对每个有效普通导入参数返回可编辑字段、派生摘要或失败任务操作。
2. 不适用参数可解释“为什么当前不可用”，而不是无声消失。
3. 同一命令语义只保留一个新建入口，例如 column-quote、file-path。
4. 普通导入不会因高级面板而生成旁路专属参数。
5. 所有活动字段都进入参数摘要和不可变任务快照。
6. 所有命令变化都能使对应预检查失效，所有风险范围变化都能使确认失效。
