# 导出向导六步全状态低保真设计

> 文档状态：EX-D1 产品设计产出  
> 创建日期：2026-08-05  
> 依据：[导出模块设计](export-module.md)、[字段与条件矩阵](export-field-rules.md)、[V1.0 支持矩阵](export-v1-support-matrix.md)  
> 安全说明：不记录真实端点、身份、密码、密钥、完整命令或工具原始输出

## 1. 文档目的

本文是导出向导六步的全状态低保真设计，覆盖每一步的默认、加载、空、错误、无权、阻断、警告、草稿恢复和版本不兼容共 9 种状态。使用结构化文本描述区域、控件和交互，不提供视觉线框。

## 2. 通用元素

### 2.1 步骤指示器

位于页面顶部，始终可见。

```text
[1 数据源] → [2 对象] → [3 内容] → [4 格式] → [5 执行与输出] → [6 确认与执行]
```

- 当前步骤高亮，已完成步骤打勾，未到达步骤置灰。
- 点击已完成步骤可回跳查看（只读），不回退数据。
- 仅 DDL 内容时跳过步骤 4，指示器显示为 `[1] → [2] → [3] → [5] → [6]`。

### 2.2 底部导航栏

始终显示在页面底部：

- **上一步**：步骤 1 时隐藏。
- **下一步**：校验当前步骤必填项和阻断条件；通过后才可进入下一步。
- **保存草稿**：保存当前进度到草稿，返回任务中心。
- **取消**：确认后丢弃未保存草稿。

### 2.3 草稿自动保存

每步字段变化时自动保存到草稿（静默），不清除已通过的预检查。页面顶部显示"草稿已保存 · HH:MM:SS"。

### 2.4 VALIDATION_GATED 参数标记

所有 VALIDATION_GATED 的字段在显示时附加"待验证"标记和提示图标，悬停显示"该参数受控实测未完成，选择后最终命令将阻断验收"。

## 3. 步骤 1：选择数据源

### 涉及字段

EX-F001~F008

### 页面结构

```text
标题：选择数据源
副标题：选择用于本次导出的 OceanBase 数据源

[搜索框] [环境筛选：全部/生产/测试/开发]

[数据源卡片列表]
  每张卡片：名称 | 环境标识 | 连接方式 | 地址:端口 | 租户 | 集群 | 兼容模式 | 最近测试状态/时间
  [重新测试] 按钮

[选中后展开区域]
  连接摘要（只读）：host / port / user / cluster
  默认数据库输入框（可编辑）
  sys 凭据状态指示（可用/不可用/不需要）
  会话配置摘要（只读）
```

### 状态矩阵

| 状态 | 展示 | 交互 |
|---|---|---|
| 默认 | 数据源卡片列表，无选中 | 搜索和筛选可用；下一步禁用 |
| 加载 | 卡片列表区域骨架屏 + "正在加载数据源…" | 搜索框可用；下一步禁用 |
| 空 | "暂无可用数据源" + "请先在数据源管理中添加并成功测试连接" | 提供"前往数据源管理"链接 |
| 错误 | "加载数据源失败：{错误信息}" + [重试] 按钮 | 保留搜索/筛选状态 |
| 无权 | "暂无数据源查看权限" + "请联系管理员授予数据源读取权限" | 不提供任何操作入口 |
| 阻断 | 选中数据源但连接测试失败："连接测试未通过，请重新测试或选择其他数据源" | 下一步禁用；可点"重新测试" |
| 警告 | 生产环境数据源显示橙色环境标识 + "生产环境数据源，请确认导出操作已获授权" | 不阻断下一步；风险确认在步骤 6 |
| 草稿恢复 | 检测到草稿时："检测到上次未完成的导出草稿（数据源：{名称}，保存时间：{时间}）" + [恢复草稿] / [新建] | 恢复后自动选中数据源并填入数据库 |
| 版本不兼容 | 草稿的参数元数据版本与当前版本不同："草稿使用的参数版本已过期，需要重新选择数据源" + [确认并新建] | 清除草稿，进入默认状态 |

### 前进条件

- 数据源已选中
- 连接测试状态为成功
- 默认数据库已填写且非空

### 传递到下一步的数据

数据源 ID、连接快照（host/port/user/cluster）、兼容模式、数据库名、sys 凭据可用性、环境标识。

### 状态矩阵

| 状态 | 展示 | 交互 |
|---|---|---|
| 默认 | 范围单选未选中，指定对象区域隐藏 | 下一步禁用 |
| 加载 | 对象类型列表加载中（如需要从数据源获取可用类型） | 骨架屏 |

| 警告 | 兼容模式不支持的对象类型被选择 | "当前兼容模式不支持{类型}，将自动禁用" |
| 草稿恢复 | 恢复已选对象列表和范围 | 自动填入 |

### 前进条件

- 范围已选择
- 指定对象时至少一个合法对象
- 无阻断条件

### 传递到下一步的数据

## 6. 步骤 4：选择数据格式

### 涉及字段

EX-F017~F020、EX-F043~F054

### 页面结构

```text
标题：选择数据格式
副标题：选择表数据的输出格式，并配置格式专属参数

▾ 基础选项 · 功能选项 · 文件格式（树节点，默认展开）

    ├─ 格式专属配置 —— 按选中格式显示参数行：
```

| 状态 | 展示 | 交互 |

| 空 | 不适用 | — |
| 错误 | 不适用 | — |
| 无权 | 不适用 | — |

- 格式已选择
- POS 格式已提供控制文件（用户提供目录或自动生成）

### 传递到下一步的数据

```text

    └─ NLS / 日期时间值格式 —— 待验证
▾ 高级选项 · 功能选项 · 黑白名单筛选（树节点，默认折叠）
    ├─ 自定义查询 —— 多行文本框（专家受限）
    ├─ 条件筛选（--where）—— 文本框（与自定义查询互斥；仅配合 --table，2026-08-11 接入）
    ├─ 一致性快照 —— 复选框 --snapshot（最近一次合并版本快照；与闪回参数组合在确认前阻断）

    └─ 文件拆分（--block-size）—— 文本框（正整数或正整数+MB/ROW；结构化格式隐藏并提示不适用）

保存点续跑不属于新建向导；仅在 EX-I8 验证失败任务的 dump.ckpt、原参数快照、路径和工具版本后，由任务详情提供。
```

| 状态 | 展示 | 交互 |

- 导出路径已填且合法（本地路径为绝对路径）

| 阻断 | 明文凭据不完整（sys 密码缺失但需要） | "需要 sys 凭据但未配置，请检查数据源安全配置" |
| 警告 | 非空目录 + 未勾选 skip-check-dir | "输出目录非空，请勾选跳过空性检查或更换目录" |
| 警告 | 高风险参数（drop-object、remove-newline、logical-database、query-sql） | 列出高风险参数并要求逐项确认 |
| 草稿恢复 | 不适用（步骤 6 不保存草稿） | — |

### 预检查项列表

当前已实现的六项固定检查：

1. **DATABASE_CONNECTIVITY**：数据源连接测试
2. **OBJECT_ACCESS**：对象可读性和权限检查
3. **TOOL_ENVIRONMENT**：执行节点工具版本和环境
4. **OUTPUT_PATH**：路径可写性和目录规则
5. **OUTPUT_EMPTY**：目录空性检查
6. **AVAILABLE_SPACE**：可用空间（最少 1 GiB）

随能力开放的扩展检查（VALIDATION_GATED 状态时显示为"待验证"）：

7. 对象类型与兼容模式/版本矩阵
8. 参数互斥/依赖完整性
9. 对象存储连通性和凭据完整性
10. sys 权限可用性（DDL + add-extra-message 场景）

### 前进条件（提交执行）

- 全部预检查通过或仅有警告（已确认）
- 命令生成成功
- 风险确认全部勾选（有风险项时）
- 无 VALIDATION_GATED 参数被设为活动状态（否则阻断验收）

### 提交后行为

- 创建任务，进入任务详情页
- 显示任务 ID、状态和实时日志流入口
- 草稿自动清除

## 9. 跨步骤通用状态

### 9.1 网络断开

任一步骤中网络断开时：
- 页面顶部显示红色横幅："网络连接已断开"
- 已填数据保留在草稿中
- 下一步和提交按钮禁用
- 网络恢复后自动重连并提示"网络已恢复"

### 9.2 会话过期

用户会话过期时：
- 弹窗提示"登录已过期，请重新登录"
- 草稿已自动保存，重新登录后可恢复
- [重新登录] 按钮

### 9.3 并发编辑

同一草稿被其他会话编辑时（罕见）：
- 提示"此草稿正在被其他会话编辑"
- 提供"只读查看"和"强制接管"选项
- 强制接管需要二次确认

### 9.4 数据源状态变化

步骤 1 选中的数据源在后续步骤中被禁用或删除：
- 检测到变化时弹窗提示"数据源'{名称}'状态已变化，请重新选择"
- 清除后续步骤已填数据
- 回退到步骤 1

## 10. 验收基线

1. 六步向导每一步的 9 种状态（默认、加载、空、错误、无权、阻断、警告、草稿恢复、版本不兼容）均有明确的展示文案和交互行为定义。
2. 步骤间的前进条件和数据传递明确，不存在跳过校验的路径。
3. VALIDATION_GATED 字段和格式在页面中有明确标记，选择后阻断验收但不阻断配置流程。
4. 草稿自动保存和恢复覆盖全部六步。
5. `--query-sql` 作为受限专家能力在步骤 5 的黑白名单筛选面板中显示，要求 CAP_SENSITIVE_COMMAND 权限和二次确认。
6. 仅 DDL 内容时步骤指示器正确跳过步骤 4。
7. 高风险参数（drop-object、remove-newline、logical-database、query-sql、skip-check-dir）均有二次确认机制。
8. 不提供视觉线框，只提供结构化文本描述，后续高保真设计可基于本文档细化。
