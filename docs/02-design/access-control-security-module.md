## 1. 评审目标

为 V1.0 建立一套足够支撑现有模块、又不扩展为企业 IAM 平台的权限与安全基线，统一回答以下问题：

- 五类角色分别负责什么，哪些能力不能因角色名称自动获得；
- 用户能否查看对象、使用对象或管理对象；
- 生产环境、高级参数、敏感命令和日志下载如何受控；
- 任务、节点、日志、模板、首页聚合和系统设置如何继承同一权限语义；
- 权限变化、敏感操作和高风险操作如何留痕。

本文定义产品权限语义和页面边界，不定义认证协议、数据库表、权限服务接口、密钥系统或具体加密实现。

## 2. PRD 角色口径收口

PRD 第 2 章的“开发人员、运维人员 / DBA、系统管理员”用于描述用户画像和使用诉求；第 17.1 节的五类角色用于权限分工。V1.0 权限基线以后者为准：

1. 普通用户；
2. 运维人员；
3. 数据源管理员；
4. 节点管理员；
5. 系统管理员。

一个已认证用户可以被授予多个固定角色。多角色只合并已授予的功能能力，不能绕过对象范围、生产环境限制、敏感信息保护或平台安全总开关。

为消除现有模块的职责交叉：

- 节点管理员是执行节点注册、编辑、状态管理和工具环境管理的主角色；
- 系统管理员负责平台设置、角色与范围授权、审计访问；
- 系统管理员如需操作节点、数据源或业务任务，仍需获得对应角色或独立能力，不因“系统管理员”天然成为全部业务对象的超级用户；
- 运维人员可以在授权范围内执行任务运维和节点运行操作，但不默认拥有节点注册、工具路径修改或系统设置权限。

## 3. 模块边界

### 3.1 包含

- 五类固定角色及其默认职责。
- 同一用户的多角色组合。
- “功能能力 + 对象范围”双重授权。
- 任务、数据源、执行节点和模板的对象权限。
- 任务日志继承、节点/调度/审计日志权限。
- 生产任务权限、二次确认与审计。
- 高级/专家配置、敏感命令和高风险操作权限。
- 最小权限配置入口：为已认证用户分配固定角色、对象范围和独立高风险能力。
- 权限变更、撤销、重新校验和审计规则。
- 页面、查询、数量、候选项、下载和跳转的一致授权。

### 3.2 不包含

- 用户注册、登录、找回密码、MFA、单点登录或统一身份源建设。
- 自定义角色设计器、权限表达式、策略脚本或属性规则编辑器。
- 组织架构、部门、团队、项目空间、租户、嵌套用户组或共享链接。
- 公开/团队/私有等新的数据源、模板或任务分享模型。
- 权限申请、审批中心、审批流、工单、定时授权或自动授权。
- 密钥生成、注入、轮换、备份、恢复和凭据重加密实现。
- 数据库对象级授权治理、导入/导出权限诊断或数据库账号权限修复。
- 通用审计分析、SIEM、DLP、告警或合规报表平台。

## 4. 授权模型

### 4.1 三个判断条件

一次操作只有同时满足以下条件才允许：

1. **身份有效**：当前请求能够确认已认证用户；认证接入方式待技术设计。
2. **功能允许**：用户具备该操作对应的固定角色能力或独立高风险能力。
3. **对象在范围内**：任务、数据源、节点或模板属于用户被授权的对象范围。

生产环境、敏感命令和平台安全总开关属于附加安全条件，不能被上述三项替代。

### 4.2 默认拒绝

- 未明确授予的能力默认拒绝。
- 前端隐藏或禁用只用于交互提示；服务端的读取、修改、下载、提交和状态操作都必须重新校验。
- 无权对象不进入列表、数量、趋势、筛选候选、上下文、下载或首页聚合。
- 页面不得通过“对象存在但无权”、总数差异、错误信息或跳转结果泄露无权对象。

### 4.3 对象范围

V1.0 只使用满足当前模块的最小范围语义：

| 对象 | 最小范围语义 | 继承关系 |
|---|---|---|
| 任务 | 本人创建，或明确授权范围内的任务 | 任务详情、配置快照、命令、任务日志和操作记录继承任务权限 |
| 数据源 | 明确授权的数据源 | 使用数据源不等于管理数据源；任务仍需提交前检查 |
| 执行节点 | 明确授权的节点；已启用节点组时可作为范围标签 | 节点详情、基础事件和节点/Agent 日志继承节点范围 |
| 模板 | 明确授权的模板范围 | 使用模板不扩大数据源、节点、任务或专家参数权限 |
| 系统设置 | 平台级能力，无对象子范围 | 只读与编辑分别授权 |
| 调度日志 | 平台运维能力 | 不因拥有任一任务自动获得全局调度日志 |
| 审计日志 | 独立审计能力 | 不因系统设置可读或业务对象可见自动获得 |

“明确授权范围”的主体绑定和持久化方式待技术设计；V1.0 不借此引入组织、团队或多租户模型。

## 5. 固定角色职责

| 角色 | 默认职责 | 默认范围 | 不自动获得 |
|---|---|---|---|
| 普通用户 | 使用授权数据源和可用节点创建任务；查看本人或明确授权任务及任务日志 | 本人任务、明确授权的数据源/节点/模板 | 生产任务、专家配置、敏感命令、全局任务、节点管理、系统设置 |
| 运维人员 | 查看授权范围内任务；执行取消、重新执行、检查点继续等状态化操作；管理授权模板；查看必要调度日志 | 明确授权的任务、模板和运行节点 | 数据源编辑、节点注册/工具路径修改、系统设置、权限管理、敏感命令 |
| 数据源管理员 | 新增、编辑、测试、启用、禁用和删除/归档授权数据源 | 明确授权的数据源管理范围 | 数据源密码回显、任务执行、节点管理、对象级权限诊断、系统设置 |
| 节点管理员 | 注册、编辑、环境核对、启停、维护、归档授权节点，管理工具路径和节点并发 | 明确授权的执行节点 | 业务任务数据、数据源凭据、系统设置、权限管理、生产任务执行 |
| 系统管理员 | 查看/编辑系统设置；为已认证用户分配固定角色、范围和独立能力；查看审计 | 平台级管理范围 | 全部任务、数据源、节点、模板或敏感命令的天然访问权 |

### 5.1 多角色

- 一个用户可以同时是运维人员和节点管理员等多个角色。
- 多角色的功能能力取并集，对象范围仍按具体对象类型判断。
- 平台不可关闭的脱敏、安全总开关和显式禁止规则优先于角色能力。
- 权限页面显示用户的直接角色、对象范围、独立能力和最终有效权限摘要，避免只显示角色名称导致误判。

## 6. 最小权限配置入口

权限配置作为“系统设置 > 安全”下的受控入口，不新增一级导航，也不建设独立 IAM 控制台。

### 6.1 页面结构

```text
权限配置
├── 已认证用户列表
├── 用户权限详情
│   ├── 固定角色
│   ├── 数据源范围
│   ├── 执行节点范围
│   ├── 模板/任务运维范围
│   └── 独立高风险能力
└── 变更比较与审计摘要
```

### 6.2 允许配置

- 为已由认证系统识别的用户分配或移除五类固定角色。
- 为对应角色选择数据源、执行节点、模板或任务运维范围。
- 单独授予生产任务创建/提交、专家配置、敏感命令查看/复制和审计日志访问能力。
- 查看当前有效权限摘要、最近变更人和变更时间。
- 保存前展示新增、移除和影响范围；关键变更记录审计。

### 6.3 不允许配置

- 创建或删除登录账号、重置认证凭据。
- 新建自定义角色或自由拼装底层接口权限。
- 把“全部对象”作为普通用户的默认范围。
- 通过权限配置页查看数据源密码、密钥、Agent Token 或命令明文。
- 用户通过普通页面给自己增加角色、范围或高风险能力；初始管理员与故障恢复流程待安全技术设计。

## 8. 任务权限与高风险能力

### 8.1 任务创建和查看

- 创建任务要求同时具备任务类型能力、数据源使用范围和执行节点使用范围。
- 数据源管理员或节点管理员的管理权不自动授予任务创建权。
- 普通用户默认查看本人创建的任务；被明确授权的数据源任务范围可查看并按任务操作契约取消，单纯只读授权不会获得取消、重试或保存模板等操作。
- 运维人员按授权范围查看并执行状态化操作，不使用“查看全部任务”作为无边界默认值；取消仍需 CSRF、幂等键、状态和租约事实复核。
- 从首页、模板、节点或日志跳转任务详情时重新校验任务权限。

### 8.2 高级与专家配置

- 普通配置对具备对应任务创建能力的用户开放。
- 高级配置仍按官方参数条件显示，不因角色切换而显示不适用参数。
- 专家配置需要独立能力；该能力只允许配置已经进入相应参数映射基线的字段，不允许任意追加命令片段。
- 参数安全阈值、互斥、依赖、生产环境限制和预检查对所有角色生效。

### 8.3 生产任务

- 生产环境由数据源固定环境标识判断，不能在任务向导中临时改写。
- 普通用户默认没有生产任务创建/提交能力；其他角色也不因角色名称自动获得。
- 生产任务能力从生产数据源进入候选和创建草稿时开始校验，并在提交时再次校验；没有该能力时不能通过手工参数或模板绕过。
- 生产任务需要任务创建/运维能力、对应对象范围和独立生产任务能力。
- 提交前始终展示生产标识、目标数据源、任务类型、对象范围、完整脱敏命令和风险摘要，并执行二次确认。
- V1.0 不引入审批中心或审批流；二次确认不能替代权限校验和预检查。

## 9. 敏感命令与凭据

### 9.1 默认行为

- 页面展示、复制、错误、日志、下载和审计统一使用平台不可关闭的脱敏基线。
- 默认只展示和复制脱敏命令。
- 任务权限、敏感命令权限和平台“允许查看敏感命令”总开关三者缺一不可。

### 9.2 受控查看/复制

当总开关开启且用户同时具备任务权限和独立敏感命令能力时：

1. 用户主动选择查看或复制敏感命令；
2. 页面展示任务、环境和泄露风险，要求二次确认；
3. 服务端在操作时重新校验权限和总开关；
4. 记录操作者、任务、环境、操作类型、结果和时间，不记录命令明文；
5. 离开页面或重新加载后恢复脱敏状态，精确会话时限待安全技术设计。

敏感命令权限不授予未脱敏日志下载，日志中心 V1.0 始终只提供脱敏内容。

### 9.3 凭据边界

- 数据源密码、对象存储密钥、Agent Token 和加密密钥不提供普通读取或回显。
- 编辑密码使用覆盖式输入；未修改时不把已有密文或占位符回填成可提交值。
- 执行节点按安全技术方案取得任务所需临时凭据；产品页面不承诺凭据传输、轮换和销毁的具体机制。
- 任务结束后清理不再需要的敏感临时文件；精确对象、时机和失败补偿待技术设计。

## 10. 日志、下载与审计

### 10.1 日志权限

- 任务日志继承任务查看权限。
- 节点/Agent 日志继承节点范围，并要求节点运行或节点管理能力。
- 全局调度日志要求运维或独立调度日志能力；普通用户只在本人任务详情看到必要调度事件。
- 审计日志要求系统管理员的审计能力或独立审计能力；查询审计日志本身记录审计。
- 日志数量、筛选候选、上下文和下载使用与结果行完全一致的授权范围。

### 10.2 审计事件

至少记录：

- 固定角色、对象范围和独立能力的授予、移除及失败；
- 生产任务提交与二次确认；
- 敏感命令查看或复制；
- 数据源新增、编辑、测试、启停和删除/归档；
- 节点注册、编辑、环境重检、维护、启停和删除/归档；
- 任务取消、删除草稿、重新执行、检查点继续和完整日志下载；
- 系统设置保存、高影响确认和安全总开关变化；
- 审计日志查询和下载。

审计事件保存操作者、对象、动作、结果、时间、授权范围摘要和必要原因，不保存密码、密钥、Token、敏感命令明文或完整业务日志。

## 11. 权限变化语义

- 权限授予或撤销对后续页面请求、查询、下载和操作立即按新权限判断。
- 已打开页面在刷新、跳转、提交或状态操作时重新校验，不能依赖旧页面状态继续操作。
- 任务提交前重新校验任务能力、生产能力、数据源和节点范围；权限变化会使既有预检查失效并要求重新检查。
- 撤销用户权限不自动取消已经运行的任务，也不改写历史任务快照；后续查看或操作按新权限处理。
- 已运行任务继续由平台执行身份和提交时快照追踪；需要取消时由仍有权限的操作者执行。
- 权限变更使用原子保存；并发修改时阻断覆盖，并展示当前有效版本。

## 12. 页面与异常状态

| 状态 | 页面处理 |
|---|---|
| 无模块能力 | 不显示误导性主操作；直接访问时显示无权限，不泄露对象数量 |
| 有能力但无对象范围 | 说明尚未授权对象，不返回可枚举候选 |
| 对象权限已撤销 | 关闭敏感展示，阻断继续操作并返回安全入口 |
| 角色/范围加载失败 | 不使用缓存角色猜测放行；显示失败并允许重试 |
| 权限保存冲突 | 不覆盖他人变更，刷新后重新比较 |
| 权限部分保存失败 | 整次变更不生效，不出现部分角色或范围 |
| 生产能力不足 | 阻断提交并说明所需能力，不显示绕过入口 |
| 敏感命令总开关关闭 | 只提供脱敏展示/复制，即使用户有独立权限 |
| 审计写入无法确认 | 高敏或高风险操作不宣称成功；精确阻断策略待安全技术设计 |

## 14. 验收基线

1. PRD 五类角色有明确职责，用户画像与权限角色不再混用。
2. 系统管理员、节点管理员、数据源管理员和运维人员之间不存在天然全权角色。
3. 每次对象操作同时校验功能能力和对象范围，前端隐藏不能替代服务端授权。
4. 无权对象不会通过列表、数量、候选、首页、日志或下载泄露。
5. 生产任务使用独立能力、预检查和二次确认，V1.0 不引入审批流。
6. 高级/专家参数权限不改变官方参数适用条件，也不能追加自由命令。
7. 敏感命令只有在总开关、任务权限、独立能力、确认和审计同时满足时受控开放。
8. 密码、密钥、Token 和未脱敏日志没有普通查看或下载入口。
9. 权限撤销不会静默取消运行任务或改写历史快照，但会阻止后续无权操作。
10. 权限配置保持一个轻量入口，不建设自定义角色、组织、分享、审批或 IAM 平台。

## 15. 已确认产品规则

AC-R01～AC-R20 已于 2026-07-19 全部确认。确认的是五类固定角色、功能与对象双重授权、职责分离、生产任务、专家配置、敏感命令、日志、审计、权限变化和轻量化边界；AC-FR01～AC-FR16 字段与条件规则也已于 2026-07-19 确认，详见[权限配置字段与条件矩阵](access-control-security-field-rules.md)。

已认证用户列表、固定角色、对象范围、独立能力、权限变更确认、生产任务提交和敏感命令查看的静态页面已完成评审，AC-LF-R01～AC-LF-R18 已确认，详见[权限与安全高风险操作低保真基线](access-control-security-low-fidelity.md)。

| 编号 | 议题 | 建议方案 |
|---|---|---|
| AC-R01 | 角色口径 | 第 2 章作为用户画像，第 17 章五类角色作为权限基线 |
| AC-R02 | 多角色 | 一个用户可拥有多个固定角色；能力合并但对象范围和安全限制不放宽 |
| AC-R03 | 授权判断 | 每次操作同时要求有效身份、功能能力和对象范围 |
| AC-R04 | 默认拒绝 | 未明确授予即拒绝；服务端强制校验，数量、候选和下载同样过滤 |
| AC-R05 | 系统管理员边界 | 管理设置、权限和审计，不天然获得全部业务对象和敏感命令 |
| AC-R06 | 普通用户 | 使用授权对象创建任务，默认只看本人任务，不默认具备生产/专家/敏感能力 |
| AC-R07 | 运维人员 | 按授权范围查看与操作任务、管理模板和查看必要调度日志，不默认管理数据源/节点配置 |
| AC-R08 | 数据源管理员 | 按范围管理连接和基础测试，不回显密码或执行任务权限诊断 |
| AC-R09 | 节点管理员 | 作为节点注册、编辑、环境和工具管理主角色，不自动获得业务任务数据 |
| AC-R10 | 最小权限入口 | 置于系统设置安全分区，只分配固定角色、对象范围和独立高风险能力 |
| AC-R11 | 对象范围 | 任务、数据源、节点和模板独立授权；详情、日志、聚合与跳转继承并重校验 |
| AC-R12 | 权限组合 | 查看、使用、管理分离；管理对象不自动获得使用该对象执行任务的能力 |
| AC-R13 | 生产任务 | 创建和提交均要求独立生产能力与明确范围，提交再执行预检查和二次确认；V1.0 不做审批流 |
| AC-R14 | 专家配置 | 需要独立能力，只开放已映射参数，不允许任意命令片段 |
| AC-R15 | 敏感命令 | 总开关、任务权限、独立能力、二次确认和审计五项同时满足才受控开放 |
| AC-R16 | 凭据保护 | 密码、密钥、Token 不提供普通回显；日志和下载始终脱敏 |
| AC-R17 | 日志权限 | 任务/节点日志继承对象范围，调度/审计日志使用独立能力，所有结果与候选同范围 |
| AC-R18 | 审计 | 权限变化、生产、敏感和高风险操作留痕，审计记录不复制敏感值或完整业务日志 |
| AC-R19 | 权限变化 | 后续请求立即按新权限校验；运行任务不自动取消，历史快照不改写 |
| AC-R20 | 轻量化 | 不建设认证、组织、用户组、自定义角色、策略脚本、分享、权限审批或通用安全平台 |
