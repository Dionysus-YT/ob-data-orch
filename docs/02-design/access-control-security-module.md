## 1. 评审目标

为 V1.0 建立一套足够支撑现有模块、又不扩展为企业 IAM 平台的权限与安全基线，统一回答以下问题：

- 五类角色分别负责什么，哪些能力不能因角色名称自动获得；
- 用户能否查看对象、使用对象或管理对象；
- 生产环境、高级参数、敏感命令和日志下载如何受控；
- 任务、节点、日志、模板、首页聚合和系统设置如何继承同一权限语义；
- 权限变化、敏感操作和高风险操作如何留痕。

本文定义产品权限语义和页面边界，不定义认证协议、数据库表、权限服务接口、密钥系统或具体加密实现。

## 2. PRD 角色口径收口

PRD 第 2 章的“开发人员、运维人员 / DBA、系统管理员”用于描述用户画像和使用诉求；第 17.1 节的五类角色用于权限分工。V1.0 权限基线以后者为准：

1. 普通用户；
2. 运维人员；
3. 数据源管理员；
4. 节点管理员；
5. 系统管理员。

一个已认证用户可以被授予多个固定角色。多角色只合并已授予的功能能力，不能绕过对象范围、生产环境限制、敏感信息保护或平台安全总开关。

为消除现有模块的职责交叉：

- 节点管理员是执行节点注册、编辑、状态管理和工具环境管理的主角色；
- 系统管理员负责平台设置、角色与范围授权、审计访问；
- 系统管理员如需操作节点、数据源或业务任务，仍需获得对应角色或独立能力，不因“系统管理员”天然成为全部业务对象的超级用户；
- 运维人员可以在授权范围内执行任务运维和节点运行操作，但不默认拥有节点注册、工具路径修改或系统设置权限。

## 3. 模块边界

### 3.1 包含

- 五类固定角色及其默认职责。
- 同一用户的多角色组合。
- “功能能力 + 对象范围”双重授权。
- 任务、数据源、执行节点和模板的对象权限。
- 任务日志继承、节点/调度/审计日志权限。
- 生产任务权限、二次确认与审计。
- 高级/专家配置、敏感命令和高风险操作权限。
- 最小权限配置入口：为已认证用户分配固定角色、对象范围和独立高风险能力。
- 权限变更、撤销、重新校验和审计规则。
- 页面、查询、数量、候选项、下载和跳转的一致授权。

### 3.2 不包含

- 用户注册、登录、找回密码、MFA、单点登录或统一身份源建设。
- 自定义角色设计器、权限表达式、策略脚本或属性规则编辑器。
- 组织架构、部门、团队、项目空间、租户、嵌套用户组或共享链接。
- 公开/团队/私有等新的数据源、模板或任务分享模型。
- 权限申请、审批中心、审批流、工单、定时授权或自动授权。
- 密钥生成、注入、轮换、备份、恢复和凭据重加密实现。
- 数据库对象级授权治理、导入/导出权限诊断或数据库账号权限修复。
- 通用审计分析、SIEM、DLP、告警或合规报表平台。

## 4. 授权模型

### 4.1 三个判断条件

一次操作只有同时满足以下条件才允许：

1. **身份有效**：当前请求能够确认已认证用户；认证接入方式待技术设计。
2. **功能允许**：用户具备该操作对应的固定角色能力或独立高风险能力。
3. **对象在范围内**：任务、数据源、节点或模板属于用户被授权的对象范围。

生产环境、敏感命令和平台安全总开关属于附加安全条件，不能被上述三项替代。

### 4.2 默认拒绝

- 未明确授予的能力默认拒绝。
- 前端隐藏或禁用只用于交互提示；服务端的读取、修改、下载、提交和状态操作都必须重新校验。
- 无权对象不进入列表、数量、趋势、筛选候选、上下文、下载或首页聚合。
- 页面不得通过“对象存在但无权”、总数差异、错误信息或跳转结果泄露无权对象。

### 4.3 对象范围

V1.0 只使用满足当前模块的最小范围语义：

| 对象 | 最小范围语义 | 继承关系 |
|---|---|---|
| 任务 | 本人创建，或明确授权范围内的任务 | 任务详情、配置快照、命令、任务日志和操作记录继承任务权限 |
| 数据源 | 明确授权的数据源 | 使用数据源不等于管理数据源；任务仍需提交前检查 |
| 执行节点 | 明确授权的节点；已启用节点组时可作为范围标签 | 节点详情、基础事件和节点/Agent 日志继承节点范围 |
| 模板 | 明确授权的模板范围 | 使用模板不扩大数据源、节点、任务或专家参数权限 |
| 系统设置 | 平台级能力，无对象子范围 | 只读与编辑分别授权 |
| 调度日志 | 平台运维能力 | 不因拥有任一任务自动获得全局调度日志 |
| 审计日志 | 独立审计能力 | 不因系统设置可读或业务对象可见自动获得 |

“明确授权范围”的主体绑定和持久化方式待技术设计；V1.0 不借此引入组织、团队或多租户模型。

## 5. 固定角色职责

| 角色 | 默认职责 | 默认范围 | 不自动获得 |
|---|---|---|---|
| 普通用户 | 使用授权数据源和可用节点创建任务；查看本人或明确授权任务及任务日志 | 本人任务、明确授权的数据源/节点/模板 | 生产任务、专家配置、敏感命令、全局任务、节点管理、系统设置 |
| 运维人员 | 查看授权范围内任务；执行取消、重新执行、检查点继续等状态化操作；管理授权模板；查看必要调度日志 | 明确授权的任务、模板和运行节点 | 数据源编辑、节点注册/工具路径修改、系统设置、权限管理、敏感命令 |
| 数据源管理员 | 新增、编辑、测试、启用、禁用和删除/归档授权数据源 | 明确授权的数据源管理范围 | 数据源密码回显、任务执行、节点管理、对象级权限诊断、系统设置 |
| 节点管理员 | 注册、编辑、环境核对、启停、维护、归档授权节点，管理工具路径和节点并发 | 明确授权的执行节点 | 业务任务数据、数据源凭据、系统设置、权限管理、生产任务执行 |
| 系统管理员 | 查看/编辑系统设置；为已认证用户分配固定角色、范围和独立能力；查看审计 | 平台级管理范围 | 全部任务、数据源、节点、模板或敏感命令的天然访问权 |

### 5.1 多角色

- 一个用户可以同时是运维人员和节点管理员等多个角色。
- 多角色的功能能力取并集，对象范围仍按具体对象类型判断。
- 平台不可关闭的脱敏、安全总开关和显式禁止规则优先于角色能力。
- 权限页面显示用户的直接角色、对象范围、独立能力和最终有效权限摘要，避免只显示角色名称导致误判。

## 6. 最小权限配置入口

权限配置作为“系统设置 > 安全”下的受控入口，不新增一级导航，也不建设独立 IAM 控制台。

### 6.1 页面结构

```text
权限配置
├── 已认证用户列表
├── 用户权限详情
│   ├── 固定角色
│   ├── 数据源范围
│   ├── 执行节点范围
│   ├── 模板/任务运维范围
│   └── 独立高风险能力
└── 变更比较与审计摘要
```

### 6.2 允许配置

- 为已由认证系统识别的用户分配或移除五类固定角色。
- 为对应角色选择数据源、执行节点、模板或任务运维范围。
- 单独授予生产任务创建/提交、专家配置、敏感命令查看/复制和审计日志访问能力。
- 查看当前有效权限摘要、最近变更人和变更时间。
- 保存前展示新增、移除和影响范围；关键变更记录审计。

### 6.3 不允许配置

- 创建或删除登录账号、重置认证凭据。
- 新建自定义角色或自由拼装底层接口权限。
- 把“全部对象”作为普通用户的默认范围。
- 通过权限配置页查看数据源密码、密钥、Agent Token 或命令明文。
- 用户通过普通页面给自己增加角色、范围或高风险能力；初始管理员与故障恢复流程待安全技术设计。

## 8. 任务权限与高风险能力

### 8.1 任务创建和查看

- 创建任务要求同时具备任务类型能力、数据源使用范围和执行节点使用范围。
- 数据源管理员或节点管理员的管理权不自动授予任务创建权。
- 普通用户默认查看本人创建的任务；被明确授权的数据源任务范围可查看并按任务操作契约取消，单纯只读授权不会获得取消、重试或保存模板等操作。
- 运维人员按授权范围查看并执行状态化操作，不使用“查看全部任务”作为无边界默认值；取消仍需 CSRF、幂等键、状态和租约事实复核。
- 从首页、模板、节点或日志跳转任务详情时重新校验任务权限。

### 8.2 高级与专家配置

- 普通配置对具备对应任务创建能力的用户开放。
- 高级配置仍按官方参数条件显示，不因角色切换而显示不适用参数。
- 专家配置需要独立能力；该能力只允许配置已经进入相应参数映射基线的字段，不允许任意追加命令片段。
- 参数安全阈值、互斥、依赖、生产环境限制和预检查对所有角色生效。

### 8.3 生产任务

- 生产环境由数据源固定环境标识判断，不能在任务向导中临时改写。
- 普通用户默认没有生产任务创建/提交能力；其他角色也不因角色名称自动获得。
- 生产任务能力从生产数据源进入候选和创建草稿时开始校验，并在提交时再次校验；没有该能力时不能通过手工参数或模板绕过。
- 生产任务需要任务创建/运维能力、对应对象范围和独立生产任务能力。
- 提交前始终展示生产标识、目标数据源、任务类型、对象范围、完整脱敏命令和风险摘要，并执行二次确认。
- V1.0 不引入审批中心或审批流；二次确认不能替代权限校验和预检查。

## 9. 敏感命令与凭据

### 9.1 默认行为

- 页面展示、复制、错误、日志、下载和审计统一使用平台不可关闭的脱敏基线。
- 默认只展示和复制脱敏命令。
- 任务权限、敏感命令权限和平台“允许查看敏感命令”总开关三者缺一不可。

### 9.2 受控查看/复制

当总开关开启且用户同时具备任务权限和独立敏感命令能力时：

1. 用户主动选择查看或复制敏感命令；
2. 页面展示任务、环境和泄露风险，要求二次确认；
3. 服务端在操作时重新校验权限和总开关；
4. 记录操作者、任务、环境、操作类型、结果和时间，不记录命令明文；
5. 离开页面或重新加载后恢复脱敏状态，精确会话时限待安全技术设计。

敏感命令权限不授予未脱敏日志下载，日志中心 V1.0 始终只提供脱敏内容。

### 9.3 凭据边界

- 数据源密码、对象存储密钥、Agent Token 和加密密钥不提供普通读取或回显。
- 编辑密码使用覆盖式输入；未修改时不把已有密文或占位符回填成可提交值。
- 执行节点按安全技术方案取得任务所需临时凭据；产品页面不承诺凭据传输、轮换和销毁的具体机制。
- 任务结束后清理不再需要的敏感临时文件；精确对象、时机和失败补偿待技术设计。

## 10. 日志、下载与审计

### 10.1 日志权限

- 任务日志继承任务查看权限。
- 节点/Agent 日志继承节点范围，并要求节点运行或节点管理能力。
- 全局调度日志要求运维或独立调度日志能力；普通用户只在本人任务详情看到必要调度事件。
- 审计日志要求系统管理员的审计能力或独立审计能力；查询审计日志本身记录审计。
- 日志数量、筛选候选、上下文和下载使用与结果行完全一致的授权范围。

### 10.2 审计事件

至少记录：

- 固定角色、对象范围和独立能力的授予、移除及失败；
- 生产任务提交与二次确认；
- 敏感命令查看或复制；
- 数据源新增、编辑、测试、启停和删除/归档；
- 节点注册、编辑、环境重检、维护、启停和删除/归档；
- 任务取消、删除草稿、重新执行、检查点继续和完整日志下载；
- 系统设置保存、高影响确认和安全总开关变化；
- 审计日志查询和下载。

审计事件保存操作者、对象、动作、结果、时间、授权范围摘要和必要原因，不保存密码、密钥、Token、敏感命令明文或完整业务日志。

## 11. 权限变化语义

- 权限授予或撤销对后续页面请求、查询、下载和操作立即按新权限判断。
- 已打开页面在刷新、跳转、提交或状态操作时重新校验，不能依赖旧页面状态继续操作。
- 任务提交前重新校验任务能力、生产能力、数据源和节点范围；权限变化会使既有预检查失效并要求重新检查。
- 撤销用户权限不自动取消已经运行的任务，也不改写历史任务快照；后续查看或操作按新权限处理。
- 已运行任务继续由平台执行身份和提交时快照追踪；需要取消时由仍有权限的操作者执行。
- 权限变更使用原子保存；并发修改时阻断覆盖，并展示当前有效版本。

## 12. 页面与异常状态

| 状态 | 页面处理 |
|---|---|
| 无模块能力 | 不显示误导性主操作；直接访问时显示无权限，不泄露对象数量 |
| 有能力但无对象范围 | 说明尚未授权对象，不返回可枚举候选 |
| 对象权限已撤销 | 关闭敏感展示，阻断继续操作并返回安全入口 |
| 角色/范围加载失败 | 不使用缓存角色猜测放行；显示失败并允许重试 |
| 权限保存冲突 | 不覆盖他人变更，刷新后重新比较 |
| 权限部分保存失败 | 整次变更不生效，不出现部分角色或范围 |
| 生产能力不足 | 阻断提交并说明所需能力，不显示绕过入口 |
| 敏感命令总开关关闭 | 只提供脱敏展示/复制，即使用户有独立权限 |
| 审计写入无法确认 | 高敏或高风险操作不宣称成功；精确阻断策略待安全技术设计 |

## 14. 验收基线

1. PRD 五类角色有明确职责，用户画像与权限角色不再混用。
2. 系统管理员、节点管理员、数据源管理员和运维人员之间不存在天然全权角色。
3. 每次对象操作同时校验功能能力和对象范围，前端隐藏不能替代服务端授权。
4. 无权对象不会通过列表、数量、候选、首页、日志或下载泄露。
5. 生产任务使用独立能力、预检查和二次确认，V1.0 不引入审批流。
6. 高级/专家参数权限不改变官方参数适用条件，也不能追加自由命令。
7. 敏感命令只有在总开关、任务权限、独立能力、确认和审计同时满足时受控开放。
8. 密码、密钥、Token 和未脱敏日志没有普通查看或下载入口。
9. 权限撤销不会静默取消运行任务或改写历史快照，但会阻止后续无权操作。
10. 权限配置保持一个轻量入口，不建设自定义角色、组织、分享、审批或 IAM 平台。

| AC-F046 | 使用与管理说明 | 固定规则 | 始终 | 使用范围不授予编辑/测试；管理范围不自动授予任务使用 |

| AC-F049 | 移除范围影响 | 权限计算 | 移除数据源时 | 阻止未来选择/管理并使相关草稿检查失效，不改写已提交任务快照 |

### 10. 变更比较、保存与审计

| ID | 字段/操作 | 来源 | 显示条件 | 规则 |
|---|---|---|---|---|
| AC-F075 | 变更比较 | 权限草稿 | 存在修改 | 分固定角色、对象范围和独立能力列出新增、移除和无变化 |
| AC-F076 | 变更原因 | 用户输入 | 存在权限修改 | 必填纯文本；长度待实现字段评审，不允许脚本或敏感值 |
| AC-F077 | 高风险确认 | 变更影响 | 新增生产、敏感命令、审计或系统管理员时 | 展示主体、能力、对象范围和影响，要求二次确认 |

| AC-F079 | 取消编辑 | 页面操作 | 存在修改 | 二次确认后丢弃未保存草稿，不改变已生效权限 |
| AC-F080 | 审计摘要 | 保存结果 | 成功或失败 | 记录操作者、主体、差异、范围、原因、结果和时间，不记录敏感值 |

<a id="field-rules-11-页面状态与条件处理"></a>

### 11. 页面状态与条件处理

| 状态 | 触发条件 | 页面规则 |
|---|---|---|
| 首次加载 | 进入列表或详情 | 使用稳定骨架，不显示虚假角色、数量或范围 |
| 身份目录失败 | 无法取得用户 | 阻断新增授权，保留最后可信只读摘要并标记过期 |
| 权限记录失败 | 无法取得当前权限 | 不允许编辑或保存，不用空权限代替失败 |
| 当前用户自身 | 权限管理员打开自己 | 只读展示；不允许普通页面自助提权或降权 |
| 账号停用 | 认证状态停用 | 既有授权只读可撤销，不允许新增角色、范围或能力 |
| 账号状态未知 | 同步异常 | 不新增高风险能力，允许刷新后重试 |
| 无对象候选 | 管理员无可授权对象 | 显示无可授权范围，不泄露不可见对象数量 |
| 角色依赖缺失 | 独立能力没有基础角色 | 阻断保存并指出需要的角色，不保存潜伏能力 |
| 范围为空 | 角色需要对象范围 | 标记能力暂不生效；是否允许保存按 AC-FR05 处理 |
| 并发修改 | 权限版本已变化 | 阻断覆盖，刷新后重新比较 |
| 保存失败 | 原子保存失败 | 全部变化不生效，保留草稿和脱敏错误供重试 |
| 审计无法确认 | 高风险变更审计失败 | 不宣称变更成功，按安全技术策略回滚或进入核对 |

<a id="field-rules-12-已确认字段与条件规则"></a>

### 12. 已确认字段与条件规则

AC-FR01～AC-FR16 已于 2026-07-19 全部确认。确认的是权限页面边界、身份只读字段、固定角色、对象范围、任务运维范围、高风险能力、角色依赖清理、身份异常、原子保存、自身权限限制和审计规则；认证接入、权限持久化、缓存失效和安全实现仍属于技术设计。

| 编号 | 议题 | 建议方案 |
|---|---|---|
| AC-FR01 | 页面边界 | 权限配置保留用户列表和单用户详情，不新增角色设计器、组织、用户组或审批页面 |
| AC-FR02 | 身份字段 | 登录标识、显示名称、认证来源和账号状态只读，平台不创建或修改认证账号 |
| AC-FR03 | 有效权限摘要 | 同时展示角色、查看/使用/管理能力、对象范围和不生效原因，不只显示角色名称 |
| AC-FR04 | 固定角色 | 五类角色可多选，能力取并集，最严格安全策略和对象范围继续生效 |
| AC-FR05 | 角色与范围 | 需要对象的角色允许先保存空范围但明确“不生效”；不能用隐式全部范围替代 |
| AC-FR06 | 数据源范围 | 使用与管理分别选择具体数据源；候选只显示名称、环境、类型和状态，不显示连接敏感信息 |
| AC-FR07 | 任务运维范围 | 运维范围通过关联数据源 ID 表达，但不授予该数据源的任务创建或管理能力 |
| AC-FR08 | 节点范围 | 节点使用、运行操作和管理分离；节点管理员只因节点范围获得最小任务摘要 |
| AC-FR09 | 模板范围 | 模板使用、创建和管理分离，管理按明确模板对象授权，不新增分享模型 |
| AC-FR10 | 生产能力 | 从生产数据源候选和草稿创建开始校验，提交时再次校验、预检查和二次确认 |
| AC-FR11 | 专家配置 | 只开放已映射专家字段，不能追加自由命令，官方条件和安全检查不因授权取消 |
| AC-FR12 | 敏感命令 | 独立能力只在总开关开启且具备任务权限时生效，仍需二次确认和审计 |
| AC-FR13 | 依赖清理 | 移除基础角色时同步移除其对象范围和依赖能力，避免保留潜伏权限 |
| AC-FR14 | 身份异常 | 停用/未知身份不新增授权；权限加载失败不允许用空值覆盖当前配置 |
| AC-FR15 | 保存 | 权限变化原子保存、校验版本、防并发覆盖，高风险新增要求差异确认和原因 |
| AC-FR16 | 自身与审计 | 普通权限页禁止修改自身权限；成功、失败和高风险确认均记录不含敏感值的审计摘要 |

<a id="field-rules-13-字段覆盖验收"></a>

### 13. 字段覆盖验收

1. AC-F001～AC-F080 覆盖用户列表、权限详情、五类角色、四类对象范围、四类独立高风险能力和保存审计。
2. 页面不承担用户认证、自定义角色、组织架构、分享或审批。
3. 使用与管理权限不会互相隐式授予，角色和对象范围均可被明确审查。
4. 无权对象不会出现在范围候选、数量、有效权限摘要或审计跳转中。
5. 生产、专家、敏感命令和审计能力不会绕过现有安全总开关、参数约束或对象权限。
6. 任务运维范围使用数据源 ID 作为独立范围索引，不等同于数据源使用或管理权限。
7. 角色移除不会留下未来可能重新激活的依赖高风险能力。
8. 权限保存原子、防并发覆盖、不可自助提权且全程可审计。

### 1. 评审目标

本文将五类固定角色、对象范围、独立高风险能力、原子保存、生产任务二次确认和敏感命令受控查看落实为静态低保真，覆盖“管理员配置权限”和“用户触发高风险能力”两条链路。

<a id="business-scenarios-3-页面基线"></a>

### 3. 业务场景

<a id="business-scenarios-ac-lf-01-已认证用户与权限列表"></a>

#### AC-LF-01 已认证用户与权限列表


- 页面展示身份来源、同步状态和最后可信时间，但不创建、修改或删除认证账号；
- 筛选只覆盖登录标识/显示名称、固定角色、账号状态和高风险能力；
- 默认列包含账号状态、固定角色、对象范围、独立能力和最近修改信息；
- 对象范围分别显示数据源、节点、任务和模板摘要，不用“全部”掩盖真实边界；
- 当前登录用户只能查看自身权限，不能从普通页面自助提权或降权；
- 未知账号状态不允许新增高风险授权，无权用户和对象不进入数量或候选。

<a id="business-scenarios-ac-lf-02-固定角色与有效权限"></a>

#### AC-LF-02 固定角色与有效权限


- 登录标识、显示名称、认证来源和账号状态只读；
- 普通用户、运维人员、数据源管理员、节点管理员和系统管理员使用固定定义，可以多选但不能自定义；
- 每个角色同时展示默认职责和明确不自动获得的能力；
- 多角色只合并已授功能能力，对象范围和最严格安全条件不扩大；
- 右侧按查看、使用、管理和高风险分别展示当前有效权限及不生效原因；
- 系统管理员不天然获得业务对象、生产任务或敏感命令访问权。

<a id="business-scenarios-ac-lf-03-对象范围与独立高风险能力"></a>

#### AC-LF-03 对象范围与独立高风险能力


- 数据源使用和管理范围分别配置，生产数据源使用风险样式标识；
- 节点使用、运行操作和管理范围分离，只显示必要状态，不展示 Agent Token；
- 任务运维范围通过数据源 ID 表达，但不授予该数据源的使用或管理权限；
- 模板使用、创建和管理分别授权，不新增分享或公开范围；
- 生产任务、专家配置、敏感命令和审计日志作为独立能力，必须满足基础角色和对象范围依赖；
- 专家配置只开放已映射字段，敏感命令能力仍受平台总开关、任务权限、二次确认和审计约束。

<a id="business-scenarios-ac-lf-04-权限变更比较与保存确认"></a>

#### AC-LF-04 权限变更比较与保存确认


- 保存前按固定角色、对象范围和独立能力分组展示新增、保留和移除；
- 新增生产范围或生产能力时，明确说明候选、草稿和提交阶段仍会重新校验；
- 变更原因必填，按纯文本处理且不得填写密码、密钥或敏感命令；
- 新增生产、敏感命令、审计或系统管理员能力时，要求确认主体、范围和影响；
- 保存携带当前权限版本；发现并发变化时阻断覆盖并要求刷新比较；
- 全部差异原子提交，不提供部分保存；成功和失败均形成不含敏感值的审计摘要。

<a id="business-scenarios-ac-lf-05-生产任务提交二次确认"></a>

#### AC-LF-05 生产任务提交二次确认


- 生产环境由数据源固定标识决定，任务向导不能临时改写；
- 弹窗展示目标数据源、任务类型、对象范围、执行节点、工具版本和脱敏命令状态；
- 任务创建能力、生产独立能力、数据源/节点范围、预检查和命令生成必须全部通过；
- 用户必须核对生产环境、对象、节点和脱敏完整命令后才能提交；
- 二次确认不是审批，不能替代权限校验、参数约束或预检查；
- 提交时服务端重新校验权限，变化时阻断提交并使相关预检查失效；成功提交生成不可变任务快照。

<a id="business-scenarios-ac-lf-06-敏感命令受控查看确认"></a>

#### AC-LF-06 敏感命令受控查看确认


- 默认页面和复制操作继续使用不可关闭的脱敏基线；
- 弹窗只展示任务、环境、操作类型和操作者，不提前展示敏感命令明文；
- 任务权限、敏感命令独立能力和平台总开关必须全部通过，并在确认时由服务端复验；
- 用户明确确认泄露风险后，仅为当前任务和当前主动操作受控开放；
- 离开或刷新页面后立即恢复脱敏，精确会话时限仍待安全技术设计；
- 审计记录操作者、任务、环境、操作类型、结果和时间，不保存敏感命令明文；敏感命令能力不开放未脱敏日志下载。

<a id="business-scenarios-4-权限表达原则"></a>

### 4. 权限表达原则

| 维度 | 页面表达 | 禁止推断 |
|---|---|---|
| 固定角色 | 平台内置职责和不自动获得项 | 角色名称等于全部权限 |
| 功能能力 | 查看、使用、管理分别展示 | 查看等于操作，管理等于使用 |
| 对象范围 | 显式对象、关联范围或有限数量 | 空范围或“全部”代表默认全权 |
| 独立能力 | 生产、专家、敏感命令、审计分别授权 | 一项能力扩大其他范围或绕过总开关 |
| 运行时门禁 | 当前对象、权限、检查、命令和确认共同校验 | 配置页授权等于任务可以直接执行 |

<a id="business-scenarios-6-当前边界"></a>

### 6. 当前边界

本次确认表示权限配置和两个运行时高风险门禁的静态低保真已经通过产品评审，但不表示：

- 身份源、认证协议、初始管理员或管理员恢复流程已经技术定版；
- 权限表、接口、权限编码、缓存失效或服务端校验点已经实现；
- 敏感命令会话时限、临时凭据、密钥保护或审计失败补偿已经确定；
- 二次确认可以替代 P0 受控验证、参数映射、对象权限或任务预检查；
- 可交互原型、高保真 UI 或业务代码开发已经准入。
