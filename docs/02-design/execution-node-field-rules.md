## 1. 目的与边界

将执行节点的列表、注册、环境检查、详情、任务关联和状态化操作落实为可逐项评审的字段规则。本文不定义 Agent 协议、心跳存储、调度算法、数据库表、接口或远程运维能力。

## 2. 通用字段状态

| 状态 | 含义 | 交互处理 |
|---|---|---|
| 已配置 | 管理员维护的平台字段 | 可按权限编辑，变化后相关检查失效 |
| Agent 上报 | 机器或运行事实 | 只读，展示采样时间和来源 |
| 派生 | 由多项节点/任务事实计算 | 只读，必须展示不满足原因 |
| 未取得 | Agent 未上报或检查无法获取 | 显示未取得，不使用猜测值 |
| 已过期 | 证据不再代表当前环境 | 保留最后值和时间，不作为实时事实 |
| 已脱敏 | 主机、路径、日志或注册信息受限 | 按权限展示，不在普通日志泄露 |

## 9. 已确认字段规则

EN-FR01～EN-FR14 已于 2026-07-17 全部确认。确认的是执行节点列表、注册、环境、资源、任务关系与状态化操作的字段语义；Agent 协议、安全认证、阈值和调度实现仍以后续技术设计为准。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| EN-FR01 | 状态表达 | 管理、心跳、环境、容量四维分开，派生一个接收新任务结论 |
| EN-FR02 | 不可用原因 | 结论必须列出全部当前原因，列表只展示首要原因和入口 |
| EN-FR03 | 机器事实 | 主机、OS、Agent、Java、工具版本和资源均以 Agent 上报/检查为准，不允许表单伪造 |
| EN-FR04 | 工具版本 | OBLOADER、OBDUMPER 分别一个活动启动文件并独立检查，不管理多版本库存 |
| EN-FR05 | 环境检查 | 固定只读检查清单，不允许任意命令或环境修改 |
| EN-FR06 | 资源快照 | 只显示当前采样值和时间，无明确硬阈值时不自动阻断或调参 |
| EN-FR07 | 任务容量 | 达到最大并发才派生繁忙；实际生效上限必须显示来源 |
| EN-FR08 | 节点选择 | 三类任务显式选择节点，默认策略最多用于排序/推荐 |
| EN-FR09 | 任务快照 | 节点、工具、目录、配置指纹和检查证据进入不可变任务快照 |
| EN-FR10 | 不自动改派 | 节点不可用时等待任务显示阻断原因，不能静默换节点 |
| EN-FR11 | 运行中失联 | 保留最后可信任务状态并进入核对中，不直接判定失败 |
| EN-FR12 | 状态化操作 | 维护/禁用只阻止新任务，不自动取消运行任务；有引用节点归档而非删除 |
| EN-FR13 | Direct Load 配置 | 节点实际配置只读展示并保存指纹，不在节点或任务页编辑 |
| EN-FR14 | 页面边界 | 列表定位、详情看环境与关联任务、完整日志进日志中心，不增加监控大屏或远程运维 |

## 10. 字段覆盖验收

1. EN-F001～EN-F072 覆盖节点定位、注册、环境、资源、任务关系、状态化操作和审计。
2. 列表不展开 Agent/Java/完整路径等详情字段，详情不重复日志中心的跨时间检索。
3. 节点通用可用性和当前任务适用性明确区分。
4. 任一旧心跳、环境检查或资源值都显示时间，不冒充实时事实。
5. OBLOADER 与 OBDUMPER 可分别正常或异常，不用单一工具状态掩盖差异。
6. 维护、禁用、离线和繁忙不会自动取消、迁移或修改已提交任务。
7. 节点检查不扩展到数据源、对象、任务路径或业务执行可行性。
