## 1. 评审目标

建立一个轻量、可信、可控权限的统一日志查询入口，使用户能够从任务、节点或平台事件出发，快速定位相关日志、查看同一来源上下文、下载脱敏结果，并返回任务详情或节点详情继续排障。

日志中心不重新解释 OBLOADER/OBDUMPER 的执行能力，也不把多个来源的文本强行归并成未经证实的因果链。

## 2. 模块边界

### 2.1 包含

- 按任务、节点、日志域、来源、级别、关键字、时间和用户查询。
- 任务日志、调度日志、Agent 日志、平台操作/审计日志及工具进程输出。
- 分页或游标加载、关键字高亮、同来源上下文查看和按时间持续加载。
- 日志采集状态、最后接收时间、延迟/中断/不完整提示。
- 跳转任务详情、节点详情和对应错误位置。
- 复制脱敏日志、下载受权限控制的脱敏日志结果。
- 查询、下载和敏感范围访问的审计。

### 2.2 不包含

- 全文日志分析平台、复杂查询语言、正则规则引擎或保存查询视图。
- 日志趋势图、聚类、异常检测、告警规则或通知编排。
- AI 根因分析、自动修复、自动生成命令或自动修改任务配置。
- 跨外部系统日志关联、链路追踪或基础设施可观测性平台。
- 日志内容编辑、补写、删除或人工修改日志级别。
- 远程文件浏览、任意节点文件下载或绕过权限读取原始日志文件。
- 日志存储引擎、索引结构、采集协议和归档实现设计。

## 3. 与其他页面的职责边界

| 页面 | 日志职责 | 不承担 |
|---|---|---|
| 任务详情 | 当前任务的实时/历史增量日志、错误定位和完整任务日志下载 | 跨任务查询 |
| 节点详情 | 最近有限节点事件及 Agent 日志入口 | 长时间范围和跨节点检索 |
| 日志中心 | 跨任务、节点和日志域查询；上下文、采集状态、下载与跳转 | 任务配置、节点管理、日志分析和告警 |
| 任务操作记录 | 当前任务内的创建、提交、取消、重试等操作追溯 | 平台全量审计查询 |

从任务详情或节点详情进入日志中心时，携带来源对象和合理时间范围；日志中心返回时不改写来源页面状态。

## 4. 日志分类模型

PRD 同时列出“任务执行日志”和“工具进程标准输出/错误输出”。为避免重复计数，V1.0 分为“查询预设”和“原始来源”两层。

### 4.1 查询预设

| 预设 | 目的 | 默认包含来源 |
|---|---|---|
| 任务日志 | 排查某个任务从调度到工具退出的过程 | 与任务关联的调度、Agent 启动/采集、工具 stdout/stderr 和工具日志文件 |
| 节点 / Agent 日志 | 排查节点关联、心跳、环境检查、启动与采集问题 | Agent 与节点相关平台事件 |
| 调度日志 | 排查任务排队、分配、启动、取消和状态核对 | 调度服务事件和错误 |
| 审计日志 | 查询用户和管理员对产品对象执行的关键操作 | 平台审计事件 |

预设只是过滤器组合，不创建一份新的复制日志，也不覆盖每条记录的真实来源。

### 4.2 原始来源

- 调度服务。
- 执行节点 Agent。
- OBLOADER 标准输出。
- OBLOADER 标准错误。
- OBDUMPER 标准输出。
- OBDUMPER 标准错误。
- OBLOADER / OBDUMPER 工具日志文件。
- 平台审计事件。

只有实际接入并能证明来源的通道才进入筛选候选；未接入通道不显示空壳选项。

### 4.3 任务聚合视图

- 同一任务的多来源日志可按展示时间排序，但每条记录必须保留来源和原始时间。
- 跨机器时钟可能存在偏差，聚合顺序只作为排障辅助，不自动推断事件因果。
- 同一来源存在稳定序号时优先保持原始顺序；无序号时不承诺毫秒级严格顺序。
- 工具日志、stdout 和 stderr 出现重复内容时不自动删除；若能可靠识别重复，可标记而不改写原文。

## 5. 页面结构

日志中心使用一个查询页面，不增加仪表盘或日志详情独立路由：

1. **预设与基础筛选**：任务、节点/Agent、调度、审计；时间、关键字和对象条件。
2. **活动条件摘要**：展示从其他页面带入及用户新增的筛选，可逐项清除。
3. **采集与结果摘要**：结果数量/是否截断、最后接收时间、采集完整性提示。
4. **日志结果区**：日志行、来源、时间、级别、对象上下文和分页/游标。
5. **上下文抽屉**：查看同一来源前后日志、原始/展示时间和关联对象。

V1.0 不提供保存视图、自定义列、查询语句编辑器或多面板日志大屏。

## 6. 查询条件

### 6.1 基础条件

- 时间范围：必填，默认最近 1 小时；从任务/节点跳转时使用来源对象相关时间范围。
- 查询预设：默认任务日志；从节点详情进入时默认节点 / Agent。
- 任务 ID / 名称：任务日志预设的主要入口。
- 节点：节点/Agent 或调度排障入口。
- 关键字：在用户有权访问的脱敏可搜索内容上按普通文本包含查询，不提供正则或复杂语法，也不能用查询结果探测敏感原文。
- 日志级别：只使用来源明确提供或可靠映射的级别。

### 6.2 展开条件

- 任务类型：导出、普通导入、旁路导入。
- 任务状态：用于缩小有权任务集合，不把状态当日志字段伪造。
- 原始来源。
- 用户/操作人：主要用于审计预设；其他预设仅在有可靠关联时生效。
- 事件/操作类型：审计日志使用已登记事件类型。
- 跟踪标识：只有平台已产生可靠 ID 时提供精确查询，不生成新的跨系统 Trace 能力。

### 6.3 查询约束

- 不允许无时间范围的全库查询。
- 关键字为空时可按对象和时间查询。
- 超过产品允许时间跨度或结果上限时，要求缩小范围，不在页面承诺无限结果。
- 精确时间跨度、单次返回上限和查询超时留待技术设计；页面应显示实际限制。
- 筛选候选项和数量只基于用户有权访问的日志集合，不能通过计数泄露无权对象。

## 7. 日志结果

### 7.1 默认字段

| 字段 | 规则 |
|---|---|
| 展示时间 | 按平台时区展示；时间来源在详情可追溯 |
| 日志级别 | 保留来源级别；无级别显示“未标级别”，不推断 |
| 原始来源 | 展示调度、Agent、工具 stdout/stderr、工具日志文件或审计事件等真实通道 |
| 关联对象 | 任务 ID、节点或用户；无可靠关联时不强行填充 |
| 消息摘要 | 默认仅遮蔽秘密，保留已授权记录的非秘密运行上下文；关键字仅高亮、不改写原文 |
| 采集标识 | 记录来自实时采集、历史文件或审计事件；精确名称待技术实现 |

### 7.2 时间语义

- 优先使用来源自身时间，同时保存并展示平台接收时间。
- 来源无可靠时间时使用平台接收时间，并明确标注“接收时间”。
- 任务/节点跨来源聚合不隐藏时钟偏差或时间缺失。
- 结果默认按最新在前；打开同来源上下文时按时间正序展示。

### 7.3 日志级别

- 来源明确提供 TRACE、DEBUG、INFO、WARN、ERROR、FATAL 等级别时原样展示。
- 大小写或同义映射只有在规则已确认时用于筛选，详情保留原值。
- stdout 不自动等于 INFO，stderr 不自动等于 ERROR。
- 无级别记录可用“未标级别”筛选，不从消息文本猜测。

### 7.4 消息展开

- 多行堆栈、异常或工具输出作为一个逻辑记录展示，原始换行保留。
- 默认折叠过长消息，展开后仍在当前结果上下文中。
- 关键字高亮只作用于展示，不改变复制和下载内容。
- 日志中可定位任务、节点、参数或文件时提供跳转/定位，但必须有可靠来源。

## 8. 上下文查看

- 选择一条日志后打开侧边抽屉，展示该条记录和同一原始来源的前后记录。
- “上下文”不混入其他节点或通道的相邻时间记录，避免把时间接近误认为同一调用链。
- 上下文数量采用有限窗口，具体条数由技术设计决定。
- 展示原始来源、来源时间、接收时间、任务/节点关联、级别原值和脱敏状态。
- 可复制当前行或当前上下文的脱敏文本。
- 对可定位错误提供“返回任务详情并定位日志”或“查看节点详情”。

## 9. 实时与持续加载

### 9.1 查询快照

- 普通跨任务/节点查询默认是结果快照，避免新日志持续插入导致用户失去阅读位置。
- 页面提供手动刷新，并显示查询执行时间和结果最新时间。

### 9.2 持续加载

- 只有单一任务、单一节点或明确调度上下文且时间范围包含当前时间时，才提供持续加载。
- 持续加载默认关闭；从运行中任务详情跳转时可保留来源页面的实时意图，但仍清晰显示状态。
- 暂停只停止页面自动追加/滚动，不停止后台采集。
- 恢复后从最后可靠游标继续；无法连续时插入“日志可能不完整”提示，不静默跨越缺口。

### 9.3 连接中断

- 保留已加载日志，不清空结果。
- 展示中断时间、最后接收时间和重新连接/刷新操作。
- 连接恢复不自动宣称缺口已补齐；需要采集证据确认完整性。

## 10. 采集状态与完整性

| 状态 | 含义 | 页面处理 |
|---|---|---|
| 采集中 | 来源仍可能产生新日志 | 显示最后接收时间，可按条件持续加载 |
| 已完成 | 来源已正常结束且采集结束 | 允许历史查询和下载 |
| 延迟 | 最后接收时间落后于可判断的活动状态 | 显示延迟，不据此判定任务失败 |
| 中断 | 采集连接异常，尚不确定是否能补齐 | 保留内容并提供重连/刷新 |
| 不完整 | 已确认存在缺口、截断或源文件缺失 | 显示缺失范围/原因，不伪装完整 |
| 未知 | 无法证明当前采集状态 | 展示最后可信证据和时间 |

- 查询无结果与日志未采集、已过保留期、无权限是不同状态，不能共用“暂无日志”。
- 平台不因日志延迟或缺失直接修改任务终态；任务状态仍按任务中心证据规则核对。
- 结果因查询上限被截断时必须明确显示，并要求缩小条件。

## 11. 下载与复制

### 11.1 下载范围

- 单一任务可下载该任务当前保留范围内的完整脱敏日志。
- 其他查询可下载当前筛选条件下的脱敏结果，但受时间跨度、数量和文件大小限制。
- 超出限制时要求缩小查询，不在 V1.0 引入异步日志导出任务或下载中心。
- 下载文件包含筛选条件、生成时间、平台时区、脱敏声明、日志来源和采集完整性说明。

### 11.2 敏感信息

- 页面、复制和下载统一使用“秘密遮蔽、非秘密运行上下文保留”的内容，避免三套不同安全语义。
- V1.0 不提供“下载未脱敏原始日志”入口；原始源文件访问不属于日志中心能力。
- 密码、存储密钥、临时凭据和敏感命令片段即使误入来源日志也必须在展示/导出前脱敏。
- 经人工确认，已授权任务日志中的连接、对象、路径、非密码命令令牌和工具原始诊断属于可见运行上下文；该确认不允许读取原始节点文件或未授权对象。
- 脱敏不能导致用户误以为日志原文就是星号；页面和下载标记“已脱敏”。

### 11.3 审计

- 下载日志、查询审计日志、访问高敏环境日志和复制大段日志等关键行为记录审计。
- 审计事件保存筛选摘要、结果范围和操作者，不复制完整日志内容进入审计日志。

## 12. 权限模型

| 日志范围 | 默认权限 |
|---|---|
| 任务日志 | 继承任务查看权限；普通用户只能查看自己或被授权任务 |
| 节点 / Agent 日志 | 节点管理员或运维人员按授权节点范围查看；系统管理员需另有节点能力 |
| 调度日志 | 运维人员或独立调度日志能力；普通用户只通过自己的任务上下文查看必要调度事件 |
| 审计日志 | 系统管理员的审计能力或独立审计能力；任务详情操作记录仍按任务权限查看 |

- 无权记录不出现在结果、数量、筛选候选、上下文或下载中。
- 从任务/节点页面跳转不扩大权限，日志中心必须重新校验。
- 用户筛选主要服务审计；不可借用户条件枚举无权用户或操作。

## 13. 保留与删除边界

- 日志保留期由系统设置管理；审计日志可使用独立保留策略。
- 日志中心展示当前可查询时间范围或最早可用时间，不能承诺已过期内容可恢复。
- V1.0 不提供单条、按任务或按节点手工删除日志。
- 任务、节点或数据源归档/删除不破坏保留期内日志的历史标识和快照关联。
- 保留期变更的生效范围、归档和物理清理方式留待技术设计。

## 14. 页面状态与异常

| 场景 | 页面处理 |
|---|---|
| 首次从导航进入 | 初始化最近 1 小时和任务日志预设，但不自动执行无对象的宽范围查询 |
| 从任务/节点进入 | 使用有权对象和相关时间范围自动查询；无权限时不展示存在性 |
| 查询中 | 保留旧结果并显示加载状态，避免闪空 |
| 查询无匹配 | 展示当前条件和清除/调整入口 |
| 日志未采集 | 说明来源尚无采集证据，不显示普通空状态 |
| 已过保留期 | 说明可查询范围和保留策略入口（有权限时） |
| 查询超时/失败 | 保留条件，展示可追踪错误，不给出未经验证修复建议 |
| 结果被截断 | 显示上限和缩小时间/条件建议 |
| 权限不足 | 不展示记录摘要或存在性；提供权限说明 |
| 下载失败 | 保留查询和下载条件，支持重试并记录失败审计结果 |

| LC-C14 | 普通跨对象查询 | 使用快照和手动刷新，不自动滚动 | 阅读稳定性 |
| LC-C15 | 下载日志 | 生成脱敏结果并记录审计 | TC-F079 / PRD 12.9 |
| LC-C16 | 下载范围过大 | 要求缩小条件，不创建异步导出中心 | V1.0 轻量边界 |
| LC-C17 | 日志已过保留期 | 展示可用范围，不承诺恢复 | 系统设置边界 |
| LC-C18 | 日志中存在可定位错误 | 查看同来源上下文并可回任务详情定位 | PRD 12.7 |

## 16. 安全与审计

- 所有日志在展示、复制和下载前经过统一秘密脱敏处理，并保留已确认的非秘密运行上下文。
- 关键字查询和高亮使用有权脱敏内容，不能通过命中数量、候选或错误信息侧信道探测敏感原文。
- 日志查询接口和筛选候选都应用对象权限，不能只在前端隐藏。
- 审计日志本身不记录密码、完整日志正文或可恢复敏感值。
- 查询审计日志、下载日志和高敏环境访问记录操作者、时间、条件摘要和结果。
- 日志消息不可包含可执行链接、脚本或未经转义的富文本；默认按纯文本展示。

## 17. 验收基线

1. 用户可按任务、节点、日志预设、来源、级别、关键字和时间查询有权日志。
2. 任务详情和节点详情跳转可带入上下文，且不扩大权限。
3. 任务日志预设不会复制或丢失真实来源，stdout/stderr 与工具日志仍可区分。
4. 无级别、无来源时间或跨机器时钟偏差不会被界面伪造为确定事实。
5. 上下文只取同一原始来源，不把时间相近记录冒充调用链。
6. 实时中断、延迟、缺口、截断和未知状态都有明确提示。
7. 页面、复制和下载使用同一“秘密遮蔽、运行上下文保留”语义，V1.0 不开放未脱敏原始日志下载。
8. 普通用户不能通过数量、筛选候选或下载发现无权任务/节点日志。
9. 日志中心不提供复杂查询语言、趋势、告警、聚类、AI 诊断或自动修复。
10. 已过保留期、未采集、无匹配和无权限使用不同结果状态。

| LC-F073 | 查询失败/超时 | 查询异常 | 保留条件，显示可追踪标识和重试 |
| LC-F074 | 结果已截断 | 达到查询上限 | 保留已加载结果并要求缩小条件 |
| LC-F075 | 下载失败 | 下载异常 | 保留下载范围，允许重试并记录失败结果 |

<a id="field-rules-10-已确认字段规则"></a>

### 10. 已确认字段规则

LC-FR01～LC-FR15 已于 2026-07-17 全部确认。确认的是日志预设、筛选、结果、上下文、持续加载、完整性、权限、下载、保留和安全展示的字段语义；采集协议、存储/索引、游标和具体限制值仍以后续技术设计为准。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| LC-FR01 | 分类与来源 | 四个查询预设只组合过滤，每条记录始终保留真实来源 |
| LC-FR02 | 时间范围 | 查询时间必填，默认最近 1 小时；来源跳转覆盖默认范围 |
| LC-FR03 | 文本查询 | 只支持普通文本包含与高亮，不提供正则、查询 DSL 或保存视图 |
| LC-FR04 | 时间与级别 | 保留来源/接收时间和级别原值；无级别、无来源时间均不推断 |
| LC-FR05 | 结果排序 | 默认最新在前；同来源上下文正序；跨来源不承诺因果顺序 |
| LC-FR06 | 上下文 | 只取同一原始来源的有限前后记录，不混入其他通道 |
| LC-FR07 | 持续加载 | 跨对象查询使用快照；仅单一活动对象可持续加载，暂停不停止采集 |
| LC-FR08 | 完整性 | 延迟、中断、缺口、截断和未知显式展示，不把未采集等同零结果 |
| LC-FR09 | 权限 | 任务、节点、调度、审计按对象/角色授权，数量、候选和下载同样过滤 |
| LC-FR10 | 脱敏 | 页面、复制、上下文和下载使用同一“秘密遮蔽、非秘密运行上下文保留”语义并标记已脱敏 |
| LC-FR11 | 下载 | 单任务完整日志或当前过滤结果可下载；超限收窄，不建异步下载中心 |
| LC-FR12 | 原始日志 | V1.0 不提供未脱敏原始日志下载或任意节点日志文件访问 |
| LC-FR13 | 保留 | 保留期归系统设置，日志中心不提供手工删除，历史关联在保留期内不被改写 |
| LC-FR14 | 页面边界 | 任务详情看单任务实时日志，节点详情看最近事件，日志中心做跨对象查询 |
| LC-FR15 | 安全展示 | 日志按纯文本转义，不执行消息中的链接、脚本或富文本 |

<a id="field-rules-11-字段覆盖验收"></a>

### 11. 字段覆盖验收

1. LC-F001～LC-F075 覆盖预设、筛选、结果、上下文、持续加载、完整性、下载、权限和异常。
2. 任务执行日志与工具 stdout/stderr 不重复建模，真实来源始终可追溯。
3. 无权限记录不进入数量、候选、上下文和下载。
4. 来源时间、接收时间、日志级别和顺序不由界面推测。
5. 实时连接中断、日志未采集、无匹配、已过保留期和权限不足使用不同状态。
6. 页面、复制和下载保持统一的秘密遮蔽与运行上下文保留边界，V1.0 不存在原始日志旁路。
7. 日志中心不引入趋势图、告警、AI 诊断、正则规则或自动修复。

<a id="business-scenarios-1-评审目标"></a>

### 1. 评审目标

本文将日志中心的统一查询、真实来源、同来源上下文、采集完整性、持续加载、权限和脱敏下载落实为静态低保真，覆盖用户从选择查询预设到定位日志、判断结果是否完整、查看上下文和下载结果的最小闭环。

设计目标是在单一查询页面内承载任务、节点/Agent、调度和审计四类预设，同时避免把预设名称误作真实日志来源、把时间接近误作因果关系、把连接恢复误作历史缺口已经补齐，或把日志中心扩展为日志分析与告警平台。

本稿不是日志采集协议、存储索引、查询引擎、告警平台或 AI 诊断设计。图片中的日志、任务、节点、时间、版本和数量均用于表达布局；实际事实以采集证据、权限规则、技术设计和受控验证结果为准。

<a id="business-scenarios-2-最小页面集"></a>

### 2. 最小页面集

本轮使用六张页面覆盖日志中心主链路与关键状态：

| 能力 | 页面 | 说明 |
|---|---|---|
| 首次进入与查询预设 | LC-LF-01 | 验证四类预设、默认最近一小时、不自动宽查、权限范围和空状态区分 |
| 任务日志聚合查询 | LC-LF-02 | 验证任务相关多来源日志聚合、真实来源、双时间、原始级别和关键字高亮 |
| 审计日志查询 | LC-LF-03 | 验证独立审计权限、受限候选、条件摘要和敏感访问审计边界 |
| 同来源上下文 | LC-LF-04 | 验证有限前后窗口、来源一致、时间差异、脱敏复制和对象跳转 |
| 持续加载与日志缺口 | LC-LF-05 | 验证单对象持续加载、暂停追加、连接恢复、历史缺口和采集完整性 |
| 脱敏日志下载 | LC-LF-06 | 验证下载范围、来源、数量、截断、采集状态、脱敏声明和审计记录 |

V1.0 使用一个日志查询页面和一个同来源上下文抽屉，不新增日志仪表盘、查询编辑器、保存视图、异步导出中心或独立日志详情路由。

<a id="business-scenarios-3-页面基线"></a>

### 3. 业务场景

<a id="business-scenarios-lc-lf-01-首次进入与四类预设"></a>

#### LC-LF-01 首次进入与四类预设


- 页头提供任务、节点/Agent、调度和审计四类查询预设，预设只改变筛选组合；
- 从导航进入时初始化任务日志和最近一小时，但不自动执行宽范围查询或展示虚构日志；
- 时间范围必填，任务、节点、用户等候选与结果数量均受当前权限限制；
- 关键字只支持有权脱敏文本的普通包含和高亮；
- 无匹配、未采集、已过保留期和权限不足分别说明，不合并成统一空状态；
- 页面不增加趋势、告警、聚类、复杂查询或保存视图。

<a id="business-scenarios-lc-lf-02-任务日志聚合查询"></a>

#### LC-LF-02 任务日志聚合查询


- 任务预设聚合调度服务、Agent、OBDUMPER stdout/stderr 和工具日志等任务相关来源；
- 每条记录保留原始来源、关联对象、阶段/事件、来源时间或接收时间及采集标识；
- stdout、stderr 和消息文本不用于推断日志级别，无可靠级别时显示未标级别；
- 来源时间和平台接收时间分开保留，跨来源按展示规则排序但不承诺因果顺序；
- 查询结果使用快照，保留条件摘要、查询时间、已加载数量、最后来源时间、最后接收时间和采集状态；
- 查看上下文、手动刷新和下载均基于当前有权结果，不改变查询范围。

<a id="business-scenarios-lc-lf-03-审计日志查询"></a>

#### LC-LF-03 审计日志查询


- 审计日志使用独立访问能力，不能仅凭系统管理员角色自动获得；
- 操作人、事件类型、对象、环境和候选集合按权限过滤，不能枚举无权对象；
- 查询、下载及高敏环境访问记录操作者、时间、条件范围和结果摘要；
- 审计记录不复制日志正文、密码、密钥、Token 或可恢复敏感值；
- 结果以纯文本摘要展示，关联对象和上下文跳转时重新校验权限；
- 不增加行为画像、风险评分、审批流或安全告警中心。

<a id="business-scenarios-lc-lf-04-同来源上下文"></a>

#### LC-LF-04 同来源上下文


- 上下文通过右侧抽屉展示当前记录和同一原始来源的有限前后窗口；
- 上下文明确来源、窗口大小、来源序号以及是否因技术限制截断；
- 不混入时间相近的调度、Agent、stdout、stderr 或工具文件记录制造伪调用链；
- 来源时间和接收时间同时可得时展示差异，但不自动判定时钟故障；
- 复制当前行和复制上下文均使用页面同一脱敏语义；
- 跳转任务或节点详情时携带定位上下文，并重新执行对象权限校验。

<a id="business-scenarios-lc-lf-05-持续加载与日志缺口"></a>

#### LC-LF-05 持续加载与日志缺口


- 持续加载只在单一活动对象且查询时间包含当前时提供，默认关闭；
- 暂停追加只停止页面自动追加和滚动，不停止后台采集；
- 页面分开展示实时连接状态、采集状态、最近中断、最后接收时间和已加载数量；
- 中断时保留已加载记录，恢复后继续接收，但不能因此宣称历史缺口已经补齐；
- 已确认缺口以范围和状态显式插入结果流，后续新日志不得覆盖或隐藏缺口；
- 采集延迟、中断、不完整和未知不直接改变关联任务的执行状态。

<a id="business-scenarios-lc-lf-06-脱敏日志下载确认"></a>

#### LC-LF-06 脱敏日志下载确认


- 下载前确认预设、对象、时间、关键字、来源、预计数量、截断和采集完整性；
- 下载内容与页面和复制使用相同脱敏语义，不提供未脱敏原始日志；
- 文件包含查询条件、生成时间、平台时区、来源和完整性说明；
- 采集中时只下载生成时刻之前已经接收的日志，不承诺包含任务后续日志；
- 超过下载限制时要求缩小查询范围，不创建异步导出任务或导出中心；
- 下载成功或失败均记录不含正文和敏感值的审计元数据。

<a id="business-scenarios-4-状态与证据表达"></a>

### 4. 状态与证据表达

| 维度 | 页面表达 | 禁止推断 |
|---|---|---|
| 查询预设 | 任务、节点/Agent、调度、审计 | 预设名称等于真实来源 |
| 来源 | 调度、Agent、stdout/stderr、工具文件、审计等 | 时间接近即存在调用关系 |
| 时间 | 来源时间、平台接收时间、查询快照时间 | 时间差自动代表节点时钟故障 |
| 级别 | 来源原值或未标级别 | stdout 等于 INFO、stderr 等于 ERROR |
| 连接 | 已连接、重连中、中断、恢复 | 连接恢复等于历史日志完整 |
| 采集 | 采集中、已完成、延迟、中断、不完整、未知 | 采集异常直接改变任务终态 |
| 结果 | 无匹配、未采集、已过期、无权限、已截断 | 所有无结果状态含义相同 |
| 安全 | 已授权、已脱敏、访问留痕 | 审计权限允许查看未脱敏原文 |

### 6. 当前边界

本次确认表示日志中心静态低保真已经通过产品评审，但不表示：

- Agent、调度器和工具日志的采集协议、认证、重连或可靠游标已经技术定版；
- 来源序号、日志缺口证明、跨来源排序、去重标记或时钟偏差处理已经实现；
- 单次查询跨度、结果上限、上下文窗口、查询超时或下载大小已经确定；
- 日志存储、全文索引、保留清理、审计独立保留或权限编码已经完成设计；
- 日志示例、任务 ID、节点、时间、数量或工具输出构成真实运行证据；
- 可交互原型、高保真 UI、日志分析平台、技术设计或业务代码开发已经准入。
