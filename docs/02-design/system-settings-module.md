## 1. 评审目标

建立轻量、可解释的系统级配置入口，统一平台基础默认值、调度约束、安全策略和工具兼容基线，同时保证这些设置不会变成第二套任务参数、节点配置或权限管理系统。

系统设置负责“平台如何提供和约束能力”，具体数据源、执行节点、任务和模板仍在各自模块管理。

## 2. 模块边界

### 2.1 包含

- 平台基础设置：平台名称、默认时区、默认语言、任务/日志保留天数、页面分页大小和任务名称规则。
- 调度设置：新节点默认最大并发、全平台最大并发、节点心跳超时、任务启动超时、调度轮询间隔和默认节点候选策略。
- 安全设置：敏感信息脱敏基线、密码加密密钥配置状态、敏感命令查看能力、生产任务二次确认和审计日志保留策略。
- 工具设置：支持的工具版本范围、默认目标版本、参数元数据版本和版本变化后的重新校验策略。
- 当前生效值、来源、更新时间、修改差异、影响范围和审计摘要。
- 按设置分区独立编辑、校验、确认和保存。

### 2.2 不包含

- OBDUMPER、OBLOADER 或 Direct Load 的任务参数及其默认值。
- 数据源环境枚举、连接信息、凭据或连接测试规则。
- 节点上的工具路径、Java、工作目录、`session.config`、资源事实或 Agent 配置。
- 任务级数据源、节点、路径、对象、格式、参数和风险确认。
- 用户、角色、组织、权限授予和审批流的完整管理界面。
- 任意正则脚本、表达式、配置脚本、动态策略代码或自定义调度算法。
- 配置中心、灰度发布、多租户/多环境配置覆盖、配置继承或配置版本分支。
- 工具安装、下载、升级、自动切换、远程运维或参数元数据在线编辑。
- 手工清理任务、日志或审计记录；这里只配置保留策略。

## 3. 轻量化设计原则

1. **平台设置不是任务参数**：系统设置不得向完整命令静默注入官方工具参数。
2. **实际值有来源**：所有设置展示当前生效值及其来源，避免页面值与部署配置不一致。
3. **分区保存**：基础、调度、安全和工具设置分别保存，避免一次修改携带无关字段。
4. **先看影响再生效**：降低保留期、并发或超时，以及修改安全和工具基线时，必须展示差异与影响。
5. **历史快照不回写**：已提交任务和已创建草稿/模板按各自快照与重新校验规则处理，不被静默改写。
6. **安全能力不可被弱化绕过**：内置脱敏和敏感操作审计不能通过普通配置关闭。
7. **没有证据就不承诺自动化**：清理时间、调度算法、工具兼容和密钥轮换等技术行为未定版时明确标记，不用界面文案代替实现证据。

## 4. 页面信息架构

系统设置使用一个管理员页面和四个分区，不增加设置首页或多级配置树：

```text
系统设置
├── 平台基础
├── 调度
├── 安全
└── 工具与兼容
```

- 每个分区显示说明、当前生效值、来源、最近修改和独立的编辑/保存操作。
- 页面默认进入“平台基础”；离开有未保存修改的分区时提示保存或放弃。
- V1.0 不提供全局搜索、配置导入/导出、批量修改、配置历史回滚或草稿发布。
- 只有系统管理员的系统设置管理能力可以编辑；其他角色不因运维、节点或数据源职责自动获得只读权限，另行授予系统设置只读能力时才可进入。

## 5. 平台基础设置

| 设置 | 产品语义 | 生效边界 |
|---|---|---|
| 平台名称 | 页面标题和产品标识文本 | 不影响工具命令和历史任务 |
| 默认时区 | 无个人偏好时的页面时间展示时区 | 不改写来源时间、UTC 存储值或历史日志 |
| 默认语言 | 无个人偏好时的默认界面语言 | V1.0 不在本模块新增个人偏好中心 |
| 任务默认保留天数 | 任务及其平台侧历史数据的默认保留策略 | 精确清理对象、时间和可恢复性待技术设计 |
| 日志默认保留天数 | 非审计日志的默认可查询保留策略 | 日志中心不提供手工删除 |
| 页面分页大小 | 列表首次加载的默认每页数量 | 用户临时切换只影响当前列表会话 |
| 任务名称规则 | 三类任务名称的统一平台校验规则 | 不进入工具命令；精确规则模型待确认 |

### 5.1 时区与语言

- 默认时区只控制展示和用户输入时间的解释；日志来源时间、平台接收时间和任务快照仍保存原始时间语义。
- 默认语言只决定初始界面语言，不翻译工具原始错误、参数名或完整命令。
- 修改时区或语言不批量改写历史数据。

### 5.2 保留策略

- 任务、普通日志和审计日志分别配置，不能用一个值互相覆盖。
- 降低保留天数属于高影响操作，保存前展示旧值、新值和可能影响的数据范围。
- 页面不得承诺立即删除、可恢复或自动归档；物理清理时间、最小保留值、关联附件和失败任务证据的处理统一留待技术设计。
- 已过保留期、无权限、未采集和查询无结果继续保持不同语义。

### 5.3 任务名称规则

- 三类任务共用同一平台规则，任务类型不另建一套命名规则。
- 校验作用于新建和编辑草稿，不回写历史任务名称。
- V1.0 只支持结构化规则，不提供任意正则或脚本；允许字符、长度、是否要求前缀等精确字段待本模块字段评审后定版。

## 6. 调度设置

### 6.1 并发

- “单节点最大并发任务数”在系统设置中定义为**新节点默认值**；节点创建后，实际值仍在执行节点页面维护并进入任务/节点快照。
- 修改新节点默认值不批量覆盖已有节点。
- “全平台最大并发任务数”是平台调度硬上限；达到上限时新任务保持等待调度并显示原因。
- 降低全平台上限不会自动取消正在运行的任务；若当前运行数已经高于新上限，只阻止新增启动，直至低于上限。
- 单节点实际上限和全平台上限都不根据 CPU、内存或磁盘自动调整。

### 6.2 心跳、启动与轮询

- 节点心跳超时用于派生节点离线/失联，不删除节点，也不直接把运行任务判为失败。
- 任务启动超时用于识别启动异常并进入状态核对；最终任务状态仍必须依据调度、Agent 和工具进程证据确定。
- 调度轮询间隔只影响平台检查等待任务的频率，不作为任务参数展示。
- 三项具体数值、单位、允许范围和修改后生效时点待技术设计；产品页面不得硬编码未经验证的默认值。

### 6.3 默认节点候选策略

- V1.0 默认保持用户在三类任务向导中显式选择节点。
- 系统策略最多改变候选排序或展示推荐说明，不能静默选中、提交或改派节点。
- 策略必须只使用已确认的节点管理状态、心跳状态、环境状态、容量状态和可选节点组标签。
- 精确策略枚举和排序算法待调度设计确认；无法解释推荐原因时不展示推荐结论。

## 7. 安全设置

### 7.1 脱敏基线

- 密码、密钥、token、敏感连接串和命令敏感片段使用平台内置脱敏基线。
- 内置基线不可通过系统设置关闭；可扩展的敏感字段关键字或规则语法待安全设计确认。
- 页面、复制、下载、错误、日志和审计使用一致的脱敏语义。
- 系统设置页面不得展示可恢复的敏感原文。

### 7.2 密码加密密钥

- 页面只展示配置状态、不可逆标识/指纹、来源摘要和最后确认时间，不展示、复制或下载密钥材料。
- 密钥生成、注入、轮换、备份和恢复机制属于安全技术设计，不能用普通文本输入框替代。
- 修改密钥相关配置属于最高风险操作，需要明确权限、二次确认和审计；是否需要重加密既有凭据待技术设计。

### 7.3 敏感命令与生产任务

- “允许查看敏感命令”是平台能力总开关，默认关闭；即使开启，用户仍需单独权限并触发二次确认和审计。
- 关闭能力不影响默认脱敏命令查看和复制。
- 生产任务二次确认是任务提交前的风险确认，不等于审批流；V1.0 不因该设置新增审批中心。
- 生产环境仍由数据源环境标识和任务权限共同判断，系统设置不能把普通数据源临时改成生产或绕过权限。

### 7.4 审计日志保留

- 审计日志保留策略与普通日志独立。
- 降低审计保留期需要高风险确认并记录操作本身；具体最低期限和合规要求待部署环境确认。
- 系统设置不提供单条或批量删除审计日志的操作。

## 8. 工具与兼容设置

### 8.1 支持版本与默认目标版本

- OBDUMPER 和 OBLOADER 分别维护平台支持版本范围及默认目标版本。
- 默认目标版本必须属于支持范围，并存在可用的参数元数据。
- 默认目标版本只作为新任务/模板的初始目标，不代表任一节点已安装该版本，也不自动切换节点工具。
- 节点工具路径和实际版本继续在执行节点管理；任务提交必须匹配所选节点的实际环境。

### 8.2 参数元数据版本

- 参数元数据是三类任务字段、显示条件、互斥依赖、命令生成和模板兼容校验的产品基线，不在系统设置中逐项编辑。
- 页面只允许选择或激活已经受控发布的元数据版本；元数据包的制作、签名、上传和发布机制待技术设计。
- 切换元数据版本前展示受影响的工具、任务类型、草稿和模板范围。
- 已提交任务保留原元数据版本和命令快照，不回写。

### 8.3 版本变化后的重新校验

V1.0 使用一套固定的安全策略，不提供可绕过校验的多策略开关：

- 新建任务和模板使用当前默认目标版本与活动元数据。
- 已有草稿再次编辑或提交时按当前目标版本重新校验。
- 模板显示兼容差异，遇到不支持或未知字段时阻断使用。
- 已提交任务和历史快照不修改；基于历史任务新建时按当前版本重新校验。
- 工具升级不自动安装、切换节点版本、迁移模板或重跑任务。

## 9. 编辑、校验与保存

```text
进入设置分区
→ 查看当前生效值、来源和更新时间
→ 进入编辑
→ 修改字段并完成即时校验
→ 查看旧值、新值和影响范围
→ 高影响项二次确认
→ 保存分区
→ 展示生效结果并记录审计
```

- 每个分区只有一个主操作“保存设置”；未进入编辑时不显示空保存按钮。
- 保存请求包含当前配置版本；检测到他人已修改时阻断覆盖并要求刷新比较。
- 字段错误定位到具体设置；分区保存失败不改变原生效值。
- 保存成功显示实际生效状态；若技术上需要延迟生效或重启，只能在有真实证据时展示，不能预先假定。
- 降低保留期、降低并发/超时、弱化安全能力、修改密钥配置、工具支持范围、默认版本或元数据版本均进入高影响确认。
- 所有修改记录操作人、时间、分区、变更前后摘要、结果和审计事件标识；敏感值不进入摘要。

## 10. 生效范围

| 设置类型 | 保存后的作用对象 | 不得发生 |
|---|---|---|
| 展示默认 | 后续页面展示和无个人偏好的会话 | 改写来源时间或历史快照 |
| 新建默认 | 新建节点、任务或模板的初始选择 | 批量覆盖已有对象 |
| 调度硬约束 | 保存后新的调度决策 | 自动取消运行任务或静默改派 |
| 安全策略 | 保存后的查看、复制、下载和提交操作 | 绕过对象权限或取消审计 |
| 工具/元数据基线 | 新建及重新编辑/提交对象 | 改写已提交任务和历史命令 |
| 保留策略 | 满足清理条件的数据 | 页面承诺未经设计的立即删除或恢复 |

## 11. 权限与审计

- 编辑系统设置只对系统设置管理权限开放，不因用户是节点管理员、数据源管理员或运维人员而自动获得。
- 系统管理员默认可查看系统设置；其他角色需要另行授予系统设置只读能力。敏感密钥材料任何角色都不可在页面查看。
- 保存、失败保存、高影响确认、敏感命令能力变化、密钥配置变化和工具基线变化记录审计。
- 系统设置页面的候选值、差异和审计摘要也按权限过滤，不通过错误提示泄露敏感配置。

## 12. 页面状态

| 状态 | 页面处理 |
|---|---|
| 加载中 | 保留分区结构，字段使用加载状态，不显示虚假默认值 |
| 无权限 | 不展示设置值，说明需要系统设置权限 |
| 配置读取失败 | 保留页面和重试入口，不允许基于未知旧值编辑 |
| 编辑中 | 显示未保存标识，离开分区或页面时确认 |
| 校验失败 | 定位字段并保留用户输入，不提交部分字段 |
| 并发修改冲突 | 展示当前版本已变化，要求刷新后重新比较 |
| 保存中 | 禁止重复提交，保留差异摘要 |
| 保存失败 | 原生效值不变，显示错误和追踪标识 |
| 保存成功 | 显示新生效值、来源、时间和审计标识 |
| 依赖不可用 | 工具元数据、密钥状态等无法核实时阻断相关保存，不默认通过 |

## 14. 验收基线

1. 系统设置只包含平台基础、调度、安全和工具兼容四个分区。
2. 页面不会出现三类任务参数、数据源凭据或节点工具路径编辑入口。
3. 每个设置显示当前生效值、来源和更新时间，分区独立保存。
4. 已提交任务和历史命令不会被设置变化回写。
5. 新节点默认并发与节点实际并发清晰分离，全平台并发是独立硬上限。
6. 节点心跳或任务启动超时不会在无进程证据时直接把任务标记失败。
7. 默认节点策略不自动选中、提交或改派节点。
8. 内置脱敏不可关闭，敏感命令即使开放仍需权限、确认和审计。
9. 密钥材料不在页面显示、复制或下载。
10. 工具默认版本必须位于支持范围且存在参数元数据，不自动安装或切换节点工具。
11. 元数据变化重新校验草稿和模板，但不改写历史任务。
12. V1.0 不建设配置发布、继承、环境覆盖、历史回滚、脚本策略或审批中心。

| SS-F070 | 审计事件 ID | 审计 | 保存成功/失败且有记录 | 有权限时可复制或跳转日志中心 |

### 9. 页面状态与异常

| ID | 状态 | 触发条件 | 页面规则 |

<a id="field-rules-11-字段覆盖验收"></a>

### 11. 字段覆盖验收

1. SS-F001～SS-F080 覆盖四个设置分区、编辑保存、影响比较、权限和异常。
2. 平台设置不会承载三类任务参数、数据源连接或节点环境字段。
3. 新建默认、调度硬约束、安全策略和历史快照具有不同生效边界。
4. 降低保留期、并发或超时以及修改安全/工具基线都有明确影响提示。
5. 密钥和敏感配置不会以明文进入页面、差异或审计摘要。
6. 工具版本和参数元数据变化不会自动安装工具、迁移模板或修改历史任务。
7. 未确认的数值范围、调度算法、扩展脱敏和密钥流程保持待设计状态。
8. V1.0 不引入配置发布、导入导出、环境覆盖、继承、回滚、脚本或审批中心。

<a id="business-scenarios-1-评审目标"></a>

### 1. 评审目标

本文将系统设置的真实生效值、来源、分区编辑、影响比较、高风险确认、原子保存和并发冲突落实为静态低保真，覆盖管理员从查看当前配置到修改一个设置分区、核对影响并完成受控保存的最小闭环。

设计目标是让用户清楚区分平台展示默认、新建对象默认、调度硬约束、安全策略、工具与参数元数据基线，以及它们对历史任务、现有节点、草稿和模板的不同影响；同时避免系统设置演变为第二套任务参数、配置发布或远程运维平台。

本稿不是配置存储、调度算法、密钥系统、清理作业、元数据发布或权限编码技术设计。图片中的天数、并发数、超时、对象数量、配置版本和时间仅用于表达布局，不构成部署默认值或实现承诺。

<a id="business-scenarios-3-页面基线"></a>

### 3. 业务场景

<a id="business-scenarios-ss-lf-01-平台基础与真实生效值"></a>

#### SS-LF-01 平台基础与真实生效值


- 页面默认进入平台基础分区，其他三个分区使用相同页面骨架；
- 每项展示当前生效值、实际来源、最近修改时间和生效状态，未知时不显示猜测默认；
- 时区只影响时间展示和输入解释，语言只影响初始界面，分页只影响列表初次加载；
- 任务名称结构化规则只作用于新建或编辑草稿，不进入工具命令；
- 任务、普通日志和审计日志保留策略相互独立；
- 未编辑时只有一个“编辑设置”入口，不显示无意义的空保存按钮。

<a id="business-scenarios-ss-lf-02-降低保留期确认"></a>

#### SS-LF-02 降低保留期确认


- 降低任务或普通日志保留期属于高影响操作，保存前展示旧值、新值和当前可核对影响；
- 已知对象数量或数据量带统计时间，无法可靠计算时显示未知；
- 物理清理时间、清理后恢复和归档能力未定版时明确标注“待技术设计”；
- 保存不承诺立即删除、自动归档或可恢复，也不提供手工清理入口；
- 审计日志保留独立，不随平台基础分区的普通日志策略一起变更；
- 高影响确认要求核对差异、影响和未确定事项，并填写不含敏感值的修改原因。

<a id="business-scenarios-ss-lf-03-调度设置与并发影响"></a>

#### SS-LF-03 调度设置与并发影响


- 新节点默认最大并发只预填后续创建节点，不覆盖已有节点实际设置；
- 全平台最大并发是新调度决策的硬上限，并与当前运行任务数分开展示；
- 新上限低于当前运行数时不取消运行任务，只阻止新增启动直至运行数降到上限以下；
- 节点心跳超时只派生失联，任务启动超时只触发状态核对，调度轮询只影响等待任务检查频率；
- 超时和轮询的单位、合法范围与生效时点尚未技术定版时不在页面伪造约束；
- 默认节点策略保持用户显式选择，不静默选中、提交、改派或依据资源采样自动调整并发。

<a id="business-scenarios-ss-lf-04-安全设置"></a>

#### SS-LF-04 安全设置


- 内置脱敏基线始终启用且不可关闭，页面、复制、下载、错误、日志和审计使用相同语义；
- 扩展脱敏规则在安全设计确认前保持不可配置，不提供正则或脚本编辑器；
- 密钥只展示配置状态、来源类型、不可逆标识和最后确认时间；
- 页面不接收、显示、复制或下载密钥材料，也不以普通表单代替生成和轮换流程；
- 敏感命令总开关默认关闭；开启不授予任何用户权限，仍需对象权限、独立能力、二次确认和审计；
- 生产任务二次确认只是提交前风险确认，不建设审批流；审计日志不提供手工删除。

<a id="business-scenarios-ss-lf-05-工具与兼容设置"></a>

#### SS-LF-05 工具与兼容设置


- OBDUMPER 与 OBLOADER 分别展示平台支持范围、默认目标版本和活动参数元数据；
- 平台默认目标与执行节点实际安装版本分开展示，默认目标不证明任何节点已安装该版本；
- OBLOADER 元数据同时服务普通导入和旁路导入，但两个模块继续保留独立参数适用状态；
- 只允许选择已经受控发布的元数据版本，不提供上传、在线编辑或任意参数修改；
- 元数据变化使新建和重新编辑的草稿重新校验，使模板重新计算兼容状态；
- 已提交任务和命令快照保持不变，页面不安装、升级、切换节点工具或自动迁移模板。

<a id="business-scenarios-ss-lf-06-配置版本冲突"></a>

#### SS-LF-06 配置版本冲突


- 编辑开始时记录配置版本，保存时发现版本变化立即阻断覆盖；
- 冲突页区分用户编辑值、当前最新生效值、同字段冲突和他人修改；
- 冲突时当前生效配置和运行任务保持不变，不发生部分保存；
- 页面不自动合并、强制覆盖或拆分提交无冲突字段；
- 返回只能查看本次输入，旧版本不能继续提交；刷新后重新读取并比较；
- 保存失败记录分区、版本冲突、操作者、结果和审计事件 ID，不记录敏感值。

<a id="business-scenarios-4-生效范围与禁止推断"></a>

### 4. 生效范围与禁止推断

| 设置类型 | 页面表达 | 禁止推断 |
|---|---|---|
