## 1. 评审目标

让用户进入平台后，在一个页面内快速判断授权范围内是否存在运行、等待、失败或节点异常，并能进入任务中心、任务详情、执行节点或日志中心继续处理。

首页是状态入口，不是任务管理、监控分析或告警处置平台。

## 2. 已确认基线

- 首页关注执行节点，不监控调度平台所在服务器资源，见 DEC-005。
- 首页保持克制，只保留一张主要任务趋势图和必要状态摘要，见 DEC-006。
- 首页看状态、列表做管理、详情做分析；不在首页展开参数、命令和完整日志。
- 任务状态、阶段、进度和结果采用任务中心已确认语义，不建立首页专属状态。
- 节点状态复用管理、心跳、环境、容量四维事实以及“接收新任务”派生结论。
- 所有统计、候选和跳转都基于当前用户权限，不通过数字泄露无权对象。

## 3. 模块边界

### 3.1 包含

- 授权范围说明、数据更新时间和运行状态自然语言摘要。
- 运行中、等待调度、今日成功、今日失败四张核心指标卡。
- 一张任务结果趋势图。
- 执行节点健康摘要。
- 当前登录用户的重点任务。
- 最近失败与核心异常摘要。
- 跳转任务中心、任务详情、执行节点列表/详情和日志中心。
- 页面级刷新、数据过期、部分加载失败、空状态和权限状态。

### 3.2 不包含

- 新建、编辑、取消、重试、删除任务或修改执行节点。
- 任务参数、完整命令、完整错误栈或长日志展示。
- 多图表仪表盘、自定义卡片、自定义布局或保存视图。
- 调度平台服务器的 CPU、内存、磁盘或进程监控。
- 执行节点历史资源曲线、容量预测、阈值告警或自动诊断。
- 告警规则、订阅、通知、确认、指派、关闭或事件工单。
- 跨来源因果分析、AI 摘要、AI 诊断或自动修复。
- 平台健康评分、SLA、成功率目标或未经定义的红黄绿综合分。
- 面向公开展示的监控大屏或多租户对比看板。

## 4. 页面信息架构

首页保持一个页面、五个内容区：

```text
首页
├── 运行摘要与更新时间
├── 四张核心指标卡
├── 一张任务结果趋势图
├── 执行节点健康摘要
└── 我的任务 / 最近失败与异常
```

- 第一屏优先展示运行摘要、指标卡、趋势图和节点异常数量。
- “我的任务”和“最近失败与异常”使用有限列表，不在首页提供复杂筛选、分页或列配置。
- 所有卡片和列表只提供查看/跳转，不复制二级页面的管理操作。
- 页面不提供时间范围以外的全局筛选器；V1.0 不增加环境、任务类型、创建人等首页筛选。

## 5. 数据范围、时间和刷新

### 5.1 授权范围

- 首页任务指标、趋势、失败列表和节点摘要只统计当前用户有权查看的对象。
- “我的任务”进一步限定为当前用户创建的任务，不等同于全部授权任务。
- 系统管理员不因角色名称天然看到全部业务对象；首页始终按其实际任务、节点和日志对象范围聚合，页面结构和字段不变化。
- 页面明确标注“当前授权范围”，不使用“全平台”误导普通用户。

### 5.2 时间口径

- “今日”按当前页面显示时区的自然日计算，时区来源遵循系统设置。
- 趋势默认最近 24 小时、按小时聚合；切换最近 7 天时按自然日聚合。
- 趋势统一按任务进入终态的时间统计，避免将创建时间、开始时间和结束时间混用。
- 来源时间仍保留原始语义，时区切换只改变展示和分桶解释，不改写历史事实。

### 5.3 刷新与一致性

- 首页使用一次页面快照聚合摘要、指标、节点和列表，并显示数据更新时间。
- 支持周期刷新和手动刷新；精确刷新间隔待性能与技术设计，不在产品文档硬编码。
- 刷新中保留上一份可用快照并显示更新中，不清空页面。
- 刷新失败时保留最后可信数据，显示失败时间、数据可能已过期和重试入口。
- 分区部分失败时明确标记该分区不可用，不用旧值与新值拼成看似同一时刻的整体结论。

## 6. 运行状态摘要

### 6.1 展示方式

使用受控模板生成一到两句自然语言摘要，例如：

> 当前授权范围内有 4 个任务运行中、1 个任务等待调度；2 个执行节点当前不能接收新任务；最近 1 小时有 1 个任务失败。

- 摘要由已确认的任务和节点事实聚合，不使用 AI 生成或复杂评分算法。
- 无法取得某类数据时明确说明“节点状态暂不可用”，不把未知写成正常。
- 摘要不把 CPU/内存采样高低直接解释为平台异常，除非已有确认阈值和状态规则。

### 6.2 摘要优先级

优先表达需要关注的事实：

1. 数据过期或关键分区不可用；
2. 最近失败任务或工具进程异常退出；
3. 节点不能接收新任务；
4. 等待调度任务；
5. 运行中任务；
6. 无上述事项时说明当前未发现核心异常。

摘要优先级只决定文案顺序，不形成综合健康分或告警等级。

## 7. 核心指标卡

V1.0 固定四张卡，不允许自定义或继续增加：

| 指标 | 精确定义 | 点击行为 |
|---|---|---|
| 运行中任务 | 当前状态为“运行中”的授权任务数 | 进入任务中心，筛选状态=运行中 |
| 等待调度任务 | 当前状态为“等待调度”的授权任务数 | 进入任务中心，筛选状态=等待调度 |
| 今日成功任务 | 当前显示时区今日进入“成功”的授权任务数 | 进入任务中心，筛选状态=成功、终态时间=今日 |
| 今日失败任务 | 当前显示时区今日进入“失败”的授权任务数 | 进入任务中心，筛选状态=失败、终态时间=今日 |

- 启动中、取消中、草稿和已取消不并入运行中或等待调度卡片。
- 指标只展示数量和必要的口径说明，不增加环比、同比、成功率或目标值。
- 数量无法取得时显示未知，不显示 0。

## 8. 任务结果趋势图

### 8.1 指标与口径

- 首页只保留这一张图。
- 时间范围：最近 24 小时或最近 7 天。
- 粒度：24 小时按小时，7 天按日。
- 时间字段：任务进入终态的时间。
- 系列：终态任务总数、成功数、失败数。
- 终态任务总数包含成功、失败和已取消；成功数和失败数是其中子集。
- 草稿、等待调度、启动中、运行中和取消中不进入结果趋势。

### 8.2 交互

- 默认展示最近 24 小时。
- 切换时间范围后重新加载同一图表，不增加第二张图。
- 点击时间点或柱进入任务中心，带入终态时间范围；点击成功/失败系列时同时带入状态。
- 图例可以开关系列显示，但不改变统计范围和任务中心跳转口径。
- 数据为空时展示“该时间范围内暂无终态任务”，仍保留时间切换。
- 不展示预测、平滑趋势、异常检测、百分比成功率或无依据 ETA。

## 9. 执行节点健康摘要

### 9.1 数据来源

完全复用执行节点模块的事实：

- 节点名称。
- 接收新任务结论及全部原因入口。
- 管理状态、心跳状态、环境状态和容量状态摘要。
- 当前运行任务数 / 最大并发任务数。
- CPU、内存当前快照及采样时间。
- 最近心跳时间。

首页不读取或展示调度平台服务器资源。

### 9.2 展示与排序

- 优先展示当前不能接收新任务的节点，其次展示繁忙节点；全部正常时按运行任务数和最近采样排序。
- 首页不使用“高负载”标签替代已确认状态；CPU/内存只作为带时间的当前快照。
- 展示有限条目和“查看全部节点”，精确条数根据低保真原型和视口确认。
- 点击节点进入节点详情；点击数量或“查看全部”进入节点列表并带入相应条件。
- 节点无权限时不展示名称、数量或资源值。

## 10. 我的任务

### 10.1 范围与排序

- 只展示当前登录用户创建且有权查看的任务。
- 优先顺序：最近失败、运行中、等待调度、最近完成；同组按最后更新时间倒序。
- 只展示有限条目，完整列表跳转任务中心并带入“创建人=我”。
- 首页不提供取消、重试、检查点继续、保存模板或复制命令。

### 10.2 字段

- 任务名称和 ID 摘要。
- 任务类型。
- 状态和条件化“状态核对中”标识。
- 当前阶段。
- 可靠进度；无可靠证据时按任务中心规则降级。
- 开始时间或最后更新时间。

点击任务进入任务详情，不在首页展开配置、命令或日志。

## 11. 最近失败与异常

### 11.1 范围

只展示平台已经识别、当前用户有权查看的核心事实：

- 最近失败任务。
- 执行节点不能接收新任务，重点包括离线、维护、禁用、环境异常和繁忙。
- 调度失败或启动失败。
- 工具进程异常退出。

### 11.2 展示规则

- 每条显示事件类型、对象、发生时间、简短原始语义和数据来源。
- 同一任务失败与其工具进程异常退出存在同一事件标识时，合并为一个主条目并保留来源，不重复计数。
- 不把时间接近的任务、节点和调度记录推断为因果关系。
- 失败任务跳转任务详情或错误日志；节点异常跳转节点详情；跨来源排障进入日志中心并带入对象和时间范围。
- V1.0 不提供确认、忽略、关闭、指派、订阅、静默或告警规则。

## 12. 页面状态

| 状态 | 页面处理 |
|---|---|
| 首次加载 | 保留稳定页面骨架，各分区显示加载状态 |
| 刷新中 | 保留上一份可信快照，显示更新中 |
| 全部加载失败 | 显示失败、最后成功时间和重试，不显示虚假正常摘要 |
| 部分加载失败 | 成功分区继续显示，失败分区独立说明且总体摘要标记不完整 |
| 数据已过期 | 显示最后更新时间和过期提示，不将旧状态表现为实时 |
| 无任务 | 指标为 0，趋势和我的任务显示有口径的空状态 |
| 无执行节点 | 节点区说明尚未注册或当前无权查看，不混为节点全部离线 |
| 无失败/异常 | 显示当前范围和时间内未发现核心异常 |
| 无权限 | 不返回数量、名称、趋势或候选，展示权限说明 |

## 14. 验收基线

1. 用户无需进入二级页面即可看到运行、等待、今日成功、今日失败和节点状态。
2. 页面明确统计授权范围，不泄露无权任务或节点数量。
3. 首页只有一张任务结果趋势图，所有系列使用统一终态时间口径。
4. 四张指标卡使用任务中心的精确状态，不混入启动中或取消中。
5. 节点区复用四维状态和接收新任务结论，不发明健康分或无依据高负载。
6. 我的任务只显示当前用户任务，进度按可靠证据降级。
7. 最近失败与异常保留真实对象、时间和来源，不推断跨来源因果。
8. 任一摘要均可跳转相应任务、节点或日志页面并带入明确条件。
9. 刷新或部分加载失败不会把未知、旧值或零值冒充实时正常状态。
10. 首页不提供任务操作、复杂筛选、告警处置、自定义布局或平台服务器资源监控。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| HM-R01 | 模块边界 | 首页只做授权范围内的状态摘要和跳转，不承担任务管理、监控分析或告警处置 |
| HM-R02 | 页面结构 | 固定运行摘要、四张指标卡、一张趋势图、节点摘要、我的任务和最近异常，不提供自定义布局 |

| HM-R05 | 运行摘要 | 使用受控模板和事实优先级生成，不使用 AI、健康分或复杂评分算法 |
| HM-R06 | 指标卡 | 固定运行中、等待调度、今日成功、今日失败四项，不增加环比、成功率或目标值 |
| HM-R07 | 状态口径 | 启动中、取消中、草稿和已取消不并入运行中/等待调度卡片，点击按精确状态跳转 |

| HM-R10 | 趋势口径 | 统一按终态时间；总数包含成功、失败、已取消，成功/失败为子集，非终态任务不进入 |

### 3. 业务场景

<a id="business-scenarios-hm-lf-01-首页正常态"></a>

#### HM-LF-01 首页正常态


- 页头固定展示当前授权范围、显示时区、统一快照更新时间、自动刷新状态和手动刷新入口；
- 运行摘要由受控模板生成，优先表达失败、节点不能接收、等待调度和运行中事实，不产生综合健康分；
- 四张指标卡固定为运行中、等待调度、今日成功和今日失败，只展示精确数量、必要口径和任务中心入口；
- 任务结果趋势是首页唯一图表，最近 24 小时按小时、最近 7 天按日，统一按终态时间统计；
- 执行节点优先展示不能接收任务的节点，保留原因、容量、最近心跳以及带采样时间的 CPU、内存快照；资源值只作为中性事实，不推断高负载；
- “我的任务”只展示本人创建的有限重点任务，不提供取消、重试、新建或其他状态化操作；
- 最近失败与异常保留对象、发生时间、简短事实和真实来源，不把跨来源时间接近解释为因果关系。

<a id="business-scenarios-hm-lf-02-部分失败与数据过期"></a>

#### HM-LF-02 部分失败与数据过期


- 页头展示最后成功更新时间和数据已过期状态，总体提示列出失败分区；
- 成功分区保留最后可信快照并明确快照时间，不能用旧值与新值拼接为同一时刻结论；
- 任务趋势和最近异常分区分别展示加载失败、失败时间与局部重试，不绘制零值趋势或“当前无异常”；
- 节点状态、容量、资源值和采样时间整体标记为过期，不表现为实时数据；
- 刷新时不清空现有内容，也不把未知值改成 0；
- 页面只表达已确认事实与未知范围，不产生“运行正常”或自动诊断结论。

<a id="business-scenarios-hm-lf-03-真实空状态"></a>

#### HM-LF-03 真实空状态


- 只有查询成功且口径明确为零时，四张指标卡才能展示 `0`；
- 趋势空状态保留时间范围与终态时间口径，不绘制伪造的零趋势线；
- 节点区明确“尚未注册执行节点”，不与无权限、全部离线或采集失败混淆；
- “我的任务”只提供进入任务中心的查看入口，不在首页直接创建任务；
- 最近异常只有在采集完整时才能说明指定范围内未发现核心异常；
- 空状态不填充示例任务、演示节点或虚构事件。

<a id="business-scenarios-hm-lf-04-无权限状态"></a>

#### HM-LF-04 无权限状态


- 用户没有任何首页可见对象范围时，不渲染指标卡、趋势、节点、任务或异常区；
- 不展示数量、对象名称、候选项、经过模糊或遮挡的数据，也不以 `0` 暗示无权对象数量；
- 页面仅说明当前没有可查看的任务、执行节点或日志对象，并提供刷新权限和权限说明入口；
- 角色名称不代表自动拥有全部业务对象权限；管理员仍按实际对象范围聚合；
- 无权限不是加载、失败或真实空状态，不提供重试数据分区或对象派生入口。

<a id="business-scenarios-4-布局与下钻边界"></a>

### 4. 布局与下钻边界

| 区域 | 首页职责 | 下钻目标 | 首页禁止 |
|---|---|---|---|
| 运行摘要 | 表达当前最需关注的事实 | 对应任务、节点或日志页面 | 综合评分、AI 结论、告警处置 |
| 指标卡 | 展示四个精确状态数量 | 带同口径条件进入任务中心 | 环比、同比、成功率、目标值 |
| 任务趋势 | 展示一个终态结果趋势 | 带终态时间和条件化状态进入任务中心 | 第二张图、预测、异常检测、BI 探索 |
| 执行节点 | 展示可接收结论、原因、容量和带时间资源快照 | 节点列表或节点详情 | 调度平台服务器资源、历史曲线、性能诊断 |
| 我的任务 | 展示本人有限重点任务 | 任务中心或任务详情 | 新建、取消、重试、保存模板、复制命令 |
| 最近失败与异常 | 展示有来源的核心事实 | 对象详情或日志中心 | 确认、忽略、指派、关闭、订阅、自动修复 |

所有跳转都必须显式携带并展示首页使用的同口径条件；目标页面重新进行权限校验，首页不得成为绕过对象权限的快捷入口。

<a id="business-scenarios-6-当前边界"></a>

### 6. 当前边界

本次确认表示首页关键静态低保真已经通过产品评审，但不表示：

- 自动刷新间隔、快照聚合超时、数据过期阈值或并发请求策略已经技术定版；
- 节点摘要、我的任务和最近异常的精确展示条数已经确定；
- 最近异常默认时间范围、同一底层事件标识和去重实现已经完成；
- CPU、内存阈值、趋势、容量预测或自动诊断已进入首页能力；
- 聚合接口、缓存、权限编码、图表组件、响应式布局或移动端降级已经设计；
- 图片中的时间、数量、任务、节点和资源值构成生产事实；
- 可交互原型、高保真 UI、技术设计或业务代码开发已经准入。
