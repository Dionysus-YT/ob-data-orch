## 1. 核查结论

- 实际运行 `obloader --help` 共检出 **103 个唯一长参数**，下表逐项给出含义、分类、普通导入处置和来源，名称覆盖无遗漏。
- 参数出现在共享帮助中不等于适用于普通导入。`--direct`、`--rpc-port`、`--parallel` 是旁路导入专属；`--enable-hidden-pk` 的官方资料确认的是导出用途。
- 本表保留 103 项共享 help 核查事实；[DEC-051](../01-product/decisions.md#dec-051-普通导入五步向导与旁路模块解耦) 排除旁路业务后，[DEC-053](../01-product/decisions.md#dec-053-普通导入参数分层与适用范围收敛) 将本轮页面目录收敛为 76 项适用配置与受管派生项，其余 27 项只在本研究基线保留处置记录。目录数量不表示已实现执行能力。
- [DEC-052](../01-product/decisions.md#dec-052-普通导入沿用导出布局与三种文件格式) 将当前前端新建格式收窄为 CSV、CUT、SQL；MIX、其他格式及 Hive 来源不进入本轮目录、表单或活动参数。本表的官方研究事实保持有效。
- `--storage-uri` 已被 `--file-path` 统一承载，`--column-delimiter` 是 `--column-quote` 的过时别名；两者只用于历史命令识别。
- `--buffer-size`、`--server`、`--public-synonym` 当前只有本地 help 字样，缺少 V4.3.5 官方普通导入语义，不进入新建任务。
- 经核验且属于本轮产品范围的参数进入常用字段、唯一高级区或受管派生说明；未准入能力和失败任务操作保留研究，不混入新建任务。参数说明与目录共用含义，执行能力仍待正式准入。

2026-10-16 G2 实现核对：普通导入生成器独立加载 `obloader-4.3.5-normal-v1` 的 72 条定义，与页面 76 项逐项对齐；差额为 `--sys-user`、`--sys-password`、`--character-set`、`--session-config` 四项受管说明，均不接受任务覆盖或进入冻结 argv。当前能力固定派生 `--no-sys`，业务密码仅进入安全文件槽位，不落入命令文本或快照。`--retry` 仍只属于未接入的失败恢复，不进入新建元数据。字段条件和非活动参数由服务端再次校验，不能仅依赖前端禁用。版本、协议和未实现边界见[普通导入技术契约](../03-technical/normal-import-contract.md)。

## 3. 分类说明

| 分类 | 说明 |
|---|---|
| 连接与会话 | 数据源、安全配置或专家会话参数 |
| 文件与匹配 | 输入路径、编码、后缀、正则、控制文件和第三方文件 |
| 内容与格式 | DDL、MIX 与七种数据格式 |
| 对象范围 | 全部、表及定义对象 |
| 列与解析 | 列映射、列名单、类型排除及文本解析 |
| 错误与数据行为 | 错误上限、严格退出、替换和清空/删除 |
| 性能与资源 | 线程、批次、限速、阈值、内存和检查点 |
| 旁路专属 | 普通导入不得生成 |
| 废弃/兼容 | 只读识别历史命令，新建任务不用 |
| 未确认/非普通导入 | 共享 help 存在，但普通导入官方语义不足或属于导出侧 |
| CLI 元参数 | 不属于任务配置 |

分类计数：对象范围 16、列与解析 19、内容与格式 9、性能与资源 10、连接与会话 16、文件与匹配 12、错误与数据行为 8、旁路专属 3、废弃/兼容 4、未确认/非普通导入 4、CLI 元参数 2，合计 103。

## 5. 本轮普通导入参数边界

本节是 DEC-053 的当前产品处置；上表中的官方能力事实仍保留，未开放不等同于工具不支持。

### 参数所有权与展示

- 数据源负责受管连接上下文，目标数据库可覆盖；`character-set`、`session-config` 不进入任务表单或活动配置。当前页面不读取秘密，不假定派生值已接入。
- 第二步常用字段为本地路径、日志目录、内容、CSV/CUT/SQL 格式、编码、后缀和适用分隔符/开关；文件正则、文本解析、压缩输入、MySQL 日期纠错进入同页唯一高级区。
- 第三步提供对象范围与映射，只有 CSV 显示自动列映射。控制文件、自动映射与显式名单严格单选；包含列和排除列按平台规则择一，冲突输入不得进入活动名单。
- 第四步常用区仅提供适用的错误与重复数据处理；性能、JVM 资源、Oracle NLS 和数据行为进入同页唯一高级区。仅对象定义不带数据写入参数，线程、JVM 内存与适用 NLS 仍可配置。
- 第五步不提供 `yes` 开关；本地已阅读影响不派生执行确认或命令。

### 不进入本轮新建目录的 27 项

| 处置 | 参数 |
|---|---|
| 旁路专属，保持模块解耦 | `direct`、`rpc-port`、`parallel` |
| CLI 元参数 | `help`、`version` |
| 废弃别名 | `storage-uri`、`column-delimiter` |
| 官方仅确认导出侧 / 普通导入语义不足 | `enable-hidden-pk`、`buffer-size`、`server`、`public-synonym` |
| 本轮未开放的格式和来源 | `mix`、`pos`、`orc`、`par`、`avro`、`source-type` |
| 本轮未开放的远程 / 第三方文件 | `external-data`、`tmp-path` |
| 缺少条件事实或受控验证 | `ignore-unhex`、`slow`、`pause` |
| 失败任务恢复，非新建配置 | `retry` |
| 当前未开放的云环境、ODP Sharding 与旧独立连接参数 | `public-cloud`、`logical-database`、`tenant`、`cluster` |

导出专属的查询、WHERE/分区、闪回、输出文件拆分、保留空文件与导出 DDL 修饰不复制到普通导入。`block-size`、`max-tps`、压缩算法与等级本身也是已核对的普通导入参数，按读取/写入语义保留，不按名称误判为导出专属。

## 6. 覆盖验收

- 基线中的参数名称集合必须与实际 `obloader --help` 提取的 103 个唯一长参数完全相等。
- 新增或升级 OBLOADER 版本时，先重跑 help 差异，再更新官方来源、分类、字段规则和验证计划。
- “工具接受参数”不能单独作为普通导入能力确认；至少需要官方语义或受控验证证据。
- 本轮页面目录应等于完整 103 项基线减去上列 27 项，不得出现目录外任意参数；可编辑字段、派生说明、格式/内容条件与摘要应一致。\n- 页面字段数量可以少于目录项，因为连接和安全参数归受管上下文；后续执行接入仍须按正式契约冻结活动参数，不能以本地目录或投影替代命令生成。
