## 1. 目的与边界

将首页的数据范围、时间口径、指标、节点摘要、任务列表、异常、跳转和页面状态落实为可逐项评审的字段规则。本文不定义统计存储、聚合任务、刷新协议、图表库、缓存、接口或高保真视觉样式。

## 10. 已确认字段与条件规则

HM-FR01～HM-FR15 已于 2026-07-19 全部确认。确认的是首页授权范围、统一快照、运行摘要、指标和趋势口径、节点状态、我的任务、最近异常、跳转与页面状态的字段语义；HM-LF-R01～HM-LF-R18 已于 2026-07-20 确认并落实正常、部分失败/过期、真实空状态和无权限四类页面。刷新间隔、展示条数、事件去重技术和响应式布局仍属于后续设计项。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| HM-FR01 | 授权范围 | 所有指标、趋势、节点和异常按对象权限过滤；我的任务进一步限定本人创建 |
| HM-FR02 | 快照与刷新 | 展示统一快照时间；刷新保留上一可信值，失败/过期/部分失败显式区分 |
| HM-FR03 | 运行摘要 | 使用受控事实模板，不使用 AI、综合健康分或无依据正常结论 |
| HM-FR04 | 指标状态 | 固定四张卡并按精确状态统计，启动中/取消中不混入运行或等待 |
| HM-FR05 | 今日统计 | 使用当前显示时区的自然日和任务终态时间 |
| HM-FR06 | 趋势 | 仅一张图，24 小时按小时、7 天按日，统一按终态时间统计 |
| HM-FR07 | 趋势总数 | 终态总数包含成功、失败、已取消；成功/失败为子集，非终态不进入 |
| HM-FR08 | 图表跳转 | 时间点和系列跳转任务中心时带入可见、可清除的同口径筛选 |
| HM-FR09 | 节点状态 | 复用四维状态和接收新任务结论，资源只展示带时间快照，不推断高负载 |
| HM-FR10 | 节点排序 | 优先不能接收和繁忙节点；全部正常时使用可解释的运行数/采样排序 |
| HM-FR11 | 我的任务 | 按失败、运行、等待、完成分组展示有限条目，不在首页提供任务操作 |
| HM-FR12 | 进度 | 沿用任务中心证据降级，无可靠数据时不显示百分比或 ETA |
| HM-FR13 | 最近异常 | 只展示有来源的核心事件，同一事件去重，跨来源不推断因果或自动诊断 |
| HM-FR14 | 空与异常状态 | 无数据、无权限、未采集、部分失败、过期和未知使用不同状态 |
| HM-FR15 | 轻量化 | 不增加图表、全局筛选、自定义布局、告警处置、资源历史或平台服务器监控 |

## 11. 字段覆盖验收

1. HM-F001～HM-F075 覆盖首页快照、摘要、指标、趋势、节点、我的任务、异常和页面状态。
2. 数字、图表和候选项不会泄露无权对象。
3. 四张指标卡和趋势使用精确定义的状态与时间口径。
4. 节点状态、资源和时间新鲜度完全复用执行节点模块。
5. 任务状态、阶段和进度完全复用任务中心规则。
6. 最近异常保留真实来源、脱敏和采集完整性，不提供自动诊断。
7. 所有首页摘要都能跳转到对应管理/分析页面，不在首页复制复杂操作。
8. 首页保持一张图和有限列表，不扩展为大屏、BI、监控或告警平台。
