## 通用前提

- 用户具备所选环境和数据源的使用权限。
- 数据源已在独立模块创建并启用；向导不重复填写连接信息。
- 执行节点已注册且工具版本满足任务要求。
- 所有未完成 V4.3.5 官方核验的参数与组合统一标记为“待官方参数映射确认”。
- 三类任务提交前都要通过参数预检查、查看完整命令并主动确认。

## 首页状态判断与下钻流程

专项规则见[首页模块专项评审稿](home-module.md)。

```text
进入首页并加载授权范围快照
→ 查看运行摘要和四项核心指标
→ 查看单一任务结果趋势与执行节点摘要
→ 查看我的重点任务和最近失败/异常
→ 跳转任务中心、任务详情、节点详情或日志中心
```

- 首页不直接取消、重试、编辑任务或修改节点，状态化操作进入对应模块。
- 指标和趋势跳转携带可见、可清除的同口径筛选条件。
- 数据刷新失败时保留最后可信快照并标记过期，不用 0 或“正常”代替未知。
- 首页统计和候选项不包含当前用户无权查看的任务、节点或日志。

## 导出任务流程

```text
选择已有数据源
→ 配置导出对象
→ 配置导出内容
→ 配置导出格式
→ 配置执行参数
→ 参数预检查
→ 查看完整命令
→ 提交执行
→ 查看任务详情和日志
```

| 步骤 | 用户行为 | 系统反馈与边界 |
|---|---|---|
| 1. 选择已有数据源 | 搜索并单选已启用数据源 | 展示只读连接摘要和最近测试结果；不可用时阻断下一步 |
| 2. 配置导出对象 | 选择全部导出或指定对象 | 两者互斥；对象类型、表达式和多库规则按导出参数与字段基线执行，冲突项保持受限 |
| 3. 配置导出内容 | 选择仅 DDL、仅数据或 DDL + 数据 | 仅 DDL 时跳过数据格式步骤；对象与内容条件按已确认字段矩阵执行，待实测组合不得放行 |
| 4. 配置导出格式 | 在官方支持范围内单选格式 | 只展示当前格式专属配置；格式切换只生成当前选项参数 |
| 5. 配置执行参数 | 配置输出位置、执行节点及必要运行参数 | 高级参数默认折叠；参数名称已建档，默认值或行为存在冲突时显示来源并保持受限 |
| 6. 参数预检查 | 发起检查并处理阻断项或警告 | 检查连接、节点、工具版本、路径、对象、必填项和参数约束 |
| 7. 查看完整命令 | 核对摘要和只读 OBDUMPER 命令，可复制 | 密码默认脱敏；命令不可直接编辑绕过规则 |
| 8. 提交执行 | 填写任务信息并确认执行 | 通过预检查且命令生成成功后提交，进入任务详情 |
| 9. 查看详情和日志 | 查看阶段、可靠进度、命令、日志和错误 | 无法可靠计算时只显示阶段与持续时间 |

## 普通导入流程

专项字段、参数和风险规则见[普通导入模块专项评审稿](normal-import-module.md)。

```text
选择已有数据源
→ 选择导入文件与路径
→ 选择导入内容与格式
→ 配置目标对象与文件匹配
→ 配置执行参数
→ 参数与文件预检查
→ 查看完整命令
→ 提交执行
→ 查看任务详情和日志
```

| 步骤 | 用户行为 | 系统反馈与边界 |
|---|---|---|
| 1. 选择已有数据源 | 选择已启用目标数据源 | 数据源连接测试不代替本任务的导入权限与参数检查 |
| 2. 选择文件与路径 | 选择执行节点可访问的本地路径/文件，或官方支持的远程存储位置 | 不提供浏览器上传和任意 URI；本步只做路径可达与初步文件发现 |
| 3. 选择内容与格式 | 选择 DDL、数据、DDL+数据或独立 MIX；数据任务选择一种官方格式 | MIX 与 `DDL + 数据格式` 不等价；选择格式后按后缀、压缩和解析条件重新计算有效文件集 |
| 4. 配置目标对象与文件匹配 | 指定数据库/Schema、对象范围和官方文件/列映射规则 | 不智能推导字段映射，不创建或修改目标表；控制文件、自动列映射及格式条件在此统一约束 |
| 5. 配置执行参数 | 配置执行节点、错误处理、性能、会话和风险参数 | 所有有效普通导入参数均可在分类面板找到；普通/高级/专家只是展示层级 |
| 6. 参数与文件预检查 | 校验连接、权限、文件存在与可读、匹配结果、目标对象和参数组合 | 阻断错误必须修复；任务级检查不回写为数据源综合能力结论 |
| 7. 查看完整命令 | 核对文件、目标对象、格式摘要和完整 OBLOADER 命令 | 默认脱敏、只读、可复制 |
| 8. 提交执行 | 确认任务信息并执行 | 创建不可变参数快照并进入任务详情 |
| 9. 查看详情和日志 | 查看阶段、进度、日志、错误和结果 | 存在有效 `load.ckpt` 且原参数快照满足条件时可使用 `--retry` 继续 |

## 旁路导入流程

旁路导入是独立流程，不是普通导入的高级配置。其独有边界包括 RPC 端口、版本约束、单表限制、表粒度整体提交、不支持重试或断点续传，以及 `thread` / `parallel` 的不同语义。

专项字段、参数、三模块一致性护栏和风险规则见[旁路导入模块专项评审稿](direct-load-module.md)。

```text
确认旁路导入适用条件与风险
→ 选择已有数据源并确认 SQL / RPC 连接目标
→ 选择执行节点和单表数据文件
→ 配置唯一目标表与受支持格式
→ 检查版本和已知表结构限制
→ 配置旁路导入专属参数
→ 参数预检查与风险确认
→ 查看完整命令
→ 提交执行
→ 查看旁路阶段和日志
```

| 步骤 | 用户行为 | 旁路独有规则 |
|---|---|---|
| 1. 适用条件确认 | 确认任务为大批量单表场景并阅读限制 | 未确认不得继续；明确不支持重试或断点续传 |
| 2. 选择连接目标 | 选择已有数据源，明确云 ODP、私有 ODP 或私有 OBServer 场景，核对 SQL/RPC 端口 | RPC 端口必填并显示来源；按 V4.3.5 专题精确版本矩阵阻断 |
| 3. 选择单表文件 | 选择执行节点和一个目标表对应的一个或多个分片文件 | 不得匹配多张目标表；文件必须在节点侧可读 |
| 4. 配置目标表与格式 | 指定唯一目标表、文件匹配及有旁路适用证据的格式 | CSV 在三种连接场景已确认；SQL/Parquet/ORC 仅云 ODP 已确认；CUT/POS/Avro 及私有路径未确认组合统一标记待官方参数映射确认 |
| 5. 结构与版本检查 | 检查工具、OBServer/ODP 版本和可查询的表结构限制 | 无元数据权限时提示用户自行确认，不得默认通过 |
| 6. 专属参数 | 配置 `direct`、RPC 端口、`thread`、`parallel` 及经核验的共享参数 | `thread` 为客户端连接池、`parallel` 为服务端工作线程；不一致时警告，不自动改值 |
| 7. 预检查与风险确认 | 处理阻断项并二次确认整体提交、失败从头执行、唯一索引等风险 | 旁路风险确认独立维护，不复用普通导入文案 |
| 8. 查看完整命令 | 核对单表、文件、SQL/RPC 端口、并发和完整命令 | 默认脱敏、只读、可复制 |
| 9. 提交执行 | 确认后提交 | 进入旁路任务详情 |
| 10. 查看详情和日志 | 查看参数校验、文件预处理、数据写入、服务端处理/提交等阶段 | 日志不能可靠解析时不展示虚假百分比；失败只允许从头重新执行 |

## 三条流程的共用与边界

| 能力 | 导出 | 普通导入 | 旁路导入 |
|---|---|---|---|
| 选择已有数据源 | 共用 | 共用 | 共用，但增加 RPC 与版本要求 |
| 文件输入 | 不适用 | 多种官方支持路径 | 单表数据文件，禁止多表 |
| 对象范围 | 全部或指定对象 | 官方支持的单表/多表匹配 | 唯一目标表 |
| 完整命令 | OBDUMPER | OBLOADER | OBLOADER Direct Load |
| 失败继续 | 存在有效 `dump.ckpt` 且满足原参数条件时可使用 `--retry` | 存在有效 `load.ckpt` 且满足原参数条件时可使用 `--retry` | 明确不支持断点续传，从头执行 |
| 公共去向 | 任务中心、任务详情、日志 | 任务中心、任务详情、日志 | 任务中心、任务详情、日志 |

## 任务追踪与失败处理公共流程

```text
向导提交复验
→ 等待调度
→ 启动中
→ 运行中
→ 查看阶段、可靠进度和增量日志
→ 成功 / 失败 / 已取消
→ 查看不可变快照、实际命令和结果
→ 按类型选择基于原配置新建、从头重新执行或检查点继续
```

- 提交复验失败时保持草稿并返回可定位错误，不长期创建“校验失败”任务状态。
- 已提交任务的配置、数据源、执行节点和命令不原地修改。
- 进度依证据降级为百分比、阶段或仅持续时间，不伪造 ETA。
- 每次从头重新执行或检查点继续使用新任务 ID，保留来源关系。
- 旁路导入不得出现检查点续传。

## 执行节点注册与启用流程

专项规则见[执行节点管理模块专项评审稿](execution-node-module.md)。

```text
创建节点记录
→ 配置管理信息、工具路径和基础目录
→ 按指引在目标机器关联 Agent
→ 接收首次心跳与机器事实
→ 执行只读环境检查
→ 检查通过后启用
→ 供三类任务选择
```

- 平台不通过 SSH 远程安装或升级 Agent、Java、OBLOADER/OBDUMPER。
- Agent 未关联、节点离线、环境异常或达到并发上限时，不可接收新任务。
- 启用、维护、禁用不自动取消运行任务；节点有历史引用时归档而非破坏历史。

## 任务选择与节点失联流程

```text
任务向导显式选择节点
→ 展示通用可用性与原因
→ 执行任务级路径、版本和配置预检查
→ 提交时保存节点环境快照
→ 启动前复验节点关键事实
→ 启动执行 / 保持等待并展示阻断原因
```

- 已提交任务不静默更换执行节点；需要换节点时先按任务详情规则处理原任务，再基于原配置创建新草稿并重新预检查。
- 运行中节点失联不直接判定任务失败；保留最后可信状态并进入核对中，Agent 恢复后按真实进程证据更新。

## 日志查询与排障流程

专项规则见[日志中心模块专项评审稿](log-center-module.md)。

```text
从任务/节点进入或选择日志预设
→ 设置必填时间范围和对象条件
→ 查询有权日志
→ 查看来源、级别、时间和采集完整性
→ 打开同一来源上下文
→ 跳转任务/节点继续排障或下载脱敏结果
```

- 任务详情继续承担当前任务实时日志；跨任务、跨节点或长时间查询进入日志中心。
- 任务日志预设可组合调度、Agent 与工具输出，但每条记录保留真实来源，不把时间接近解释为因果关系。
- 实时连接中断时保留已加载内容；确认存在缺口时明确标记不完整。
- 页面、复制和下载使用同一脱敏语义；V1.0 不开放未脱敏原始日志下载。

## 模板创建与使用流程

专项规则见[模板中心模块专项评审稿](template-center-module.md)；已确认页面见[模板中心复用链路低保真基线](template-center-low-fidelity.md)。

### 创建或保存模板

```text
手工新建 / 复制模板 / 从成功任务保存
→ 确认模板类型与目标工具版本
→ 配置或提取活动显式可复用值
→ 选择数据源策略
→ 查看将保存、排除和使用时待补内容
→ 完成参数结构兼容校验
→ 保存模板
```

- 导出、普通导入和旁路导入模板保持独立类型，不自动转换。
- 从任务保存只对成功任务开放，只提取活动、显式、非敏感配置；不复制凭据、节点、检查结果、风险确认、命令、日志或运行结果。
- 固定数据源只作新草稿默认预选，不扩大权限，也不禁止用户在任务向导中更换。
- 高风险参数值可以进入模板并明确标记，但已确认风险的状态不能复用。

### 使用模板创建任务

```text
选择有权模板
→ 查看兼容状态与差异
→ 创建对应类型可编辑新草稿
→ 重新选择或确认数据源
→ 选择执行节点并重新取得凭据/环境派生值
→ 补齐当前版本必填项并处理高风险配置
→ 执行完整任务预检查
→ 查看完整命令
→ 提交执行
```

- “可用、需复核、不可用、校验未知”只说明工具与参数结构兼容；不可用或未知状态不默认放行。
- 模板使用不会直接执行任务，也不会复用来源任务或模板保存时的预检查证据。
- 模板编辑或删除不改写已创建草稿和历史任务；新任务保留模板来源摘要用于追溯。

## 权限配置与高风险操作流程

专项规则见[权限与安全基线专项评审稿](access-control-security-module.md)；已确认页面见[权限与安全高风险操作低保真基线](access-control-security-low-fidelity.md)。

### 配置用户权限

```text
选择已认证用户
→ 查看当前角色、有效权限和限制
→ 配置固定角色
→ 配置数据源、节点、任务与模板范围
→ 配置依赖条件满足的独立高风险能力
→ 查看角色、范围和能力差异
→ 填写变更原因并确认高风险影响
→ 校验权限版本并原子保存
→ 查看审计摘要
```

- 当前用户自身只读；账号停用或状态未知时不新增角色或高风险能力。
- 角色允许先保存空对象范围但明确不生效，不能用隐式全部范围代替。
- 移除基础角色时同步清理其依赖范围和独立能力，不保留潜伏权限。
- 并发版本变化或任一字段失败时整次保存不生效。

### 提交生产任务

```text
选择生产数据源或进入生产草稿
→ 校验任务能力、生产独立能力和对象范围
→ 完成参数与环境预检查
→ 生成并核对脱敏完整命令
→ 展示生产环境、对象、节点和风险摘要
→ 用户完成二次确认
→ 服务端重新校验权限与检查证据
→ 提交并生成不可变任务快照 / 阻断并使检查失效
```

- 生产环境来自数据源固定标识，不能由任务向导临时改写。
- 二次确认不是审批，不能代替权限、对象范围、参数约束或预检查。

### 查看或复制敏感命令

```text
用户主动选择敏感命令操作
→ 校验任务权限、独立能力和平台总开关
→ 展示任务、环境、操作类型和泄露风险
→ 用户明确确认
→ 服务端再次校验
→ 当前任务和本次操作受控开放
→ 离开或刷新后恢复脱敏并记录审计
```

- 确认前不显示敏感命令明文；审计不记录命令明文。
- 敏感命令能力不开放未脱敏原始日志，日志页面和下载仍使用统一脱敏结果。

## 系统设置修改流程

专项规则见[系统设置模块专项评审稿](system-settings-module.md)。

```text
进入平台基础 / 调度 / 安全 / 工具与兼容分区
→ 查看当前生效值、来源和更新时间
→ 编辑当前分区
→ 完成字段与依赖校验
→ 查看旧值、新值和影响范围
→ 高影响变更二次确认
→ 保存当前分区
→ 核对实际生效状态和审计标识
```

- 四个分区独立原子保存；一个字段失败时不让其他字段部分生效。
- 设置变化不回写已提交任务和历史命令，新建或重新编辑对象按当前基线处理。
- 降低保留期、并发或超时，以及修改安全、工具版本和参数元数据基线时必须展示影响。
- 配置版本发生并发变化时阻断覆盖，要求刷新后重新比较。
- 系统设置不提供任务参数、节点工具路径、配置脚本、工具安装或手工清理入口。
