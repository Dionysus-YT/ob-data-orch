> 参数事实依据：[旁路导入参数映射基线](direct-load-parameter-mapping.md)

## 1. 目的与一致性边界

本文把旁路导入参数和官方限制落到字段层。字段状态、默认值、条件显示、草稿、派生、预检查失效、命令预览和风险确认规则与导出、普通导入保持同构；只在 RPC、版本、单表、结构、整体提交和失败语义上保留必要差异。

本文不定义 API、数据库表、前端组件、控制文件编辑器或命令生成代码。

## 2. 字段状态与三模块通用规则

| 状态 | 含义 | 生成命令 | 提交快照 |
|---|---|---:|---:|
| 未设置 | 用户未覆盖，沿用 OBLOADER 4.3.5 官方默认 | 否 | 记录默认来源或“官方默认” |
| 已显式设置 | 用户在当前适用条件下主动配置 | 是 | 是 |
| 非活动 | 因格式、连接场景、版本或表结构不适用 | 否 | 否；草稿期可按命名空间暂存 |
| 派生 | 从数据源、执行节点、元数据、节点配置或确认结果计算 | 需要时 | 是，敏感值脱敏 |
| 阻断 | 映射不确定、依赖不满足或预检查失败 | 否 | 不允许提交 |

通用规则：

- 未设置参数显示“沿用官方默认”，不主动生成。
- 参数搜索能定位全部 103 个 help 参数，并说明当前是可编辑、派生、不适用还是待确认。
- 相同的命令预览、脱敏、复制、预检查分级、风险确认和任务快照规则不因 Direct Load 另起一套。
- 任何影响文件集合、唯一目标表、连接场景、RPC、版本、结构、命令或风险范围的变化，使对应检查和确认失效。
- 入口适用条件确认不替代最终风险确认。

## 11. 已确认字段规则

DL-FR01～DL-FR12 已于 2026-07-17 全部确认。确认的是字段状态、参数入口、派生、条件显示、阻断、命令快照和失败操作规则；参数映射中已标记待官方确认或待受控验证的事实状态不变。

| 编号 | 议题 | 已确认方案 |
|---|---|---|
| DL-FR01 | 三模块字段状态 | 沿用未设置、显式设置、非活动、派生、阻断五态和统一命令/快照规则 |
| DL-FR02 | 全部参数入口 | 103 参数均可搜索，并显示旁路适用状态和不可用原因 |
| DL-FR03 | 连接场景 | 云 ODP、私有 ODP、私有 OBServer 显式单选，连接字段按场景派生 |
| DL-FR04 | RPC 来源 | 展示数据源/节点/查询/人工来源，端口默认值只作提示，必须实测连通 |
| DL-FR05 | 版本矩阵 | 采用 V4.3.5 专题精确版本范围，无法取得版本不默认通过 |
| DL-FR06 | 单表预览 | 文件匹配必须给出唯一目标表；零匹配、多表或无法判断均阻断 |
| DL-FR07 | 格式证据门槛 | 只有有旁路适用证据的格式可提交，普通导入支持不自动等于旁路支持 |
| DL-FR08 | 全量/增量模式 | 由目标表空状态派生并只读展示，不提供手工模式切换 |
| DL-FR09 | 结构与替换 | BIT/虚拟列、索引、LOB、唯一索引共同决定阻断、提示和 replace-data 显示 |
| DL-FR10 | thread/parallel | 不一致只警告并解释语义；同步填充是一次性操作，不自动联动或写默认 |
| DL-FR11 | 节点配置 | session.config 的实际值和指纹只读进入快照，不在任务中修改 |
| DL-FR12 | 失败操作 | 不显示 retry/checkpoint；从头执行使用明确文案，基于原配置新建重新预检 |

## 12. 字段覆盖验收

1. 旁路字段使用与导出、普通导入一致的状态、默认、草稿、派生和失效语义。
2. 参数搜索覆盖 103 个名称和 3 个 Direct Load 节点配置键。
3. SQL/RPC、连接场景和版本信息在摘要、命令和快照中一致。
4. 文件只能映射到唯一目标表，不能通过高级配置绕过。
5. 未确认格式和共享参数不会无证据进入最终命令。
6. 全量/增量、结构限制和 replace-data 条件来自实际目标表事实。
7. thread/parallel 的语义和默认不被合并成一个模糊“并发数”。
8. 风险确认绑定当前快照，失败任务永不出现断点继续。
