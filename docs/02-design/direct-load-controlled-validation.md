# 旁路导入参数最小受控验证计划

> 文档状态：计划已形成，尚未执行\
> 目标程序：OBLOADER 4.3.5-RELEASE Direct Load\
> 更新日期：2026-07-17\
> 参数事实依据：[旁路导入参数映射基线](direct-load-parameter-mapping.md)\
> 字段规则依据：[旁路导入字段与条件矩阵](direct-load-module.md#field-rules)

## 1. 目的

本计划验证旁路导入的连接场景、版本、单表、格式、结构、全量/增量、替换、并发、节点配置、运行阶段和失败语义，并为普通导入共享参数是否适用于 Direct Load 提供最小证据。

它不是生产性能测试，也不授权连接业务库。未具备隔离环境、最小权限和执行授权前，只进行静态核对。

## 2. 安全边界

- 只使用专用非生产租户、专用数据库和 `dlvt_` 前缀测试表。
- 测试账号不复用生产凭据；RPC、SQL、对象存储和节点信息全部脱敏留证。
- 全量/增量、replace、truncate、唯一索引和取消用例分别使用独立表，执行前记录表结构、行数和预期影响。
- 每次真实执行只允许一个目标表；测试目录不得包含其他业务表文件。
- 不以“验证性能”为由制造生产级并发、内存水位、合并压力或 TB 数据。
- 不在任务测试中修改执行节点全局 `session.config.json`；配置行为验证使用隔离节点副本和单独授权。
- 服务端提交/取消用例必须有数据库管理员在场，并预先定义停止条件和恢复方式。
- 任何页面、日志、命令和证据不得记录密码、secret、token 或未脱敏连接串。

## 3. 最小测试资产

| 资产 | 用途 |
|---|---|
| `dlvt_empty` | 空表全量模式、replace-data |
| `dlvt_nonempty_plain` | 非空无索引/LOB 的增量模式 |
| `dlvt_indexed` | 普通索引对增量 replace-data 的影响 |
| `dlvt_unique` | 唯一索引冲突与 replace-data 边界 |
| `dlvt_lob` | LOB 对增量 replace-data 的影响 |
| `dlvt_bit` | BIT 类型限制 |
| `dlvt_binary` | 其他二进制类型口径差异 |
| `dlvt_virtual` | 虚拟生成列限制 |
| 小型标准 CSV 与同表分片 CSV | 主路径、单表多文件、解析参数 |
| CUT/POS/SQL/ORC/Parquet/Avro 最小文件 | 旁路格式适用性调查 |
| 本地与专用远程存储路径 | 文件来源适用性调查 |
| 隔离执行节点配置副本 | timeout/heartbeat 默认和行为验证 |

每项结果至少保存：脱敏命令、工具/数据库/ODP 版本、配置指纹、输入清单、表结构、前后行数、关键查询、日志、退出码和重复执行结果。

## 4. 优先级

| 优先级 | 范围 | 产品影响 |
|---|---|---|
| P0 | 核心命令、连接、版本、单表、已确认格式门禁、结构、模式、风险、失败 | 未通过则阻断旁路模块定版 |

## 8. 结果判定

| 状态 | 判定条件 | 产品动作 |
|---|---|---|
| 通过 | 至少两次独立执行一致，目标数据、服务端状态、日志和退出码满足预期 | 更新参数事实、字段和约束状态 |
| 失败 | 工具明确拒绝或行为与官方语义冲突且可重复 | 隐藏、禁用或修正规则 |
| 不确定 | 环境、权限、日志或数据不足以区分行为 | 保持待确认，不开放 |
| 环境阻断 | 缺少云 ODP、私有 ODP、特定版本、存储或结构环境 | 记录环境要求，不推定通过 |
| 需官方确认 | 二进制范围、共享参数、help-only 或多种行为均可解释 | 不先开放能力，取得官方语义后再测 |

一次成功、只看到参数被解析、只有退出码 0 或只看到客户端日志，都不足以确认 Direct Load 能力；必须同时核对目标表和可获得的服务端状态。

## 10. 执行前门槛

开始真实验证前必须具备：

- OBLOADER 4.3.5 隔离执行节点和原始配置备份；
- 符合精确版本矩阵的非生产 OBServer，ODP 用例另需符合版本的隔离 ODP；
- 允许创建、查询、清空和删除 `dlvt_` 表的专用账号；
- 可查询表结构、索引、LOB、版本和 RPC 端口的最小权限；
- 各连接场景独立的 SQL/RPC 地址和明确授权；
- 专用本地目录及远程存储测试前缀；
- 数据库管理员确认整体提交、取消和恢复方案；
- 明确输入文件、临时表、日志和节点配置副本的清理责任人。
