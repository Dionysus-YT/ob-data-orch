## 完成内容

- `WorkbenchButton` 和 `OrchButton` 的异步状态预留进度位置，保留可见动作名、无障碍名称和按钮尺寸；加载期间禁用操作。危险按钮悬停继续使用危险色。
- `OrchMenu` 支持上下键打开、方向键及首尾导航、Escape 归还焦点；禁用项保留键盘可达性并直接展示原因，事件处理再次阻断执行。菜单内部滚动不触发关闭，挂载结束后不会遗留监听器。

- 统一错误字段边框，避免普通主题覆盖错误状态；通用表格区域支持键盘聚焦滚动。
- 两套确认框固定头尾，正文独立滚动；低高度桌面抽屉减少上下留白，保留底部操作空间。
- 恢复已有测试约定：仅有列表摘要时，“最近测试成功”使用中性呈现，不能被渲染为真实连接资格已通过。

前端 `npm test`：18 个文件、149 项测试通过。`npm run lint`、`npm run build`（包含 TypeScript 检查）、`scripts/check-secrets.ps1` 和 `git diff --check` 通过。
