## 2. F0 验收记录

- 页面基线与路由：已覆盖首页、数据源、三类任务向导、任务、日志、模板、节点、系统设置与权限配置；节点详情和权限配置不再使用通用占位组件。
- 禁止伪造：没有业务数据时，页面使用空状态或“功能尚未接入”；不写入示例用户、节点、任务、日志、命令成功或真实连接事实。
- 契约边界：现有 `/api/v1` 覆盖首条数据源/导出/任务链路、节点最小声明配置和一次性 Agent 关联材料；节点浏览器写入不包含 Agent、心跳、环境、容量或管理状态。其余模块必须在相应工作包开始前建立服务端契约和失败关闭测试。
- F0 剩余条件：页面级对照已完成。若后续发现页面字段、低保真或契约冲突，应作为 F0 回归项处理，不能在 F1～F7 中静默偏离。

## 3. F1 与 F1.3 当前结论

数据源 F1、节点 F1.3 和受认证关联/心跳 F1.4 都只处于 G2：数据源真实成功测试/启用仍需要受认证 Agent 终态；节点材料只在一次 `no-store` 响应中展示，浏览器不能写心跳或环境事实，也不能把节点变为导出候选。

当前停止点是 G3/WI-06 真实验证门禁。导出 F2 不继续进入预检查、提交、任务或真实执行接入；恢复前必须由获授权真实节点完成固定 `EXPORT_PREFLIGHT`，并具备连接、对象、工具、路径和空间的可复核证据。
