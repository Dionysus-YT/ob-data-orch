# 产品页面功能接入计划

> 文档状态：执行计划基线  
> 更新日期：2026-07-23  
> 适用范围：已确认产品页面从低保真基线进入真实功能接入的顺序与验收  
> 权威关系：阶段与 G1～G4 门禁以 [开发任务地图](development-task-map.md) 为准；本计划不修改任何真实执行准入条件。

## 1. 目标与原则

当前页面基线已经覆盖首页、数据源、三类任务向导、任务中心/详情、日志、模板、节点与系统设置。下一步不是把所有按钮同时接到后端，而是按一条可验证链路逐项接入，并保持以下原则：

1. 先消除产品页面与已确认低保真、专项设计、字段规则之间的偏差，再接入数据和动作。
2. 没有已实现且受测试保护的服务端契约时，页面保留明确的空、加载、不可用或“待接入”状态；不得用样例数据、成功提示或可点击但无后果的操作伪造能力。
3. 已接入的浏览器功能只调用 `/api/v1` 的脱敏响应；页面不直接连接数据库、节点、文件系统或 Java/OB Loader/Dumper。
4. 每一个写操作均依既有契约处理认证、授权、CSRF、`Idempotency-Key`、`If-Match`、冲突与 `Cache-Control: no-store`；没有对应服务端校验则不能以页面限制代替。
5. 真实连接、真实凭据、真实工具、真实 Agent 或真实 ODP 行为仍受 G3/G4 门禁约束。本计划中的“功能完成”最多表示页面与 G2 合成链路完成，除非验收记录另有明确证据。

## 2. 当前基线与待接入边界

| 范围 | 页面基线 | 已允许的下一类工作 | 不应据此宣称 |
| --- | --- | --- | --- |
| 数据源 | 列表、表单、连接状态与测试入口 | 对齐已存在的安全摘要、写入与测试请求契约 | 已完成真实数据库连接测试 |
| 导出 | 六步向导与命令/预检查页面 | 对齐首条 CSV 导出草稿、预览、预检查与任务提交 | 已实现全部 109 参数或真实导出 |
| 普通导入 / 旁路导入 | 两条独立六步向导 | 只做字段规则与服务端契约准备 | 可提交或执行导入 |
| 任务与日志 | 任务列表、详情五区、日志查询工作台 | 读取已授权的任务、预检查和脱敏日志投影 | 真实调度、取消、重试或 SSE 持久日志 |
| 模板、节点、设置、权限 | 入口、低保真结构与空状态 | 补齐各自领域契约后按次序接入 | 已具备管理或运维能力 |

## 3. 实施顺序

### F0：页面基线收敛与契约对照

- 对象：所有已路由页面，补齐访问控制页面的低保真路由与空状态。
- 工作：逐页核对导航、标题、操作位置、空/加载/错误状态与已确认低保真；建立“页面字段 → 专项字段规则 → API 契约”的可追溯清单。
- 验收：不再存在工程验证页替代产品页、虚构业务记录、未确认能力或不可达的主入口。
- 非目标：不新增 API、数据库表或产品模块。

### F1：数据源管理闭环

- 依据：[数据源管理评审稿](../02-design/data-source-management.md)、[字段与条件规则](../02-design/data-source-field-rules.md) 与既有浏览器 API 契约。
- 工作：列表/筛选、创建、读取、编辑、启用/禁用/归档、受控测试请求与结果状态回显；统一处理 401、404、409、412、网络错误和空状态。
- 验收：密码始终只写不回显；数据源测试只表达基础连接事实；测试结果持久化语义未完成前不伪造最近测试时间或成功状态。
- 非目标：导入/导出权限诊断、对象级权限检查、性能诊断和任务可行性判断。

### F2：首条导出切片的浏览器闭环

- 依据：[导出模块](../02-design/export-module.md)、[导出字段规则](../02-design/export-field-rules.md)、[首条纵向切片](first-vertical-slice.md) 与 [API/SQLite 契约](api-sqlite-data-contract.md)。
- 工作：已有数据源选择 → 单表 CSV 草稿 → 脱敏命令预览 → 节点预检查 → 提交 → 任务详情与当前任务日志投影。
- 验收：字段依赖和互斥由共享元数据驱动；命令仅来自服务端确定性生成器；预检查和任务都绑定草稿 revision、配置指纹、节点与凭据 revision；真实执行入口保持门禁关闭。
- 非目标：导出全参数一次性落地、批量任务、定时调度、真实 OBDUMPER 成功声明。

### F3：任务中心、任务详情与日志读取能力

- 依据：[任务中心模块](../02-design/task-center-module.md)、[日志中心模块](../02-design/log-center-module.md) 及对应字段规则。
- 工作：权限范围内的列表/详情读取、可靠状态/阶段降级、不可变快照、脱敏命令、当前任务日志与日志中心带条件跳转。
- 验收：未知进程事实显示“状态核对中”；无可靠证据不显示百分比或 ETA；跨任务日志只在日志中心查询；不泄露无权任务、日志或数量。
- 非目标：取消、重试、检查点继续、跨任务全文检索、未脱敏下载与自动诊断。

### F4：执行节点的事实投影与任务选择

- 依据：[执行节点模块](../02-design/execution-node-module.md) 与字段规则。
- 前置：Agent 身份、心跳与环境事实契约具备可验证实现。
- 工作：节点注册关联、列表/详情只读事实、固定环境检查结果、任务选择时的可选性说明。
- 验收：不通过节点页面远程安装、执行命令、浏览文件或修改 `session.config.json`；离线不直接改写任务失败；不自动改派。

### F5：模板中心

- 依据：[模板中心模块](../02-design/template-center-module.md) 与字段规则。
- 前置：F2 的草稿/快照/参数元数据读取链路稳定。
- 工作：模板列表、创建、编辑、复制、删除、兼容状态和“使用模板创建新草稿”。
- 验收：模板类型不转换；不保存凭据、节点、预检查、命令、日志或结果；使用模板永远重新校验且不直接执行。

### F6：普通导入与旁路导入

- 依据：各自专项方案、字段矩阵、参数映射和受控验证计划。
- 前置：对应参数具有官方适用证据，且普通导入/旁路导入的服务端模型、命令生成与预检查契约分别已评审。
- 工作：按独立六步向导逐步接入，复用共享的状态、命令、预检查和任务交互，不复制不适用参数。
- 验收：普通导入不生成 `--direct` / RPC 专属参数；旁路导入坚持 SQL/RPC 分开、唯一目标表、整体提交且不显示检查点继续；未核实项统一保持“待官方参数映射确认”。

### F7：系统设置与权限配置

- 依据：[系统设置模块](../02-design/system-settings-module.md)、[权限与安全模块](../02-design/access-control-security-module.md) 及字段规则。
- 前置：身份、固定角色、对象范围、审计、配置版本与安全设计具有服务端失败关闭实现。
- 工作：只读生效值、分区原子编辑、版本冲突处理、固定角色与对象范围管理、高风险能力受控确认。
- 验收：密钥永不可见；设置不回写历史任务；权限不以 UI 隐藏替代服务端校验；不建设 IAM、审批流或通用配置发布系统。

## 4. 与 G3/G4 的关系

F0～F7 是页面与 G2 服务端能力的接入顺序，不替代 G3/G4。只有 [开发任务地图](development-task-map.md) 中的 DEV-07 前置条件满足后，才可在获授权的非生产 Windows 环境验证 F1/F2 的真实连接和真实导出；三个麒麟目标的原生运行、恢复与发布仍按 DEV-08/DEV-09 独立验收。

## 5. 每个功能小步骤的交付格式

每次只选择一个页面动作或一条读写链路，并在交付中记录：

1. 对应的产品规则、字段规则、低保真与 API/领域契约；
2. 修改范围及未做内容；
3. 自动化测试、浏览器视觉核对和负例；
4. 页面状态（基线 / G2 合成可用 / 真实验证通过 / 门禁阻断）；
5. 下一条唯一可执行的工作项及外部前置条件。
