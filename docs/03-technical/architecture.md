> 文档状态：待技术评审  
> 适用范围：V1.0 首条纵向切片及后续三类任务共用基础

## 1. 设计目标

技术架构需要支持数据源管理、三类任务配置、参数元数据、完整命令、预检查、执行节点、任务状态、日志、模板、权限和系统设置，同时保持轻量、可测试、可追踪和可回退。

首版不建设微服务平台、通用工作流引擎、通用数据迁移引擎、远程运维平台、日志分析平台或 IAM 平台。

## 2. 候选架构结论

采用“模块化单体控制面 + 独立执行 Agent”作为首版候选：

```text
浏览器
  ↓ HTTPS
控制面应用
  ├── 认证与权限边界
  ├── 数据源管理
  ├── 参数元数据与配置校验
  ├── 命令生成与脱敏预览
  ├── 任务与调度
  ├── 节点管理
  ├── 日志与审计入口
  └── 模板与系统设置
  ↓ 持久化                         ↓ 受认证任务通道
关系型元数据存储                   执行 Agent
                                   ├── 环境事实与心跳
                                   ├── 工作目录与进程管理
                                   ├── OB Loader/Dumper 启动
                                   └── stdout/stderr/工具日志采集
```

选择模块化单体是为了减少当前轻量项目的部署、事务和排障成本；执行 Agent 独立是因为工具、工作目录、日志和资源事实位于执行节点，不能由控制面服务器伪造或直接替代。

该结论是技术设计候选，不代表语言、框架、数据库产品、消息组件或部署平台已经选定。

## 3. 组件职责

| 组件 | 负责 | 不负责 |
|---|---|---|
| Web 界面 | 已确认页面、字段条件、命令脱敏预览、任务与日志查看 | 拼接未经服务端校验的命令、保存敏感明文 |
| 控制面 API | 权限校验、业务规则、快照、任务编排和审计 | 直接在控制面服务器执行 Loader/Dumper |
| 参数元数据模块 | 参数名称、类型、层级、模式适用性、条件、风险和版本 | 猜测未验证参数行为、在线任意编辑参数定义 |
| 配置校验模块 | 字段条件、互斥、依赖、活动值、提交门禁 | 用前端隐藏代替服务端校验 |
| 命令生成模块 | 从不可变活动配置确定性生成参数序列和脱敏预览 | 接受任意命令片段、静默增加用户未选择参数 |
| 任务与调度模块 | 草稿、提交快照、等待、分配、状态核对和派生任务关系 | 自行扩展官方工具执行能力 |
| 节点管理模块 | Agent 关联、四维状态、环境事实、容量和状态化操作 | SSH、远程终端、工具安装升级或自动调参 |
| 执行 Agent | 启动受控工具进程、采集事实、报告状态和日志 | 决定产品参数、越权读取其他任务或数据源 |
| 日志入口 | 保留真实来源、时间、完整性、权限和脱敏语义 | AI 诊断、跨来源因果推断、未脱敏下载 |
| 凭据边界 | 安全引用、短时解密使用、审计和清理 | 将密码、密钥、Token 或 sys 凭据写入任务快照、模板或普通日志 |

## 4. 核心工程不变量

1. **参数元数据版本化**：每个任务快照记录使用的工具目标版本和参数元数据版本。
2. **命令生成确定性**：相同活动配置、派生事实和元数据版本必须生成相同的参数序列；参数顺序规范化。
3. **提交快照不可变**：提交后配置、命令、数据源非敏感摘要和节点事实不被原对象变化回写。
4. **计划命令与实际命令分离**：两者分别保存脱敏证据，并记录平台运行时增加内容的来源。
5. **无证据不开放**：P0 未通过或环境阻断的参数组合保持隐藏、只读或阻断。
6. **服务端重复校验**：字段条件、权限、对象范围、预检查和风险确认不能只依赖前端。
7. **状态来自事实**：任务终态、进度、结果和节点状态只能来自已确认事件、进程或工具证据。
8. **失联不等于失败**：Agent 或日志通道中断时保留最后可信状态并进入核对，而非直接判定任务失败。
9. **秘密不进入普通数据面**：凭据不进入 URL、命令预览、日志、审计正文、模板或 Git。
10. **所有高风险操作可审计**：权限变更、生产提交、敏感命令查看、节点维护和配置高影响保存均保留结构化审计事实。

## 5. 首条切片运行序列

```text
用户选择已有数据源
→ 控制面校验对象权限与数据源可用状态
→ 用户配置基础 CSV 导出
→ 参数元数据计算活动字段并完成服务端校验
→ 预检查连接、对象、输出路径和执行节点事实
→ 命令生成模块产生计划命令与脱敏预览
→ 用户确认后固化任务快照
→ 调度选择已确认可接收任务的节点
→ Agent 取得一次性执行上下文并启动 OBDUMPER
→ Agent 回报进程、阶段、日志和结果事实
→ 控制面形成任务终态、实际命令证据和日志入口
```

首条切片不包含 POS、ORC、Parquet、Avro、对象存储、检查点继续、自动取消、旁路导入或高级调度。

## 6. 概念数据边界

本阶段只定义概念实体，不创建数据库表：

| 实体 | 关键边界 |
|---|---|
| DataSource | 保存基础连接信息、环境、类型和凭据引用；不保存任务权限诊断结果 |
| ParameterMetadataVersion | 保存目标工具版本下的参数定义、适用状态和来源证据 |
| TaskDraft | 可编辑配置；引用数据源和元数据版本，不包含运行事实 |
| TaskSnapshot | 提交后的不可变配置、派生摘要、确认和计划命令证据 |
| TaskExecution | 分配节点、状态、阶段、进程和终态事实 |
| ExecutionNode | 管理状态、Agent 事实、环境事实、容量和资源快照 |
| LogRecord | 真实来源、来源时间、接收时间、级别、脱敏正文和完整性 |
| CredentialReference | 指向安全存储的引用和用途范围，不包含可展示明文 |
| AuditEvent | 主体、动作、对象、范围、时间、结果和非敏感差异 |

## 7. 安全与通信候选

- 浏览器只与控制面通信，不直接连接执行节点或数据库；
- Agent 使用主动向控制面建立的认证通道候选方案，避免控制面开放 SSH 或远程终端；
- 数据源连接测试和任务预检查在明确执行位置运行，并记录执行位置和时间；
- 执行上下文使用短时授权，任务结束、取消确认或超时后清理；
- 页面、复制、下载、日志和审计复用同一脱敏语义；
- 生产任务和敏感命令继续要求独立权限、对象范围、二次确认和审计。

Agent 通道协议、双向认证、凭据安全存储、密钥轮换、审计写入失败策略仍待安全技术评审。
