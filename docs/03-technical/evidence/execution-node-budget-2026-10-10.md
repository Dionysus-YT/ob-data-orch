## 使用与未验证边界

- 默认系统预留 `max(2 GiB, 总内存20%)`、堆外预算 `max(1 GiB, 实际堆25%)` 是可配置工程选择，尚未经用户确认或负载测量，不能保证 RSS/CPU/磁盘承载。CPU/磁盘图是事实展示，不作未经验证的硬阈值调度。
- 当前节点提供官方默认 4G，任务允许覆盖；没有可编辑的节点默认堆。真正的并发数取决于各任务堆、开销与当前可用内存，技术 Worker 上界不是同等大小任务的承载数。
- 控制面、迁移链与 Agent 必须配套升级。当前运行服务未替换、正式库未迁移；旧 Agent 缺资源事实或旧执行分配未知时保持待核对并阻断新领取。
- FIFO 不跳过超预算队首；无自动缩堆或跨节点迁移。待核对资源不擅自释放，也不新增强制清账入口。此限制优先保障不重复启动、不超分配。
- 初始管理员可信角色/能力已接入；真实多账号身份部署和撤销传播未验证，不提供新账号管理。全局只读能力不豁免任务写入、安全材料或日志脱敏契约。
- 未执行真实 Agent/OBDUMPER 并行、数据库/凭据操作、物理 RSS 压力及异常进程树恢复验证；未执行全仓 verify、远端 CI 或 Linux 原生验证，不将历史平台/Token/Go CI 阻断描述为已解决，不提升 G3/G4。
