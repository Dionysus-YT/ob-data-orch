# DEV-05 Agent 本地合成适配验证

> 验证日期：2026-07-22
> 验证环境：Windows AMD64、Go 1.26
> 准入级别：G2 合成/隔离验证
> 结论：固定预检查、私有工作区、写前意图、假工具事实与安全清理可在本地合成测试中闭环；不构成真实导出、真实进程或目标平台验证

## 1. 目的与范围

本次验证只落实 DEV-05 的最小必要能力：Agent 在不执行任何真实命令前，固定检查 `EXPORT_PREFLIGHT`；假工具以结构化合成事实模拟成功、失败和中断；执行材料仅在私有临时目录中创建和清理。

不使用真实数据库、真实凭据解析、真实 OBDUMPER/Java/OS 进程、真实网络或真实 Agent HTTP 通道。默认 `cmd/agent` 仍保持空闲且真实执行功能门禁继续关闭。

## 2. 最小实现与对抗性验证

| 能力 | 合成验证事实 | 反例与结论 |
|---|---|---|
| 固定预检查 | 仅执行数据库连通、对象访问、工具环境、输出路径、输出目录为空和可用空间六项枚举 | 未知能力、活动 execution、旧/漂移绑定、非绝对路径、未知状态和非安全摘要均失败关闭；失败时假工具启动次数为 0 |
| 写前意图 | `start-intent.json` 先于假工具 `Start` 写入 execution 私有 `evidence/` | 意图重复、损坏或缺少恢复身份被拒绝；不允许覆盖后再次启动 |
| 假工具终态 | 合成 PID、开始时间、可执行文件摘要、工具终态和结果事实形成有序事件 | 成功要求进程结束 + 工具成功 + 结果已核对；工具失败投影为失败；中断、未知启动错误或不完整证据仅进入核对中 |
| 材料清理 | 使用合成安全材料和启动意图的私有工作区 | 未完成证据时不清理；目录存在额外残留时返回隔离结论，不伪造清理成功 |

所有新增持久化意图字段只允许不透明 ID、时间、epoch 和 64 位 SHA-256 摘要；测试同时拒绝可能携带秘密的摘要或证据码。探针与假工具的内部错误被稳定错误码替代，不向上层传播原始消息。
