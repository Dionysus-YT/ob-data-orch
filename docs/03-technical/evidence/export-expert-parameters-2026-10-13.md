## 接入与边界

- 四项开关接入唯一表单、请求 DTO、服务端资格、指纹、预览、预检查和冻结执行；sequencePolicy 只在序列定义/整库结构活动，PRESERVE/RESTART 映射官方小写枚举。
- 九项格式字段按租户和 CSV/CUT/SQL 内容活动；Oracle NLS 会话格式与文件值格式独立。DATE 的工具默认值随兼容模式不同，页面使用“按租户模式”表述，避免把 MySQL 默认描述用于 Oracle。
- 新目录 v11 继承 v10，覆盖 13 项（包括整库 CUT/SQL 的 --all 映射）、增加四项，共 79 定义。旧元数据不改写，旧草稿明确加入新参数时原子保存新版目录、能力和指纹；不静默改历史预览。
- JDBC v6 的固定只读探针核对弱读、OB 版本/主键元数据/隐藏列以及 sys TABLEGROUP 视图权限。不接收外部 SQL 或 JDBC URL，不返回源行或原始异常。启用相应参数必须取得专用 OBJECT_ACCESS 通过证据，普通对象可读证据不能替代。
- sys 引用由迁移 0026 冻结并参与预检查摘要；提交内部快照引用精确匹配，浏览器白名单投影不披露。响应前再次复验 sys ACTIVE 修订、授权与租约，撤销/轮换阻断旧材料。
- sys 密码进入官方任务级 RSA 加密属性，实际 argv/环境/SQLite/日志没有密码；普通 sys 账号只在内部官方 argv 使用，浏览器命令、复制与日志遮蔽。存储、线协议和直接 Java 启动均拒绝 sys 密码令牌。令牌预算调整为 160，覆盖参数目录且保持上限。
