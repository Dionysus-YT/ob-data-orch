# Windows Agent 中断与恢复验证（2026-08-04）

> 验证状态：取得部分现场证据；日志补传恢复未通过；不是 G3 通过证明。
> 适用范围：用户授权的非生产 `test` 数据源、固定单表 CSV 与 Windows AMD64 本机。
> 关联：F2、F3、WI-03、WI-07、WI-10、WI-12。

## 1. 范围与安全控制

- 使用两个临时、独立关联的 Windows Agent 身份和新的空输出目录；没有停止或强制终止原有常驻 Agent。
- 中断仅发送到测试 Agent 新建进程组的 `CTRL_BREAK_EVENT`；不使用强制结束进程，也不触碰控制面服务。
- 验证仅读取任务安全投影、进程存在性、队列文件数量/字节数和输出文件元数据；不读取 CSV 业务行、原始日志、凭据或完整执行命令。
- 临时 Agent 工作目录和输出目录保留给用户复核；本记录不包含连接表达、注册码、密码、原始日志或任务标识。

## 3. 未执行与阻断理由

- **长期控制面不可达：未执行现场网络分区。** 现有连续不可达、顺序重放和容量上限证据来自隔离 TLS 假控制面与常规 Agent 二进制。对共享本机控制面断网或停服会影响原有 Agent 和用户页面，当前授权不包含该破坏性操作；不能用合成结果替代现场通过。
- **跨平台：未执行。** 当前只具备 Windows AMD64 本机与已授权窗口；三个麒麟目标机、服务账户和受控窗口均未提供。交叉构建不构成验证。
- **低权限账号与 CSV 特殊值：未执行。** 当前没有获授权的低权限测试身份，也未读取导出内容。
