本地源码与合成验证完成；没有替换本机运行中的控制面或 Agent，没有开展本项目的真实数据库、凭据、OBDUMPER 或云厂商认证验证。真实功能与 EX-V1 准入不能由这些结果外推。

## 用户确认与行为

用户确认目录检查失败时继续独立检查、进入第五步自动预检查、结果为主且配置摘要可折叠；后续明确要求学习内嵌 OMS 的预检查设计，完整命令不可折叠。五步外壳、唯一表单、命令生成器与提交确认沿用既有能力。

| 检查 | 实际依赖与失败行为 |
| --- | --- |
| 工具、输出路径、目录空性、空间 | 先收集无秘密事实；目录或空间失败不阻断数据库组。无法安全定位导出目录时，空性和空间记为未执行；日志路径失败不阻断合法导出目录的独立事实 |
| 数据库连接 | 工具环境通过后才可解析当前租约的 DATABASE_CONNECTION；工具未通过则不解析、不启动固定 JDBC |
| 对象与参数访问 | 依赖数据库连接；连接失败或未知则不调用对象 Probe。既有一次进程/连接的固定 JDBC 范围不扩大 |
| 存储端点 | 独立于本机和数据库组；既有运行开关与受控 endpoint 授权不变 |
| 存储认证 | 端点通过、冻结存储引用及认证探测器明确需要凭据后才能解析 STORAGE_CREDENTIAL；默认探测器仍不解析凭据 |

新增四个 `PRECHECK_BLOCKED_BY_*` 证据码说明未执行，只允许合法依赖项的 UNKNOWN。报告保持固定六项、三态与顺序，FAILED/UNKNOWN 都阻断提交，未增加 SQLite 迁移、通用检查或自由文本。

自动检查由 `useExportDraftLifecycle` 持有：等待保存、回填和命令准备就绪，同一表单版本只自动尝试一次；失败手动重试，同配置往返保留正在进行或完成的结果。读取失败保留原标识并恢复读取，不重复发起；回执标识不一致、字段变化、节点 A → B → A 和卸载均拒绝迟到响应。完整清单、草稿修订、指纹、节点、命令及有效期共同决定提交资格。到期只使本地资格失效，不伪造服务端状态或自动探测。

页面采用 Ant Alert、原生四列检查表格、摘要 ghost Collapse、常驻命令区和已有 Footer；失败原因只展示一份，修正入口回到相应步骤。等待阶段的占位 UNKNOWN 保持等待结果，失败、依赖阻断、无法确认和按配置跳过分别呈现。第五步进度按 PASSED 事实计数，失败和阻断不会显示为全部完成。
