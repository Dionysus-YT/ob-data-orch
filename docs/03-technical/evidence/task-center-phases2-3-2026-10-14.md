# 任务中心后续阶段实施与合成验证 · 2026-10-14

范围为用户明确授权的“日志清理 → 任务详情 → 草稿列表”，同时修复时间控件及中文月份。任务中心与任务详情遵守已确认 P1，复用数据源工作面、Ant 控件和 P0 Token；未修改 Product Shell 或全局设计 Token。

## 本地实现

- 时间由原生 date input 改为 Ant RangePicker，支持今天、昨天、最近 7 天、最近 30 天、本月及部分区间。注册 Dayjs `zh-cn`，日历月份/星期及预设中文，输入为 `YYYY-MM-DD`。使用已有 Ant 间接依赖的同版本 Dayjs 1.11.23，声明直接依赖，许可证 MIT，只影响浏览器。
- 模板名称及日期错误归 Form.Item；操作菜单与确认沿用 Ant。领域菜单补齐方向键、Home/End、Escape、焦点归还、对象变化及迟到打开隔离，不引入基础控件 Wrapper 或全局通知状态。
- 日志：默认 30 天、7–365 天配置，从结束时间起算；排除运行中、取消中、待核对。0028 账本采用 `DELETING → 删除文件 → 索引确认 DELETED`，启动/每小时按 64 段分批清理，崩溃可恢复。只删除日志根内已核验普通段；读取互斥，未知缺失/损坏不冒充过期，迟到上传不能重建索引。任务、快照、结果、操作和审计保留。
- 详情：稳定对象头、单一详情事实、五个 Ant Tab 及 query；运行概览用三组 Descriptions。冻结配置通过五步白名单，路径仅创建者可见，凭据引用隐藏；大 SCN 保持整数精度。日志支持本地过滤、明确 ERROR 定位、自动滚动暂停/恢复和过期说明；操作记录从既有安全审计/事件投影分页，拒绝事件标记 DENIED。终态停刷、不可见暂停、授权失效清空；写事务结束句柄绑定会话，旧 finally 不释放新任务暂停。
- 成功任务开放基于原配置新建，失败/取消任务开放对应派生；核对或命令摘要不一致时关闭。检查点继续成功跳转新任务，修复字符串路由被当作提示的回归。
- 草稿：`/tasks?tab=drafts` 仅当前主体的未提交且未删除记录，关键字/数量/游标同一所有权谓词；继续编辑/提交进入既有向导步骤 1/5，重新读取并预检查。0029 删除标记保留历史引用；CSRF、版本、幂等及活动/未知租约均复验，删除/预检查失效/审计/回执原子提交。
