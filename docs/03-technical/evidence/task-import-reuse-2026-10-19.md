# 任务中心与普通导入复用闭环修复 · 2026-10-19

用户要求从全局审查导出与普通导入的一致性，并明确授权修复审查发现的六项问题。本轮完成源码与隔离合成验证；不包含现役控制面/Agent 安装、运行库升级或新的真实数据库、存储与官方工具验证。工作树包含用户原有未提交改动，未提交或推送。

## 修复范围与结果

| 问题 | 完成后的行为 | 主要能力所有者 |
| --- | --- | --- |
| 普通导入草稿保存后缺少管理入口 | 统一“我的草稿”按真实类型恢复、删除，所有权、关键字、计数与游标由同一 SQL 查询范围约束；普通导入不取得导出提交快捷入口 | `useTaskDraftList`、`listOwnedTaskDrafts` |
| 普通导入终态缺少配置派生与模板链 | 可信成功任务支持新建/保存模板，失败或取消支持新建/从头重跑；响应携带类型，普通导入进入独立向导和检查链 | `importdomain/reuse.go`、`normal_import_reuse.go`、`useTaskListActions` |
| 模板首次使用先出现空候选/必填错误 | 先选择模板，再原子加载其类型的源/节点候选；绑定完整后显式创建草稿，刷新候选不关闭已打开的节点下拉 | `useTemplateDraft` |
| 节点目录说明只提导出 | 改为“任务数据目录白名单”，说明导出写入与普通导入读取各需权限；不改变路径形式、目录范围或 Agent 约束 | `nodePlatformRules`、节点表单/详情 |
| 任务详情手动刷新无反馈 | 手动刷新加入既有单链读取，在途显示 loading/disabled/aria-busy，成功显示“已刷新”；切换对象、授权失效和卸载清除旧反馈 | `useTaskDetail` |
| 任务详情页签键盘操作缺失 | 与节点详情共用无状态键盘导航，方向键及 Home/End 更新焦点、选中页签和 URL，不接管面板输入 | `antTabKeyboard` |

两类任务继续共用已定版的对象头、详情工作面、五个 Tab 与三组事实布局；字段和结果仍分别使用输入/输出与自身工具语义，详见[详情布局修正证据](task-center-phases2-3-2026-10-14.md#2026-10-19-导出与普通导入详情一致性修正)。本轮未修改全局 Token 或页面 Archetype；共享 `WizardFrame` 只增加导航锁定输入，消费现有重跑资格，不决定业务状态。

## 契约与安全边界

- 新增 `GET /api/v1/task-drafts` 及 `config-templates` 的列表、改名、删除、创建草稿入口。旧 `export-drafts` / `export-config-templates` 路径保持导出限定，普通导入不能经旧路径获取或使用模板。浏览器拒绝未知类型和派生响应类型不符。
- `0032_task_config_templates.sql` 仅前向增加模板类型、索引和不可变约束，历史记录默认为导出；没有改写历史迁移。迁移目录现在为 32 项，OpenAPI 为 92 个操作，对应既有完整性断言已同步，未移除门禁。
- 普通导入从当前支持版本的冻结快照只提取独立配置，清除任务名称；模板默认清除数据源和节点，保留显式路径。秘密、输入清单、旧预检查、风险确认、租约与运行结果不进入复用配置。切换源模式或节点平台时不静默丢弃参数或转换路径。
- 派生事务重新读取来源授权、可信终态及原配置，原子写入来源关系、审计与幂等回执；提交再核对草稿来源。模板持久化事务核对可信成功来源和精确安全配置，审计资源分别使用导出/普通导入类型。
- 从头重跑锁定原配置，直接进入第五步重新预检查；步骤栏、返回/保存和预检查修改入口与锁定一致。方法与仓储都拒绝配置改写，保存响应丢失来源关系也不能解除锁定。相同配置允许重新绑定当前引用事实；需要调整参数时从来源任务“基于原配置新建”。
- 统一列表与普通导入删除都阻断活动或无法判定过期时间的租约。列表不泄露配置、路径、命令或凭据，跨主体查询/写入维持不存在语义。
- 模板选择、候选、绑定、写响应与详情读取继续按会话版本隔离，覆盖 A → B → A、权限撤销、重复请求、迟到成功/失败/finally 与卸载。没有引入共享 Wizard Engine、全局状态或网络入口。
