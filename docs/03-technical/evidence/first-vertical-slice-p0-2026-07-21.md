## 4. OBDUMPER 运行发现

### 4.1 Windows 本地库发现

首次运行在连接数据库后报错：

```text
org.apache.hadoop.io.nativeio.NativeIO$Windows.access0(Ljava/lang/String;I)Z
```

工具包包含 `hadoop.dll` 和 `winutils.exe`，但 Windows 启动脚本没有把其目录加入本地库搜索路径。临时补充路径后，工具能够继续到表元数据查询和任务拆分。

### 4.2 Windows 文件 URI 阻断

分别验证了默认嵌套输出、`--no-nested-dir` 和标准 `file:///E:/...` 输入，工具最终都构造出以下错误路径：

```text
file://nullE:/...
```

错误发生在 CSV 文件创建阶段，不是连接、认证、表不存在或磁盘空间不足。现有证据不足以批准 Windows 作为首条切片执行节点。

### 4.3 退出码不可信

多次工具日志均记录 `System exit 1`，但 `obdumper.bat` 返回 0。Agent 必须结合受控 Java 进程、工具终态日志、结果文件和任务事实判断结果，不能只读取批处理退出码。

## 5. 安全发现

- OBDUMPER 参数回显把密码显示为 `******`；
