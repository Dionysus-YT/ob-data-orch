# DEV-06 最小前端业务链路验证

> 验证日期：2026-07-22
> 验证环境：Windows AMD64、Node.js 24.16、npm 11.13、Go 1.26
> 准入级别：G2 合成/隔离验证
> 结论：最小前端已安全接入现有浏览器 API 投影；不构成真实认证、真实预检查、真实执行或目标平台验证

## 1. 范围与最小设计

页面仅覆盖一条固定路径：读取已授权数据源摘要，创建或更新单表 CSV 草稿，读取控制面脱敏命令预览，发起和查询预检查，提交冻结任务，并读取任务详情与已脱敏日志快照。

前端不提供普通导入、旁路导入、模板、调度、取消、重试、系统设置或真实执行按钮；也不保存密码、用户名、密文、凭据引用、原始日志或未脱敏命令。数据源 API 的浏览器投影已同步移除用户名，前端只解析显式白名单字段。

## 2. 对抗性处理

| 风险 | 实现与验证结论 |
|---|---|
| 未配置身份/CSRF | 写请求只有取得运行时 CSRF 元数据时才发送；缺少元数据返回本地安全错误，不生成伪造令牌。 |
| 旧草稿或并发写入 | 写请求带 `If-Match`；409/412 显示刷新提示，客户端不自行重试或覆盖。 |
| 无权或不存在对象 | 401 和 404 使用不枚举资源的通用提示；不显示响应体或请求标识中的对象详情。 |
| 命令和日志泄露 | 不读取 `argvTemplate` 等非必要字段；命令与日志在展示前执行第二层模式检查，失败时隐藏内容。 |
| 真实执行误导 | 页面固定显示 G2 与真实执行未开放；提交仅调用既有任务冻结 API，页面不连接数据库、Agent 或工具。 |
| 未实现节点 API | 不创建本地节点数据；节点标识由已登记节点事实提供，失败保持服务端 404 语义。 |

## 3. 已执行验证

```powershell
go test ./internal/controlplane/...
./scripts/check-secrets.ps1
Set-Location web
npm test
npm run lint
npm run typecheck
npm run build
```

2026-07-22 结果：上述命令均通过。浏览器在 `http://127.0.0.1:4173/` 进行了桌面和 390px 宽度渲染检查：页面标题、G2/真实执行门禁、数据源空态、草稿字段校验和任务查看控件均可见，控制台未记录相关 warning 或 error。

本地 Vite 页面没有连接已配置浏览器身份的控制面，因此数据源读取展示“无法连接控制面”的失败态。这是预期的失败关闭结果，不是数据源为空或真实 API 成功的证据。

## 4. 未验证与门禁

- 未验证运行时浏览器会话、CSRF 元数据注入、执行节点列表或完整 OpenAPI 响应 schema；
- 未验证真实 Agent 预检查、SSE 日志、持久日志段、真实任务执行或真实数据库/凭据；
- 未在 Windows 真实控制面或三个麒麟目标完成端到端验证。

因此 DEV-06 只证明 G2 前端/API 客户端与本地渲染质量；WI-01～WI-12、G3、G4 和生产发布继续阻断。
