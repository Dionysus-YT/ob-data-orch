# 系统管理父子导航验收 · 2026-10-23

本轮按用户明确要求及 [DEC-061](../../01-product/decisions.md#dec-061-系统管理父子导航与模块边界)，将侧栏调整为可展开的“系统管理”，下设系统设置、权限配置、存储凭据三个独立子项。父级不跳转聚合页面，权限配置移出设置分区并去掉返回设置按钮，原三个深链接兼容。没有增加截图中的未准入模块。

本记录是后续导航变更的独立证据；[权限首批验收](access-control-2026-10-23.md)及其原始指纹保持为此前版本，不作为当前导航的截图证据。

## 实现与边界

- `ProductShell.vue` 只装配父级导航；`ProductSystemNavigation.vue` 持有分组、当前子项、展开和弹层焦点状态，不依赖业务模块或持有业务表单。
- 200px 完整导航使用缩进子项，48px 图标轨使用 Ant Dropdown/Menu；路由和布局变化关闭旧弹层，键盘支持展开、方向键、首尾、Enter、Escape 与焦点恢复。
- 系统设置保留平台基础、调度、安全策略和工具兼容四个分区；权限配置仍只管理已有认证主体的授权；存储凭据保持自己的生命周期。未改变后端、API、权限策略或保存事务。
