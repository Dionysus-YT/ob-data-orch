# 权限配置首批本地验收（2026-10-23）

结论：本地实现与本首批 G2 合成验收通过。入口为“系统设置 → 安全 · 权限配置”（`/settings/access-control`）。这不是完整权限与安全模块、真实多用户部署或现役服务升级的验收。

## 交付范围

- 固定五类角色；数据源使用/管理、节点使用/管理、按数据源关联的任务运维、模板使用/管理七种可新增范围。空范围允许保存但不产生对应对象授权；不接受通配符、未知或重复项。独立能力与 `NODE_OPERATE` 只保留/撤销旧记录，新增在客户端与服务端均阻断。
- 身份、账号状态只读；权限管理员只能修改其他主体。未知/停用主体仅允许集合收缩。最小候选目录只含 ID、名称、类型、环境和可新增状态，不包含地址、账号、路径、命令、凭据或任务内容。
- 全量替换使用 CSRF、If-Match、独立幂等键、必填原因和风险确认。角色依赖清理纳入保存前差异；系统管理/生产范围提示风险。版本冲突保留草稿并阻断覆盖，失败不宣布成功；旧回执只确认原提交并重新读取当前版本。
- 授权、版本、未提交草稿的预检查失效、成功审计和幂等回执在同一短事务；审计失败回滚。当前角色/范围参与业务请求、待领取任务与执行材料复验，不以缓存或提交快照替代当前权限。
- 新任务首次 INSERT 冻结本任务的权限版本和范围摘要，保留既有不可变触发器；历史不回填。撤权不取消已领取执行，不改写历史。全局只读提示在实际 SQL 中复验当前初始部署身份及角色，普通系统管理员不能继承全局业务读取。
- 模板使用不能改名/删除，管理不能自动派生；共享模板隐藏原来源任务。创建者的具体范围、版本与审计随对象创建原子提交。首页任务分区受限显示未授权，保留独立节点授权，不能显示可信零值或误报读取失败。

## 发现与修正

首次实现把冻结权限写成插入后的 UPDATE，被既有任务不可变触发器拒绝；已改成首次 INSERT 同时冻结，保留保护。旧正向授权夹具补充显式 DATA_SOURCE_USE；迁移校验和测试纳入 0035，使测试继续验证旧迁移变更拒绝。范围控件补齐标签关联，嵌套确认使用产品焦点栈；保存后的目录复验结束再恢复行操作焦点。长字段收敛为省略显示；首页明确区分未授权与读取失败。

收尾另发现普通 Oracle 日期格式也可能使用新版元数据。专家资格因此改为冻结领域层的实际分类，并保留历史未知时的收缩判断；普通日期格式与 `--query-sql` 不因版本被升级为专家能力。新分类以及原执行材料回执在撤权后不得复用均有负例；恢复路径通过既有检查点回归覆盖。

原生浏览器的页面断言曾通过但回收超时；最终使用短路径的独占临时配置目录、关闭本例独占浏览器、清除该目录，主批次最终无超时或重试。一次清理脚本被策略阻断，改为已核验固定目录且去掉强制参数的精确删除后成功，删除结果已复核。期间全仓 lint 曾受本轮未创建的首页临时探针阻断；没有修改该文件，工作区随后移除该探针，最终全仓 lint 重跑通过。

隔离 Vite 仍记录已知 `ResizeObserver loop completed with undelivered notifications` 诊断及工具颜色环境提示；正式构建仍有大于 500kB 的分块提示。页面与交互断言通过，不据此宣称零诊断或全面完成性能优化。
