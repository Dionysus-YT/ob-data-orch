# 模板中心现役重设计与本地验收（2026-11-02）

本轮完成现役范围内的模板中心实现、合成验证及页面验收。用户定版、现役安装、真实业务复验与发布分别判断：本轮没有安装、部署、变更现役 SQLite、连接真实数据库/存储或运行官方工具，不提升 EX-V1/NIV/DLV/G3/G4 门禁。

依据为 [DEC-069](../../01-product/decisions.md#dec-069-模板中心按现役能力重定义)、[模块设计](../../02-design/template-center-module.md)、[页面 P1](../../../design-system/pages/template-center.md)、[P0](../../../design-system/MASTER.md)与数据源定版复用规则；当前阶段见[任务地图](../development-task-map.md#template-center-redesign)。

## 实现与职责

- 只覆盖导出、普通导入成功任务保存的模板。模板中心提供名称/类型筛选、完整授权集合内每页 10 条、使用抽屉、改名和删除。来源缺失显示“—”；技术信息默认折叠。未增加手工创建、复制、参数编辑器、固定源策略、兼容服务或旁路模板。
- 目录事实、筛选/分页和共享写锁归 `useTemplateCatalog`；改名/删除各自的输入、冲突与确认归 `useTemplateActions`；模板绑定、候选、创建身份和已创建草稿归 `useTemplateDraft`。页面与两个业务弹层只装配和发出意图，不另持可写业务副本。
- `availableActions` 是当前既有 USE/MANAGE 的最小只读投影，分别裁剪创建草稿与改名/删除。缺少字段兼容为只读，未知或重复值拒绝；服务端写入仍复验。撤权清空旧事实/会话，撤权前的读取及旧 finally 不能恢复权限或释放新事务。
- 保存模板的幂等摘要包含任务 ID 与裁剪后的名称；由模板创建草稿的摘要包含模板、数据源和节点 ID。使用 JSON 数组的 SHA256，避免拼接分隔符碰撞。同键同内容重放，异名称/异绑定冲突。
- 保存和创建由当前业务会话持有原键，30 秒有界等待；超时、响应丢失或不可信响应保留结果未知，锁定原内容，显式重试沿用原键。未知后的后续拒绝不证明原请求失败。确认创建后若导航失败，保留 draftId，只重新打开，不能再次 POST。关闭、切换、撤权和卸载使旧会话失效；本轮未增加跨刷新持久恢复。
- 使用模板必须显式重选数据源与节点。普通导入消费自身候选及独立向导；创建只得到同类型可编辑草稿，凭据、预检查和风险确认不继承。新增操作资格同步 OpenAPI，没有新路由、表、迁移、授权能力或 Agent 协议。

维护入口：[模板](../../../web/src/workbench/templates/README.md)、[任务保存入口](../../../web/src/workbench/tasks/README.md)。API 只负责协议与安全摘要，不持有重试状态。

## 失败记录与修正

- 首次浏览器进程受继承的 `socks5:` HTTP 代理影响，在页面验收前失败。仅在隔离测试子进程清空 HTTP/HTTPS/ALL_PROXY，NO_PROXY 限回环；未更改用户代理配置，也未访问真实外部服务。
- 表单首轮发现标签未关联控件，已用原生 Ant Form 的 name/model 与命名字段修复。之后用例修正为通过可访问名称聚焦 Select 并用方向键展开，匹配必填标签；未使用强制点击跳过实际交互。
- 两个业务生命周期用例沿用旧展开导航，已按当前默认收起及 48px 菜单语义修正夹具，保留原迟到/卸载与页面切换断言。
- 长值测试曾因前一 Tooltip 退场动画同时存在而严格匹配失败，改为精确完整值匹配，保留键盘读取要求。API 参数化用例类型形状曾导致构建失败，修正为对象矩阵后，该文件与最终类型/生产构建通过。
- 早期 `fullPage` 截图在 1280×720 视口输出 1280×991、保存弹窗输出 1280×727。最后以 `fullPage: false` 重取实际视口，尺寸核对如下；早期图仅保留复核，不作为本次三档尺寸证据。

没有将上述失败或中间批次计为通过，没有移除权限、迟到、原生错误或焦点断言。
