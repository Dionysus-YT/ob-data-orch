# 日志中心任务日志查询契约

2026-10-25 依据 LC-R / LC-FR / LG 已确认规则接入任务日志首批；不开放新的执行、真实探测或日志采集来源。日志采集和保留仍以[日志与证据契约](log-collection-evidence-contract.md)为权威，本文件只定位本批实现与 API。

## 范围与权限

- 仅查询控制面已持久化、已双重脱敏的 OBDUMPER stdout / stderr / 工具文件以及 OBLOADER stdout / stderr。每条保留实际通道、同源标识、epoch/seq、接收时间及 GAP/TRUNCATED；当前持久记录没有可靠来源时间或级别，不从文本或 stderr 推断。
- 每次短 SQLite 读取先载入当前 ACTIVE 主体、固定角色和精确范围，复用任务中心 TASK_READ 谓词，再读取索引及正文。本人基础角色、数据源运维和初始部署全局兼容身份保持现有语义，普通系统管理员不因此获得业务日志。
- 无权任务与不存在任务均拒绝，宽查询的来源/保留事实只来自当前有权任务。正文检索、同源窗口、复制、下载及响应前复验使用同一当前授权指纹；不可用时失败关闭。复制/下载成功审计事务也复验授权。
- 首次导航默认任务日志与最近 1 小时，不自动查询。任务详情链接携带精确任务和提交前一分钟至当前范围，日志中心独立授权后自动查。节点/Agent、调度和审计预设尚未接入；没有空选项，也不宣称其查询已完成。单任务实时 SSE 继续由任务详情持有。

## 有界查询和固定水位

`GET /api/v1/logs/tasks`：`from`、`to` 必填；可用 `taskId` 精确过滤、`source` 已接入通道、`keyword` UTF-8 最多 256 字节的普通文本包含和 `limit`。默认 200、最多 500 条；跨任务最多 24 小时，单任务不受该跨度限制。未知/重复条件、正文或无效输入拒绝。

默认按接收时间倒序，同时间按真实物理通道、内部 stream、批次来源序号及批次 ID 稳定排序，批次内序号倒序。UTC RFC3339Nano 补齐至纳秒比较，不使用毫秒日期函数降低精度。关键字只扫描当前授权并重新验证摘要、二次脱敏后的正文；不复制全文到 SQLite，不提供 FTS、正则或查询语言。

0040 前向新增 `log_query_positions`，只保存不可重用的单调批次序号和批次引用。旧批次只回填索引，不改正文、历史任务或迁移。新批次与登记同事务提交查询序号；保留清理通过外键级联移除查询索引，AUTOINCREMENT 避免删除后水位重用。已提交水位固定后，晚到批次及相同接收时间批次都不能插入旧快照。

版本化 AES-GCM 不透明游标绑定主体、完整当前授权指纹、所有筛选、固定水位、快照时间、稳定位置及累计扫描量。主体/筛选/授权变化、篡改、1 小时过期或进程重启均要求重新查询。`pageCursor` 支持返回同水位旧页；`nextCursor` 继续该页，`snapshotToken` 只用于下载，记录 `token` 只用于同源窗口。类型不可互换。

单次 10 秒；累计每个查询最多扫描 50000 条或 64 MiB，跨页预算不重置。达到上限显式 `truncated`，停止翻页并要求收窄。响应只提供实际本页数量/累计扫描，不提供未知总量。`RETAINED`、`NOT_COLLECTED`、已登记清理 `EXPIRED` 与损坏/未知读取失败分别表达；有保留记录也不代表采集完整。清理元数据不包含精确历史接收时间边界，`expired` 只证明有权任务存在历史清理，不证明任意时间段可恢复。

## 同源窗口与输出

`GET /api/v1/logs/task-context?token=…`：同一个内部 stream（含执行与 epoch）前后各最多 50 个来源序号，按来源序号正序；忽略原时间和关键字，但固定原水位，不混入其他来源。正文与查询共用摘要验证、二次脱敏、读/封存/清理锁；在锁内刷新同批次元数据，避免封存后误读过期 `.open` 文件。窗口受 10 秒和扫描预算约束，无法可靠读取时拒绝，不伪造连续。

`POST /api/v1/logs/task-context:copy`：只接收记录 token，CSRF 必需。批量上下文复制先记录不含正文的审计，再向浏览器返回文本。单条已显示脱敏消息可本地复制；浏览器卸载、关闭或切换会话后禁止迟到剪贴板写入与提示。

`POST /api/v1/logs/tasks:download`：必须提供 `token` 和 `fullTask`、有效浏览器 CSRF。`false` 下载整个快照内所有匹配记录；`true` 只允许精确单任务，忽略时间、通道和关键字，下载水位内全部保留日志，包括接收时间等于快照时间的记录。最多扫描/输出 100000 条或 100 MiB；达到任一限制且尚有内容时整体拒绝，不返回截断文件，不建异步导出中心。

UTF-8 `.log` 由服务端生成，包含 UTC 生成/快照时间、模式、时间/任务/来源、关键字 SHA256（不复制关键字原文）、实际来源集合、条数、历史清理/缺口和脱敏声明，多行消息缩进。成功或失败记审计，正文、原文关键字及 token 不入审计；审计失败不释放文件。`SUCCEEDED` 指服务端生成和审计通过，不能证明浏览器已落盘。页面、上下文、复制与下载不提供未脱敏旁路。
