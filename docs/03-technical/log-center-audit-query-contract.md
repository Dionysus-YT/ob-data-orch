# 日志中心审计查询首批契约

> 2026-10-26 用户按 [DEC-065](../01-product/decisions.md#dec-065-单管理员首版与一次性审计读取授予) 选择单管理员首版，为下文 AQ-C01 的单账号来源增加显式一次性部署授予途径。该例外只适用于原安装入口校验原口令与固定确认后的初始 admin，不开放普通权限页自授、角色隐含能力、自动迁移或重启补授。使用标记、版本和 PERMISSION_INITIAL_AUDIT_GRANTED 审计同事务提交，撤权后不能重新使用；查询、对象裁剪、下载和访问审计边界不变。本地实现不代表已开通现役账号。

本切片沿用日志中心单页面、固定预设与平台审计事件，不建立审计仪表盘、通用 JSON 浏览、全文索引或第二套审计存储。准入和验收状态只查开发任务地图。

## 权限冲突与安全收缩

AQ-C01：权限模块旧角色表与 `HasCapability` 将系统管理员隐含视为审计读者，而日志产品 LC-LF-03 与日志技术契约第 17 节明确要求独立能力、禁止管理员自动获得。影响为设置管理员可能扩大到审计正文。按项目冲突规则，本批采用收缩实现：**必须持久显式具有 `CAP_AUDIT_LOG`**；初始 admin、系统管理员、登录会话和日志保留管理资格均不替代该能力。旧角色说明不能作为自动授权依据；若后续要恢复角色隐含能力，须单独明确决策并同步冲突契约。

本批不自动授予或迁移已有账号权限，不开放自授。权限管理员可为其他已存在的 ACTIVE 认证主体显式授予审计能力，新增须影响确认；自身只读、状态异常只能收缩、版本、幂等、审计原子性不变。生产、专家、敏感命令、全局调度日志及 NODE_OPERATE 新增仍保持各自门禁。固定 admin 的单账号来源不因此扩展为多用户认证系统；只有一个账号且没有审计能力时入口保持不可用，不重置口令或改库补授。

显式审计能力允许读取平台设置、权限变更、存储凭据生命周期与日志访问的安全事件元信息，不能读取其中秘密或业务正文，也不派生业务 API 权限。业务事件先按当前范围裁剪，再读取差异：任务/执行复用 TASK_READ；数据源按精确使用或管理范围，生产使用另验生产资格；节点/Agent 按管理或运行范围；导出草稿限当前普通用户自有草稿。未知事件域默认排除。原始差异中的关联对象、原因及嵌套值不进入响应，不借它们扩大对象范围。

## 查询与投影

- `/api/v1/logs/audit-access` 只返回当前显式能力资格，不返回事件数或候选。页面仅显示实际接入且当前有权的审计预设。
- GET `/api/v1/logs/audit`：必填 UTC 起止时间 `[from,to)`，默认最近一小时、最多 24 小时；操作人 ID、对象域/ID、事件代码、SUCCEEDED/FAILED/DENIED 结果为精确匹配；关键字只对安全投影做区分大小写的字面包含。未建立主体/对象目录候选、历史环境推断或任意 SQL 条件。
- 仅返回平台记录时间、真实 actor 类型/ID、动作代码、对象类型/ID、结果、事件 ID 和请求 ID；不伪造级别、第二个时间或因果上下文。详情使用同一个安全投影，GET `/api/v1/logs/audit-detail?token=...` 再验当前权限。
- 差异只公开固定布尔字段 `changed/confirmed/redacted/environmentInspectionAuthorized/storageConnectivityProbeAllowed` 与非负安全整数 `revision/records/count`。未知字段、字符串、原因和嵌套对象不返回、不搜索；记录明确 `detailsOmitted`。固定字段类型错误、非法标识、时间损坏失败关闭；超过 16 KiB 的差异只取长度、不给原值。
- 每页默认 200、最多 500；累计扫描最多 50000 个已授权事件或 64 MiB，10 秒超时。预算耗尽标记截断并要求收窄，不提供伪总数。无权对象与不存在对象的精确筛选返回同一空投影，无事件计数或候选差异。

## 固定水位、下载与访问审计

0041 只新增不可重用追加次序表、既有事件回填及 AFTER INSERT 触发器，触发器与所有现有审计生产事务共同提交；不修改历史迁移、不复制审计差异或工具正文。分页按规范化纳秒记录时间与事件 ID 倒序，水位冻结后新写入或晚到事件均不进入当前快照。AEAD 令牌绑定主体、用途、条件、当前完整权限指纹、水位、分页位置及累计预算；一小时、进程重启、变更或撤权失效。

POST `/api/v1/logs/audit:download` 只接受快照令牌、校验当前会话 CSRF，重新校验权限后下载匹配的全部安全投影；不限于当前页。UTF-8 `.log` 文件包含 UTC 范围、来源、脱敏/不完整边界；关键字只声明有无，不复制原文。沿用查询扫描预算，并有 100000 条/100 MiB 文件上限；达到任一限制整次拒绝，不交付部分文件或异步任务。

实际执行的查询、详情和下载记录 AUDIT_LOG_QUERY / AUDIT_LOG_DETAIL / AUDIT_LOG_DOWNLOAD，包括安全条件摘要、关键字 SHA-256、结果条数和结果。固定水位在自身访问审计前取得，因此访问事件不干扰当前分页。成功与读取失败都在返回前重验当前权限并提交访问审计；依赖、权限或访问审计不可用时不返回正文。认证/授权或输入验证阶段拒绝的请求没有执行查询，不承诺在不可用的审计存储中补记成功。不会记录正文、令牌、差异或关键字原值。

## 页面与验收边界

`LogCenterView.vue` 只装配预设和导航；任务能力由 `workbench/log-query` 持有，审计能力由 `workbench/audit-logs` 持有。切换预设、路由、筛选、关闭详情、会话失效及卸载立即使旧异步响应失去回写资格；不能通过 A → B → A 恢复旧会话。读失败或响应不可校验时撤下缓存，保留筛选供重查。查询、分页、详情、确认下载在方法入口防重；焦点、ESC、短时反馈、持续错误沿用平台。

首批不含尚未建立可靠对象授权映射的普通/旁路草稿、预检查、连接测试等独立事件域，不声称全平台审计已完整接入；环境候选与审计保留期没有可靠历史事实，暂不提供。没有审计删除入口。合成多主体、实际会话/CSRF、临时 SQLite 与浏览器验证不等于现役已登录验收、真实外部身份接入或 G3/G4。
