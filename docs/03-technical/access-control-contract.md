# 权限配置首条工程切片

> 2026-10-25 审计入口实现按[审计查询契约 AQ-C01](../03-technical/log-center-audit-query-contract.md#权限冲突与安全收缩)收缩：必须显式 CAP_AUDIT_LOG，旧角色隐含审计的表述不能作为自动授权依据；其他未接入能力不因此开放。

本契约承接权限与安全模块的固定角色、对象范围和授权变更规则。当前切片为 G2 本地实现与隔离验证，运行、验收和准入状态以开发任务地图为准。

导航按 [DEC-061](../01-product/decisions.md#dec-061-系统管理父子导航与模块边界) 及 [DEC-062](../01-product/decisions.md#dec-062-系统设置拆分为四个独立配置域)：系统管理下的权限配置为独立子项，与平台设置、调度策略、安全策略、工具与兼容及存储凭据分开。保留 `/settings/access-control` 兼容地址；导航层级不改变浏览器身份、权限接口、授权对象或事务边界。

## 身份与边界

沿用 DEC-048 的固定 `admin` 登录、初始职责和已有 `identity.Provider`，只管理可信认证提供方通过 `EnsureAuthSubject` 写入的主体投影。权限接口不创建、删除、停用或重命名认证账号，不接收用户头、密码、会话或认证材料。现有本地部署仍只有固定管理员可实际登录；多主体行为使用独立认证提供方和临时 SQLite 验证，不据此声称已接入真实外部身份系统。

初始管理员只在组合根完成可信身份投影后引导一次：将既有兼任职责明确保存为五类固定角色，并为此前可访问的现有数据源、节点与自有模板保存具体范围。后续启动不重新授予已撤销权限。初始部署身份的既有全局任务只读能力继续独立于普通系统管理员；其他系统管理员不会取得该兼容身份或全部业务对象。

单主体具体绑定上限为 200 项；初次引导也受同一上限约束，超过时整次事务失败并阻止启动，不截断旧事实或启动一个无法读取权限的管理员。已有部署须在安装前确认该边界，不能从本轮隔离验证推导任意数据规模可直接升级。

## 固定策略

- 五类角色沿用 `ROLE_BASIC_USER`、`ROLE_OPERATOR`、`ROLE_DATA_SOURCE_ADMIN`、`ROLE_NODE_ADMIN`、`ROLE_SYSTEM_ADMIN`。角色取并集，对象范围保持独立；需要对象的角色允许保存空范围，页面说明尚不生效。
- `AC-ROLE-01`：旧产品矩阵将运维人员列为可创建任务，安全契约 §13 则要求另有任务创建能力。首版按收缩方案实施：单独运维角色只提供明确任务运维范围，兼任普通用户后才获得创建、数据源/节点使用及专家配置资格；不根据角色名称扩大能力。该差异保留为待后续产品口径收口，不修改官方工具或既有任务语义。
- 范围沿用六种既有类型，并增加明确的 `TEMPLATE_USE`、`TEMPLATE_MANAGE`。每个绑定只含类型和不可变对象 ID，完整配置最多 200 项，拒绝未知、重复、空值、通配符和路径表达式。
- 数据源使用/管理、节点使用/运行/管理、按数据源关联的任务运维以及模板使用/管理互不扩大。系统管理员具有设置与权限职责；审计按 AQ-C01 收缩为显式独立能力，业务对象仍须对应角色与精确范围。
- 权限管理员通过独立授权目录读取必要对象元信息以配置范围；目录只返回 ID、名称、类型、环境与可新增状态，不返回连接、账号、路径、任务内容、命令或秘密。该权限不允许调用对应业务详情。无权限者不能读取主体、数量、候选或存在性差异。
- 生产、专家、敏感命令、审计和调度日志沿用既有独立能力编码；授权不代替生产确认、参数准入、敏感命令总开关或日志模块接入。未接入的入口保持不可用，`--query-sql` 仍是普通参数。
- 首批闭环包含五类角色、数据源使用/管理、节点使用/管理、任务运维来源与模板使用/管理。单独 `NODE_OPERATE` 的页面/消费边界以及独立高风险能力尚未完整接入，因此只读并允许撤销旧记录，拒绝新增；不以保存授权记录冒充能力已生效。模板创建保留已有初始部署身份的受控入口，其他主体的模板创建能力仍待独立契约，不因运维角色自动开放。

## 读取与保存

浏览器接口固定在 `/api/v1/access-control`。所有读取使用 `no-store`，身份 ACTIVE 且具有权限管理职责后才能读取主体列表、权限详情或授权候选；列表使用有界查询和绑定筛选的不透明游标。主体状态、显示名称和登录标识均只读。

完整替换必须携带 `If-Match`、幂等键、全部角色/能力/范围、必填纯文本变更原因及必要风险确认。原因限 1–200 个字符，拒绝控制字符、无法完整脱敏的敏感键值和标识。未知字段拒绝；同一幂等键只重放相同目标及规范请求，不能用于其他用户或异内容。

保存短事务重新读取操作者职责、目标状态、当前版本、对象当前事实与幂等回执。禁止修改当前操作者自己的权限。停用或未知主体只允许集合收缩。角色依赖缺失拒绝保存；界面在移除基础角色时清除依赖并纳入差异比较。新增系统管理员、生产、敏感命令、审计或生产范围必须确认。

角色、范围、能力、权限版本、预检查失效、成功审计和幂等结果在同一短事务提交。审计失败整次回滚。并发版本冲突不覆盖、不自动合并；失败保留页面草稿，但不得宣称保存成功。失败审计仅保留已授权操作的安全结果码，不写入非法输入原文。

## 生效与兼容

运行时从当前持久授权读取，不使用浏览器声明或缓存角色。每次新请求与秘密解析复验当前主体和对象范围；权限变更使该主体未提交草稿的既有预检查失效。撤权不取消已经运行的工具，不改写历史快照，也不恢复旧预检查资格。

新任务在首次 INSERT 时一并冻结当前权限版本和本任务的数据源、节点、生产/专家资格摘要，继续受既有任务不可变触发器保护；历史任务保持空值。待领取任务以及再次解析执行材料前复验当前授权，不能用提交时快照代替当前权限。专家配置在唯一生成路径另验已有 `CAP_EXPERT_CONFIG`；普通 `--query-sql` 不归入专家或敏感命令。生产任务的数据源使用授权另验已有 `CAP_PRODUCTION_TASK`，不替代原有生产确认。审计消费与显式新增按审计查询契约接入；其余日志和单独节点运行消费仍未开放新增。

导出是否需要专家能力由规范化领域结果分类并作为控制面内部事实冻结，不接受浏览器自报，也不从元数据版本推导普通配置的能力。普通日期/日期时间格式与结果集 SQL 不因此升级为专家配置；历史没有分类事实时采用旧版本收缩判断，恢复路径优先沿用来源任务已冻结的分类。

共享模板列表和读取按使用/管理职责及精确范围投影；使用不能改名/删除，管理不能自动派生，派生另验数据源与节点使用资格。共享模板隐藏原来源任务 ID，不因模板授权扩大历史任务读取。新建对象只为当前创建者明确绑定其已有角色允许的具体范围，并在同一创建事务递增权限版本与审计，不重授旧对象；其他用户的旧编辑版本因此必须冲突重读。

失去全部任务读取范围的首页分区使用 `RESTRICTED`，不显示可信零值；本人任务分区独立复验基础角色。节点仍单独授权，范围不可见与事实读取失败分别表达。

新增迁移只前向扩展范围类型与权限版本，不改写历史 SQL 或身份。源码更新不代表现役 SQLite 已升级。没有外部身份接入、真实多用户部署、官方工具或数据库操作授权时，只运行合成提供方、临时数据库、假 Agent 和隔离页面。

## 验收

覆盖五类角色组合、空范围、跨对象拒绝、使用/管理隔离、系统管理员无天然业务权限、自身只读、异常账号只能撤权、候选最小投影、未知字段、CSRF、版本冲突、幂等重放/冲突、角色依赖清理、审计失败回滚、预检查失效和后续请求立即撤权。前端另覆盖 A → B → A、迟到读取/保存、卸载、重复提交、取消编辑、风险确认、权限失效和三档/原生 200%/键盘验收。

本轮结果与范围见[2026-10-23 本地验收](evidence/access-control-2026-10-23.md)。本首批不宣称完整权限与安全模块、真实外部身份接入、其他业务页的全部跨身份按钮资格联调或正式多用户部署通过。审计首批仅按审计查询契约开放；其他独立能力新增、单独节点运行消费、调度日志入口与实际多身份认证仍须按任务地图分别准入。
