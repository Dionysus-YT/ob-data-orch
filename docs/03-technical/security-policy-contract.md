# 安全策略只读状态契约

2026-10-24 用户要求自主完成开发实例升级及后续模块。安全首批接入当前控制面的安全事实，不开放未定版的审计保留期限、密钥维护或安全保护降级。

- `GET /api/v1/settings/security` 使用现有浏览器身份，`SECURITY_POLICY_READ(platform)` 只允许当前 ACTIVE 系统管理员；不新增角色、独立授予能力或业务范围。读取前后分别复验持久授权，撤权时连错误差异也收缩为不可访问。
- 接口不接收查询、正文、路径或写方法；`Cache-Control: no-store`，安全依赖缺失、密钥标识不可用、上下文取消或门禁关系矛盾时失败关闭。错误只返回固定安全文本。
- `source=STARTUP_CONFIGURATION`、`loadedAt` 和四项有效执行开关来自实际组合根。普通导入和旁路探针要求总执行开关，旁路执行还要求旁路探针；这里只描述控制面许可，不推断 Agent 本机许可、用户权限、预检查或真实任务可用。
- 密钥状态仅在现有内存 keyring 仍包含当前版本别名时返回 `LOADED`。只返回非秘密 `credentialKeyId`、凭据加密格式及本机载体来源类型，不返回密钥、密文、路径、字节摘要或可恢复表示。读取状态不重新解析业务密码、扫描目录或调用工具；载入时间不冒充轮换时间、当前 ACL 验证或恢复演练。
- 内置脱敏固定启用，敏感命令原文查看未开放；生产确认继续由各任务提交规则执行。`query-sql` 仍为普通导出参数，本接口不增加敏感能力门禁。
- 审计期限为明确未配置：`auditRetentionDays=null`、`auditAutomaticCleanup=false`，不把普通日志期限视为审计期限。最低保留期及清理契约未定前不提供编辑或删除入口，不执行审计清理。
- 页面唯一读取所有者位于 `workbench/security/useSecurityPolicy.ts`。失败、撤权、路由变化和卸载清除事实；请求防重、AbortSignal 与会话代阻止迟到成功、失败及 finally 恢复旧状态。API 严格校验白名单和依赖，不显示猜测状态。
- 本批没有 SQLite 迁移或 Agent 协议变化，继续 39 项迁移、41 张 STRICT 表；OpenAPI 增加 1 项读取操作。没有写设置、弱化保护或扩展真实任务授权。

验证须覆盖持久角色、机器隔离、授权前拒绝、响应前撤权、缺失依赖、异常遮蔽、非法查询/正文/方法、矛盾门禁、前端失败与迟到/卸载，以及设置页三档、键盘和缩放。源码、合成验证、现役安装及已登录真实页面分别记录，不将登录不可用的页面验收写成通过。
