# 工具与兼容只读契约

2026-10-24 按用户继续开发及完整自主授权，接入内置工具与模块目录事实。该首批承接 SS-F049～SS-F055 的只读部分及 SS-F059/SS-F060 历史边界，不开放版本修改或元数据发布、激活、安装、切换。

## 读取与权限

- `GET /api/v1/settings/tools` 使用现有浏览器身份；`TOOL_COMPATIBILITY_READ(platform)` 只允许当前 ACTIVE 系统管理员。不新增角色、可授予能力或业务对象范围，不授予节点事实读取。
- 先授权再读取，返回成功或失败前再次复验。撤权统一为不可访问，不通过状态或错误差异泄露目录；机器身份和其他对象范围不适用。
- 无查询、正文或写方法，未知长度正文也拒绝；响应 `Cache-Control: no-store`。缺失服务、目录错误、取消和无效时间失败关闭，错误不返回内部路径或原始异常。

## 事实来源与版本含义

`source=BUILT_IN_CATALOGS`。组合根在正常启动时实际加载 `parammeta` 的受控资源，与唯一命令生成器同源；任一目录不可加载阻断启动，不用产品声明或前端常量替代。`loadedAt` 是本进程载入时间，`capturedAt` 是本次读取时间，两者均不是元数据发布时间、配置修改时间或节点检查时间。

| 工具/模块 | 当前事实 |
|---|---|
| OBDUMPER | 受控目标及模块内置新建默认目标均为 `4.3.5-RELEASE`，没有平台持久覆盖。 |
| 导出目录 | `metadataSelection=TASK_CONFIGURATION`；现役生成路径按配置选择 v5、v7、v9-combined-object-selection、v10-ddl-text-formats、v11-expert-parameters。版本保持完整受控 ID，不按字符串“最新”排序或静默升级。 |
| 导出历史目录 | v6 与 v8-object-selection 的 `usage=HISTORICAL_REPLAY`，仅由已冻结草稿显式重放，不作为新建候选。其余目录标记 `TASK_CONFIGURATION` 不代表任意配置均可使用。 |
| OBLOADER | 受控目标及两个模块的内置默认目标为 `4.3.5-RELEASE`；普通/旁路目标必须一致，但参数与资格不合并。 |

现役导出并不存在全平台单一“活动元数据版本”配置。页面如实读取配置选择与历史重放分类，属于实现事实补充；不取消已确认的后续受控版本管理设计，也不把只读目录列表当作可激活列表。支持目标只说明产品当前内置目标，真实能力仍受任务模块、组合验证、节点环境、用户授权和执行门禁约束。

## 数据与页面边界

- `Snapshot` 只含时间、来源、两种工具及三个模块的受控标识；不含定义正文、路径、凭据、节点/草稿/模板 ID、数量或安装结论。每次读取深复制列表，调用者不能改写内置基线。
- 前端严格校验白名单、两种工具与三个模块的顺序和身份、固定目标与目录所属关系、重复版本、选择/用途枚举和时间。普通与旁路目录不得互换，固定导入目录不得标成历史重放；不回显非法响应。
- `workbench/tools/useToolCompatibility.ts` 是唯一事实及读取会话所有者。刷新先撤下旧事实，失败/撤权不保留猜测状态；路由变化、A→B→A、卸载、防重、取消及迟到成功/失败/finally 均隔离。页面只装配和展示，无设置表单或通用配置引擎。
- 页面分别展示 OBDUMPER、OBLOADER 和兼容历史规则；节点实际版本仍归节点环境检查，不读取或推断覆盖数量。新建/重编辑按既有模块规则核对，已提交任务保留原快照，不因读取本页改变任何配置。
- 没有 SQLite 迁移、Agent 协议、命令生成行为或参数资源修改；继续 39 项迁移、41 张 STRICT 表。OpenAPI 新增 1 项 GET，共 118 项操作。
