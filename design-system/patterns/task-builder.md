# Task Builder Pattern

Export、Normal Import、Direct Load 共享 Task Builder Interaction Language，但各自的步骤 schema、资格、风险、命令语义和提交门禁独立。

2026-10-15 经用户确认，[DEC-051](../../docs/01-product/decisions.md#dec-051-普通导入五步向导与旁路模块解耦) 将普通导入改为“选择数据源 → 导入文件与格式 → 对象与映射 → 执行参数 → 预检查与命令”五步；随后 [DEC-052](../../docs/01-product/decisions.md#dec-052-普通导入沿用导出布局与三种文件格式) 明确普通导入沿用导出的顶部水平步骤栏、全宽工作面、摘要 Drawer 与固定底栏，文件类型仅配置 CSV、CUT、SQL。内容使用紧凑按钮单选，格式使用下拉；常用字段按导出的分组与表单几何呈现，步骤内只保留一个高级设置区。普通导入进度只表达本地输入完整度，预检查未接入时最后一步保持 0%。旁路保持独立六步，不共享导入业务状态、参数或规则。Product Shell、Archetype 和视觉 Token 不变。

[DEC-053](../../docs/01-product/decisions.md#dec-053-普通导入参数分层与适用范围收敛) 继续按导出标准组织普通导入参数：字段与选项的说明使用 Ant Tooltip，参数名和含义分行展示；提示按钮与 Checkbox/Radio 并列，点击或键盘查看不能改变业务选项。实际 CLI 参数才提供提示，平台选择与本地确认不伪装成 CLI 开关。条件不适用的字段不进入活动摘要，受管连接值不在任务级重复编辑；第四步性能和资源进入唯一高级区。

## 结构

```text
Task Header
  saved / dirty state, Save Draft, current step context
Task Step Rail
  三类向导统一使用顶部水平 Ant Steps；旁路按 DEC-056 保留独立五步，窄屏只滚动步骤栏自身
Current-step Workspace
  chosen by step content
Optional Inspector / Summary Drawer
Fixed Footer
  previous + current step primary action
```

## Step State

| State | 含义 |
| --- | --- |
| Complete | 已满足且当前有效 |
| Current | 正在编辑，使用 interaction blue |
| Pending | 尚未配置或前序未满足 |
| Blocked | 被冲突、权限、证据或前置条件阻断 |

## 规则

2026-10-20 旁路按 [DEC-056](../../docs/01-product/decisions.md#dec-056-旁路五步配置与入口集中确认) 更新为五步：数据源与连接 → 导入目标 → 文件与格式 → 执行参数 → 预检查与提交。本文下方 2026-10-19 的六步及第六步描述为历史序号，现役前四步统计有效输入，第五步统计九项检查；从头执行锁定第五步。

- 三类向导的数据源筛选、单选列表和具名事实使用 `archetypes.css` 的 `wizard-source-*` 共同布局，模块各自持有状态及资格，不复制第二套样式或引入 Ant 基础控件封装。
- 旁路首步保留适用说明；首次有效继续时使用现有确认 Dialog，安全动作“返回配置”初始聚焦，明确动作“已了解，继续配置”才记录入口阅读确认。取消、绑定变化、路由会话变化和卸载不能补确认；同一已确认草稿往返不重复弹。入口确认与最终风险确认独立。
- 旁路按 DEC-057 限定本地私有 ODP / OBServer，RPC 分别预填可编辑默认端口 2885 / 2882，草稿恢复保持保存值；F5/VIP 的双通道转发提示采用持续 Ant Alert。当前格式仅 CSV，活动参数目录 102 项，其他部署入口和说明不展示。预填、基础连接测试与入口确认都不授予执行资格。

- Global Navigation 不隐藏；Task Step Rail 只属于当前草稿。
- 所有步骤可见，当前步骤使用 `aria-current="step"`。
- Previous 不丢失有效草稿。
- Continue 先做当前 step validation。
- Save Draft 不代表可提交、已预检或命令有效。
- Precheck、Command Preview 和风险确认在相关字段变更后必须 stale。
- Submit 只在有效预检快照上可用。
- 命令预览只读、脱敏、来自控制面唯一生成器。
- 底栏只保留当前步骤操作；通用配置与预检说明不重复常驻。字段错误在 Form.Item 原位表达并定位，预检查恢复入口依据当前有效证据区分节点能力与业务配置；等待、失效及依赖阻断不能引导修改无关字段。

禁止把所有步骤做成相同 card grid，禁止让 Inspector 复刻完整表单。

## 2026-10-17 / 2026-10-19 三类向导一致性整改

本轮按用户确认统一共同呈现与同类交互，不改变 Shell、Archetype、Token、各模块检查清单或执行门禁。

2026-10-19 用户在旁路审查整改中明确要求进度条与导出、普通导入一致：旁路改用同一顶部水平 Steps、当前步骤百分比、已配置/待完善状态及历史步骤返回交互，取代此前旁路竖向栏。前五步只统计当前有效输入；第六步只统计固定九项当前有效预检查的通过项，等待、缺证、失效与过期不能补齐进度。百分比不表达工具执行进度，也不授予提交资格；从头执行仍锁定第六步。下列共同摘要、表格、反馈和事实展示规则同时适用于旁路，各自业务模型保持独立。

- 摘要 Drawer 保留一层正文留白；采用分组标题、标签在上的事实排版、短事实双列及可换行的等宽技术值。各模块保留自身业务字段与风险。
- 预检查采用相同的四列语义与操作层级：预检查项、状态、检查结果、操作。相同事实使用“未开始、等待检查结果、通过、未通过、前置阻断，未执行、无法确认、已失效”等文案；总览必须消费当前领域结果与提交资格，不能以固定蓝色说明代替成功或失败。未开放执行时，检查通过也不能表达可启动。
- 只读命令沿用同一字体、边框和间距；准备阶段用 Ant Spin，复制失败留在命令操作附近并提供剪贴板权限或手动复制的恢复方式。所有反馈沿用现有会话失效与迟到防护。
- 数据源选择统一“集群 / 租户”的具名元信息与最近测试时间、原位刷新及空态管理入口；候选资格仍由各自业务规则决定。首次引用读取保留筛选区域并使用原生 Skeleton，未就绪时不能推进。
- 离开只确认尚未保存且会丢失的输入；干净已保存草稿直接离开。更换来源会清除关联输入时，先确认影响；取消保留原绑定与输入，确认后才执行各模块已有清值规则。
- 参数目录跳转不代表前序步骤已配置。校验失败以 Form.Item 关联字段，自动展开包含错误的高级区并在动画完成后定位；会话变化或卸载后不得抢回焦点。参数抽屉每次打开均捕获触发器，关闭返回本次入口。
- 提交确认显示冻结目标与范围，初始焦点落在“返回检查”；复用现有焦点栈与 Ant Modal 动效，保留各模块的生产风险和可选名称。

上轮保留的共享问题于 2026-10-19 按用户要求更新规范：主工作面保留现有浅阴影；预检查结果表保留 44px 表头，管理表格继续为 36px；环境色以现役 Ant 主题使用的 `tokens.ts` 为准并重新生成 CSS。规则见 [DESIGN §6](../DESIGN.md#6-density-surface-and-motion)、[Tables Pattern](tables.md)及 [Token 规则](../tokens/README.md)。这不改变各向导的参数、检查清单、业务准入或执行能力。
