按 DEC-049，导出步骤 schema 为五步，内容与对象位于同一工作页；Task Builder Framework 是 P0。当前不能在此处把某一步的内容布局固化为全部步骤的通用骨架。

## 2026-10-08 当前参数分布

用户确认按卸数审计方案整改：第二步集中对象/结果集及筛选，第三步集中格式、读取一致性与文件交付约定，第四步集中输出目的地及执行资源，第五步增加格式和文件组织摘要。第三步按最新要求保留原有数据文件设置与格式常用选项栏（数据格式、编码、分隔/包围/换行、NULL、转义），下方另起独立的“其他选项”栏，集中展示快照、列头、修剪、CUT 行尾/删除换行、目录层级和空文件开关，按当前格式显示。闪回 SCN、Oracle 闪回时间、日期格式与启用压缩移入唯一高级区，与文件拆分方式/阈值、压缩算法和等级集中配置，已配置项数仅统计区内参数；第四步目的地选择进入常用区。第三步不再展示格式示意。第三步全部外层分栏（数据文件设置、CSV/CUT/SQL 常用选项、其他选项）统一使用既有底色、边框与圆角，标题均位于底色区域之外。

第三步其他选项还展示包含结构时的前置 DROP、保留 Schema 前缀与使用原生建表语句，前两项不受数据格式或租户限制，紧凑 Schema 沿用整库或指定纯表的既有资格。仅结构仍保留此区域，隐藏数据参数。MySQL CSV/CUT 展示受限的零日期保留勾选及验证原因；第三步其他选项统一放置弱读、使用隐藏主键、附加对象信息和排除生成列，沿用既有内容、对象范围与查询条件；前三项仍禁用并说明原因，不解除业务门禁。“隐藏主键”与“使用隐藏主键”为同一参数，只展示一次。第二步已配置计数不包括移出的 DDL 与排除生成列开关。

本节取代下列历史记录中涉及参数位置的规定；五步外壳、Ant 控件、租户与证据门禁保持适用。

MySQL 模式不显示 Oracle 专属参数，包括指定时间/闪回时间点和游标抓取行数；切换到 MySQL 时清除对应活动值。Oracle 下按既有能力和证据门禁展示，不因显隐调整开放未验证参数。

第四步日志路径与导出路径同级放在常用区，标为可选，留空继承工具默认；跳过导出目录空性检查也放在常用区，仅本地输出显示，并在勾选后显示覆盖风险提示。这两项不计入高级设置的已配置项数。

第二至第四步的高级设置复用导出专用 `ExportAdvancedSettings`：Ant 原生带边框 Collapse、浅底标题栏与白色表单区，底色由既有 Canonical Token 映射到作用域 Collapse 主题；标题显示已配置数量，右侧显示展开/收起提示和原生箭头。默认折叠，收起保留当前字段值，开合和箭头动画使用 Ant 原生反馈，不覆盖全局 Collapse 或其他页面。

## 历史确认记录

2026-09-30 用户确认导出进度栏置于当前工作区顶部，使用 Ant `Steps` 的水平布局；窄屏允许横向滚动。数据源、数据库和导出对象仍为当前步骤的业务内容，不放入进度栏。

2026-10-06 用户确认当前步骤使用 Ant `Steps.percent` 展示由表单与预检查事实计算的进度；已完成步骤采用原生完成态。对象分类复选框直接勾选当前已加载候选，不联动展开；展开只由箭头或分类名称触发。函数、存储过程、序列文字图标与表、视图图标使用相同的尺寸容器。

Ant `Steps.percent` 使用标准尺寸图标，避免小号步骤的进度圆环挤入标题；窄屏保持步骤栏自身横向滚动，页面不产生整页横向滚动。

2026-10-06 用户确认步骤 3 参考 ODC 的数据格式布局：数据格式、文件编码和单个文件拆分位于同一常用区；CSV/CUT/SQL 按格式显示相应的分隔符、文本识别符、换行符和 CSV 列头。编码及文本格式常用值使用 Ant 下拉选择，并保留自定义输入以承接 OBDUMPER 已有参数能力；较少使用的序列化、日期时间和压缩选项放入当前步骤唯一的高级设置。

2026-10-07 步骤 3 文件编码补齐 ODC 的 UTF8、UTF16、UTF32、ISO、ASCII、GB2312、GBK、GB18030、BIG5 展示项；提交值使用对应的执行环境编码名。单个文件上限改为 Ant 下拉，提供 64、512、1024、2048 MB 和自定义拆分阈值。ODC 的“无限制”因 OBDUMPER `--block-size` 默认值文档冲突，仅以“不指定、继承工具默认”呈现，不能承诺真正无限制。结构与数据组合开放 CSV、CUT、SQL，分别显示实际格式名称。

2026-10-07 CSV 常用区集中列头、字段分隔符、文本识别符、换行符号及文件编码/拆分；包围模式、转义、NULL 替换、修剪、日期时间与压缩归入本步骤唯一高级设置。OBDUMPER 4.3.5 的 CSV 字段分隔符和文本识别符只接受单字符，CUT 的分隔字符串独立处理。高级日期时间字段按所选数据源的 MySQL/Oracle 兼容模式及验证状态启用；Oracle 日期时间格式尚未验证，仍显示禁用原因。

2026-10-07 CUT 常用区展示可多字符的分隔字符串与换行符号，高级设置保留行尾分隔符处理、转义、NULL 替换、修剪、删除换行、受租户模式约束的日期时间与压缩。SQL 常用区仅展示换行符号以及共享的文件编码/拆分，高级设置仅保留压缩。官方 4.3.5 文档对 CUT 行尾开关的效果、SQL 能否使用 NULL 替换存在自相矛盾的描述；页面对前者不预断输出方向，对后者遵循参数说明的 CSV/CUT 限定。

2026-10-07 步骤 2 导出内容新增“按结果集导出”：数据库选择仍位于常用区，后续对象范围和双栏改为查询输入及条数上限，默认 1000。查询输入嵌入 Monaco，提供行号和 SQL 高亮；工具栏通过 Ant 控件提供查找/替换、撤销/重做、SQL 格式化、选中文本大小写转换、缩进与注释。格式化按 MySQL 或 Oracle 方言在本地处理；注释仅供编辑，提交前必须移除。界面不提供 SQL 执行或文件浏览；只显示单条 SELECT 校验与任务执行时才确认语法、对象及权限的边界。

2026-10-08 查询编辑器的 Monaco 查找控件需加载 Codicon 字体以正确显示图标；格式化与大小写转换均显示明确操作反馈。大小写转换优先作用于选区，无选区时作用于全文。工具栏提供本地 IN 值转换，支持粘贴换行、逗号或制表符分隔的文本或数值，在选区或光标处插入带括号的 SQL 列表；文本单引号按 SQL 规则转义，数值无效或超出查询长度时保留原 SQL。该操作不执行查询。

2026-10-08 用户确认查找与替换合并为单个工具栏按钮，点击后直接显示查找及替换输入；图标参照 ODC SQL 工具栏的文档查找、撤销/重做、魔棒格式化、方框 IN、Aa、缩进和注释语义，继续使用 Ant 按钮及菜单承载交互。

查找与替换使用 Monaco 原生控件；展开时编辑器外框随控件高度增加，保留原有 240px 代码可见区域，关闭后恢复原高，不让查找行挤占固定高度的 SQL 输入区。

2026-10-08 读取一致性位置修订：第二步删除读取一致性区域；条件筛选和分区筛选在包含数据的普通对象高级区始终呈现，整库或混合类型时置灰并说明仅指定表可用，恢复为指定表后可填写。第三步其他选项提供 `--snapshot` 勾选，唯一高级区提供 `--flashback-scn` 与 Oracle 专属 `--flashback-timestamp`；快照和闪回互斥，错误归属第三步，未配置继承实时读取。仅结构与结果集不显示这些一致性控件。

## 2026-10-08 其他选项分类与参数说明

第三步其他选项按“结构导出、数据读取、字段与文本处理、文件组织”四类组织，共享一个连续底色区域与外框，不拆成四块；“其他选项”主标题在底色外，分类小标题在区域内以间距区分，分类无适用参数时隐藏。15 项使用已确认的精简名称，名称后以独立 Ant 问号按钮提供 Tooltip，参数名和含义分行显示，支持悬停与键盘聚焦；说明按钮不属于 Checkbox 标签，点击不联动勾选。四个受限入口保留可见的不可用原因，Tooltip 也可独立访问。租户/格式/内容/对象范围显隐及原提交绑定不变。

## 2026-10-08 第三步全区域参数说明

数据文件设置、CSV/CUT/SQL 常用选项和高级设置的 18 个编辑入口复用 ExportOptionHint，在字段名称后以 Ant 问号按钮提供参数与含义的分行说明，支持悬停及键盘聚焦。FormItem 使用 label slot，保留 html-for、控件名称、校验反馈、required 与原提交绑定；压缩开关说明独立于 Checkbox。CSV/CUT 字段分隔符分别指向 column-separator/column-splitter；拆分方式和阈值说明同一 block-size 参数，区分 MB/ROW 与任务总量上限。Oracle 闪回时间、MySQL DATE/DATETIME 值格式及压缩等级继续按原资格显示，不为未开放参数增加入口。其他选项继续保持一个连续底色区域。

## 2026-10-08 全步骤参数展示统一

以第三步为基准，第二、第四步的实际 OBDUMPER 参数项复用名称后的 ExportOptionHint，分行展示参数与含义，并复用既有浅底色、边框与圆角。混合表单只给工具参数区域着色，不覆盖平台配置。分区标题不附加说明图标，外部标题位于底色之外。

按用户后续明确要求，第一步数据源与名称/环境筛选，第二步执行节点与查询结果条数限制，第四步执行节点、目的地选择、对象存储 URI 子字段与存储凭据，以及第五步只读配置摘要，均不添加底色或工具参数说明。对象选择保留既有双栏工作面和交互，不在导出对象标题上附加提示。第四步日志路径继续与导出路径同级可选，目录空性跳过在外层其他选项区；其说明按钮独立于 Checkbox。高级设置沿用既有 Ant Collapse。参数位置、校验、租户/格式/内容显隐与能力门禁不变。

## 2026-10-08 第二步简化与对象框固定

第二步按用户后续要求成为展示例外：高级设置之外取消新增的参数问号提示与浅底色，已选对象栏也不着色；数据库、内容、范围和结果集恢复普通表单展示。原有校验、风险与失败反馈保持适用，高级设置保留原生 Collapse 及参数说明。第三、第四步的参数展示标准不受本次例外影响。

候选与已选对象两栏各固定为 400px 高，标题、搜索和清空操作在滚动内容之外；对象、空状态及目录反馈在各自的可聚焦滚动区内展示。对象增加、展开、筛选、删除与清空均不改变框高，不通过截断或选择上限实现。窄工作区和 200% 缩放沿用双栏顺序堆叠，每栏仍独立滚动。

第二步顶部取消“导出内容与对象”h2 及紧随其后的总说明，“导出内容”改为 h3 分区标题，保留单选组的可访问名称、选择态与校验。“手动输入数据库”放在数据库选择框及展开按钮的右侧，同一行呈现；窄屏数据库字段转为单列以保留右侧入口。

第二步不显示重复选项含义的模式说明或内部验收口径，例如“只支持结构的对象不会被标记为已导出数据”；不解释命令标志生成、控制面查询包裹等实现过程。结果集字段只提示单条 SELECT 限制与默认条数。影响用户配置的禁用原因、输入校验、目录失败/截断、选择变化和风险反馈继续呈现。

对象选择性能约束：对象目录完整加载，不按对象条数截断；候选/已选列表超过 100 行时采用可见窗口渲染，继续复用 Ant List/Checkbox 和现有 400px 工作面。搜索、分类计数、全选与跨步骤状态基于完整集合；窗口阈值仅影响 DOM，不限制加载或选择。虚拟行固定高度，长名称提供 title；内部滚动、分类折叠和窄屏单列仍保持可达。

## 2026-10-09 第四步执行节点展示

执行节点采用无底色的只读信息行：节点名称为主要事实，平台置于次行，配合中性节点图标与底部分隔线；右侧使用 Ant 链接按钮“更换节点”，返回第二步调整绑定。窄屏与长名称允许换行，操作仍可达。不把节点状态推断为在线或通过预检查；加载、失败重试及派生草稿的固定绑定反馈保留，固定绑定时不提供更换入口。
