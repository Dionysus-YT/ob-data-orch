# Overview Page Rule

> 状态：**当前布局规则生效；立体卡片与独立趋势弹窗本地验收通过**
>
> 2026-10-28 用户明确要求参考 OCP 首页并同步修改不适用的旧约束，且确认保留四项任务指标。本页与 [P0 MASTER §5/§6](../MASTER.md)、[DEC-066](../../docs/01-product/decisions.md#dec-066-ocp-参考首页布局) 共同取代 DEC-060 的首页结构；视觉仍沿用 [DESIGN](../DESIGN.md)、数据源定版的字体、控件和 Shell。验收以第 4 节的实际证据为准。

## 1. 参考与布局映射

参考用户在内嵌浏览器打开的 OCP `/overview`，复用其“顶部概览卡 → 并列信息工作区 → 通栏明细”的阅读节奏、标题/正文分隔和留白。OCP 的资源分类映射为本项目四项已有任务指标；诊断工作区映射为已有关注事实。立体卡片与图表弹窗按 [DEC-068](../../docs/01-product/decisions.md#dec-068-首页立体指标与独立趋势分析弹窗) 进一步修订。不引入集群、租户、SQL 诊断、资源 Top5、健康评分或额外监控图。

| 顺序 | 分区 | 当前规则 |
| --- | --- | --- |
| 0 | 页头 | 一个 `首页` h1；右侧为当前授权范围、UTC、快照时间、过期/更新中状态、自动刷新与文本刷新按钮 |
| 1 | 四项任务指标 | 四列等宽、16px 间距、24px 内边距；使用同视角透明立体插画与既有轻阴影，蓝色运行、紫色等待、绿色成功、红色失败只辅助辨识。文字与数字为真实 UI，数字保留 Ant 链接按钮，今日 Tooltip 保留精确 UTC 自然日/终态时间口径；未知/未授权不写成 0 |
| 2 | 任务结果趋势 / 需要关注 | 桌面 3:2 并列、顶部对齐；趋势仅一张，关注区内依次呈现受控摘要、有限异常及覆盖范围。标题栏与正文由细边框分隔，不使用嵌套卡片 |
| 3 | 我的任务 | 独立通栏 Ant Table，最多 5 条；保留本人范围、状态、阶段/可靠进度、更新时间及详情/全部任务下钻 |
| 4 | 执行节点 | 独立通栏 Ant Table，最多 5 条；标题行展示可见总数及不可接收数量，并保留全部节点入口。名称、四维状态、全部阻断原因、槽位、心跳、CPU/内存及采样时间保持可读 |

节点计数归节点区，不再占据第五张指标卡。没有可见节点时仍按契约显示范围受限，不泄露计数或将其当成节点总数为零。

## 2. 响应式与可访问性

- 1920×1080、1440×1024、1280×720 的首屏均优先呈现四卡、趋势及关注区；保留现役 Shell 几何与 24px 工作区边距。
- 工作区容器不足 1000px 时，趋势/关注按 DOM 顺序转为单列；不足 900px 时指标为两列，不足 420px 时为一列。任务/节点表始终通栏，窄屏必要滚动只由表格内部承担。
- 不固定工作区高度、不裁切关注事实、不为等高隐藏原因；内容增长时页面纵向滚动。
- 趋势 SVG 只绘制真实时间点之间的细线，不插值或常驻显示每个圆点；坐标文字独立排版，浅网格与底部 Checkbox 图例保持可读。透明 Ant Button 命中区按相邻点中线划分，悬停/聚焦显示竖向参考线、真实计数与 UTC 时间，Enter/点击打开该桶分析。系列可见性不改变统计范围。
- 表格名称关联真实 `table`；单个 h1、分区 h2、键盘顺序与视觉一致。四卡数字、趋势明细及对象链接全部使用 Ant Button 的焦点与交互。

## 3. 状态与事实边界

放大与下钻分析均为独立 Ant Modal，同一时刻只有一个视图。弹窗宽度不超过 `1280px` 或视口减 `48px`，正文独立滚动；打开聚焦标题，Tab 限制在窗口内，Escape/关闭恢复入口。关闭立即卸载分析读取，不能等关闭动画结束才取消。原生 200% 下窗口、关闭、筛选、分页及内部表格滚动仍须可达。

弹窗捕获打开时的图表范围、UTC 快照和桶边界；同范围自动刷新不移动正在分析的窗口。分析使用既有授权任务列表读取当前可见任务，结果是独立读取，不伪装为图表事务内的任务明细。仅允许全部终态、成功、失败、已取消与捕获范围内的桶筛选，每页 10 条；任务详情新标签页打开以保留分析上下文。空窗口/非法桶不能退化为无筛选读取，列表授权失效立即通知 `useOverview` 清除全页旧事实。

摘要、指标、趋势、节点、本人任务和异常始终来自同一快照。刷新保留整份可信旧快照，部分失败、全失败、过期、可信空结果与无权限分别呈现；授权失效及时清除旧事实。范围切换和卸载的迟到隔离继续由 `useOverview.ts` 唯一管理。

不增加首页管理操作、新 API、全局 Token、基础控件 Wrapper、图表依赖或独立通知状态。接口、时间与授权边界见 [API 契约 §5.1.1](../../docs/03-technical/api-sqlite-data-contract.md#511-首页只读运行快照2026-10-23)，业务范围见 [首页模块](../../docs/02-design/home-module.md)。
