# Overview Page Rule

> 状态：**当前布局规则生效；立体卡片与独立趋势弹窗本地验收通过**
>
> 2026-10-28 用户明确要求参考 OCP 首页并同步修改不适用的旧约束，且确认保留四项任务指标。本页与 [P0 MASTER §5/§6](../MASTER.md)、[DEC-066](../../docs/01-product/decisions.md#dec-066-ocp-参考首页布局) 共同取代 DEC-060 的首页结构；视觉仍沿用 [DESIGN](../DESIGN.md)、数据源定版的字体、控件和 Shell。验收以第 4 节的实际证据为准。

## 1. 参考与布局映射

参考用户在内嵌浏览器打开的 OCP `/overview`，复用其“顶部概览卡 → 并列信息工作区 → 通栏明细”的阅读节奏、标题/正文分隔和留白。OCP 的资源分类映射为本项目四项已有任务指标；诊断工作区映射为已有关注事实。立体卡片与图表弹窗按 [DEC-068](../../docs/01-product/decisions.md#dec-068-首页立体指标与独立趋势分析弹窗) 进一步修订。不引入集群、租户、SQL 诊断、资源 Top5、健康评分或额外监控图。

| 顺序 | 分区 | 当前规则 |
| --- | --- | --- |
| 0 | 页头 | 一个 `首页` h1；右侧保留当前授权范围、UTC、短快照时刻、过期/更新中状态、自动刷新与文本刷新按钮；完整快照日期及 30 秒刷新周期通过悬停/键盘提示查看 |
| 1 | 四项任务指标 | 四列等宽、16px 间距、24px 内边距；统一蓝白透明立体素材，80px 图像盒及既有轻阴影，去除重复的“当前状态 / UTC 今日”小字。文字、符号与数字区分指标，数字保留 Ant 链接按钮，今日 Tooltip 保留精确 UTC 自然日/终态时间口径并支持键盘；未知/未授权不写成 0 |
| 2 | 任务结果趋势 / 需要关注 | 桌面 3:2 并列、上下边缘对齐，各固定 420px 高；趋势仅一张，关注区内依次呈现受控摘要、有限异常及覆盖范围。标题栏与正文由细边框分隔，正文超出后内部纵向滚动，不使用嵌套卡片 |
| 3 | 我的任务 | 独立通栏工作面固定 360px 高，正文中的 Ant Table 最多 5 条；保留本人范围、状态、阶段/可靠进度、更新时间及详情/全部任务下钻，长内容在正文内纵向滚动 |
| 4 | 执行节点 | 独立通栏 Ant Table，最多 5 条；标题行展示可见总数及不可接收数量，并保留全部节点入口。名称、四维状态、全部阻断原因、槽位、心跳、CPU/内存及采样时间保持可读 |

2026-10-31 用户进一步要求需要关注、我的任务和任务结果趋势不随内容增长改变区域大小：三个摘要区的空态、受限、失败和有数据态共用固定外框，标题及操作入口位于滚动正文外，Empty 居中占用剩余正文。此决定取代本轮早前“可信空结果收紧、真实内容自然撑高”的高度规则；原生 Empty 仍复用既有 8px 外边距，其他区域的最小 96px 空态规则保留。“我的任务 / 查看我的全部任务”已表达本人范围，不重复展示其排序说明。关注区首段保留服务端唯一受控摘要，优先异常、节点阻断和非零待处理事实，不重复零计数。资源已过期时在 CPU/内存之前显示“历史采样（已过期）”，无时间则显示“采样时间未知”；完整心跳、采样时间与原因不隐藏。趋势分析入口文案使用“查看对应任务”，原互斥弹窗、捕获窗口和读取边界不变。

节点计数归节点区，不再占据第五张指标卡。没有可见节点时仍按契约显示范围受限，不泄露计数或将其当成节点总数为零。

## 2. 响应式与可访问性

- 1920×1080、1440×1024、1280×720 的首屏均优先呈现四卡、趋势及关注区；保留现役 Shell 几何与 24px 工作区边距。
- 工作区容器不足 1000px 时，趋势/关注按 DOM 顺序转为单列，区域高度仍保持；不足 900px 时指标为两列，不足 420px 时为一列。任务/节点表始终通栏，窄屏必要的横向滚动只由表格内部承担。
- 趋势、关注与我的任务固定区域高度，超出正文内纵向滚动；完整原因、记录、图例与时间口径均可滚动到达，不省略或截断事实。正文有独立可访问名称并可键盘聚焦，用方向键、Home/End 或鼠标滚动；标题、时间范围和全部任务入口保持在正文外。整个工作区继续自然纵向滚动，执行节点区保持按内容增高。
- 2026-11-02 按用户要求提升曲线的柔和感与整体舒适度：连线平滑通过每个真实桶，区间过渡不越过相邻计数、零平台保持为零，各系列使用相同过渡权重，避免分项在桶间高于总数。该表现规则取代先前禁止连线插值的限制，不生成平滑计数、新观测点、统计或查询参数；提示和下钻只取真实桶。
- 主系列采用 2.25px 产品蓝及极浅渐隐底色，成功/失败保留语义色、1.5px 次级线条；仅保留浅水平网格。整数纵轴为峰值留出顶部空间，图例与精确 UTC 时间窗口同列对齐。默认绘图区固定 200px 高，放大图随视口在 180–280px 内适配；常规桌面不因宽度增大挤出图例或窗口。标记使用独立 CSS 圆形，与真实 SVG 坐标一致，宽高变化及原生缩放不拉伸圆形。
- 图例上移至图形上方，继续使用 Ant Button 的 `aria-pressed`、Enter/Space、可见焦点与隐藏态划线。页头使用紧凑描边时间范围控件、UTC 和可键盘访问的统计口径提示，完整时间窗口随图形统一呈现。透明 Ant Button 命中区按相邻点中线划分，悬停/聚焦显示细参考线、小空心点及唯一活动白底读数；鼠标离开后恢复键盘焦点读数，Enter/点击按同一桶分析。系列开关不改变比例尺、统计范围或下钻窗口。
- 表格名称关联真实 `table`；单个 h1、分区 h2、键盘顺序与视觉一致。四卡数字、趋势明细及对象链接全部使用 Ant Button 的焦点与交互。

## 3. 状态与事实边界

放大与下钻分析均为独立 Ant Modal，同一时刻只有一个视图。弹窗宽度不超过 `1280px` 或视口减 `48px`，正文独立滚动；打开聚焦标题，Tab 限制在窗口内，Escape/关闭恢复入口。关闭立即卸载分析读取，不能等关闭动画结束才取消。原生 200% 下窗口、关闭、筛选、分页及内部表格滚动仍须可达。

弹窗捕获打开时的图表范围、UTC 快照和桶边界；同范围自动刷新不移动正在分析的窗口。分析使用既有授权任务列表读取当前可见任务，结果是独立读取，不伪装为图表事务内的任务明细。仅允许全部终态、成功、失败、已取消与捕获范围内的桶筛选，每页 10 条；任务详情新标签页打开以保留分析上下文。空窗口/非法桶不能退化为无筛选读取，列表授权失效立即通知 `useOverview` 清除全页旧事实。

摘要、指标、趋势、节点、本人任务和异常始终来自同一快照。刷新保留整份可信旧快照，部分失败、全失败、过期、可信空结果与无权限分别呈现；授权失效及时清除旧事实。范围切换和卸载的迟到隔离继续由 `useOverview.ts` 唯一管理。

不增加首页管理操作、新 API、全局 Token、基础控件 Wrapper、图表依赖或独立通知状态。接口、时间与授权边界见 [API 契约 §5.1.1](../../docs/03-technical/api-sqlite-data-contract.md#511-首页只读运行快照2026-10-23)，业务范围见 [首页模块](../../docs/02-design/home-module.md)。
