# 系统管理配置域 · 页面规则

> Authority: P1；依据：[DEC-064](../../docs/01-product/decisions.md#dec-064-平台设置收拢与分组重设计)，取代 DEC-062 的四页并列入口。
> 范围：平台设置中的常规设置、调度策略、安全策略、工具与兼容四个配置域；业务仍以[设置设计与字段规则](../../docs/02-design/system-settings-module.md)为准。

## 页面与职责

| 页签 | 路由 | 实现入口 | 所属内容 |
|---|---|---|---|
| 常规设置 | `/settings/platform` | `GeneralSettingsView.vue` | 展示默认、任务命名、任务与普通日志保留 |
| 调度策略 | `/settings/scheduling` | `SchedulingPolicyView.vue` | 平台并发、超时、队列检查间隔和候选选择 |
| 安全策略 | `/settings/security` | `SecurityPolicyView.vue` | 脱敏、密钥保护边界、已准入能力、生产确认和审计保留 |
| 工具与兼容 | `/settings/tools` | `ToolCompatibilityView.vue` | 工具目标、元数据、草稿/模板兼容和历史边界 |

系统管理仅保留平台设置、权限配置、存储凭据三个子项。`PlatformSettingsView.vue` 持有统一标题、四个原生 Ant Tabs 和嵌套路由出口；不持有业务事实或保存事务。旧 `/settings` 保留查询和锚点后进入常规设置，原四个深链接保持兼容，刷新、前进/后退都从路由投影选中项。页签是平台设置的上下文切换，不增加全局配置树或聚合首页。

## 布局与状态

- 采用 P0 Settings Archetype：统一工作区标题/上下文 → 单一设置工作面内的四个页签 → 当前域说明与平面分组；无常驻侧栏、卡片墙或全页保存栏。
- 复用 `orch-page-header`、`settings-main`、Ant Tabs/Form/Form.Item/InputNumber/Radio.Group/Collapse/Alert/Descriptions/Button 与既有 Token，不引入 React ProForm、JSON 编辑器或通用配置引擎。`settings-domain`、`settings-group`、`settings-control-header` 等设置布局集中于 `platform/archetypes.css`，仅定义几何、间距、分隔和操作位置，不重绘 Ant 状态或新增 Token。用途栏为无底色的 200px 平面说明，视口不超过 1100px 合并为单列。
- 已开放的普通日志优先于未开放的基础/命名说明；各组标题旁放编辑和刷新，主体为分组表单。普通日志与调度三类事务的未保存输入仍由各自唯一状态所有者派生；页签切换复用路由/注销守卫，拒绝离开时路由、选中项和输入保持一致，保存中禁止卸载写会话。只挂载当前域，切换清理消息、读取和表单，不用 KeepAlive 恢复旧会话。
- 2026-10-27 按用户授权的检查整改，未开放的基础配置和任务名称规则统一收进“未开放设置”折叠说明，不占用独立分组或提前展示尚未接入的校验、生效行为；已开放的普通日志表单、独立保存及权限边界保留。
- 2026-10-26 按用户采纳的表单整改方案，已读取的数值默认用原生 `InputNumber readonly` 展示并附加天/秒/个执行单位；候选顺序使用原生 Radio.Group，非编辑态禁用选择。点击对应编辑动作后解锁，原因和核对/取消动作仅在编辑态出现；取消恢复已读取事实，不从控件反写只读事实或自动开启编辑。时间三字段在宽屏并排，不超过 800px 时单列。编辑块最多 720px，表单最多 640px，数值控件最多 280px；控件仍为 36px、正文仍为 14px。
- 来源、版本、修改记录、采样时间与最近读取事实使用原生 Collapse 的“配置详情”，默认收起；字段范围及简短生效边界归 Form.Item 帮助，不在每组重复常驻大段 Alert。危险确认、错误及保存不确定反馈仍保持既有 Alert/Modal。读取失败或无权时撤下控件和详情，不以空控件伪装未配置；已确认未配置的数值为空且明确标注，不预填猜测值。保存未知时区分表单输入与“最近读取（当前值待核对）”，取消后仍不能将旧值称为当前值。
- 安全和工具保持只读，不提供虚假开关或保存。安全规则及执行许可用 Badge 和紧凑 Descriptions，非秘密密钥别名仍可见；来源和时间收进配置详情。工具目标与目录选择可见，具体配置/历史目录按模块在“参数目录”折叠中查看；来源和载入/读取时间进入配置详情。折叠只改变呈现，不改变目录适用性、权限或事实会话生命周期。
- 2026-10-27 二次整改：统一页头及当前域不再重复用途介绍；分组名称、实际字段和编辑动作承担信息层级。调度数值范围与操作帮助仅在编辑时显示，未配置、待核对、字段错误及确认风险继续保留。安全只读声明和执行许可边界各保留一次；工具目标与默认值相同时合并展示，节点安装/资格边界统一说明一次；载入时间口径进入配置详情。权限配置的自身只读反馈位于对应编辑器，不常驻列表说明。
- 已接入的真实配置才显示当前生效值、来源和时间；平台页的普通任务日志保留策略、调度页的并发上限、时间策略及候选顺序接入实际读写，其他内容继续明示未开放，不以缺省值冒充部署事实。
- 普通日志策略由 `workbench/platform-settings/useLogRetention.ts` 唯一持有读取、编辑、冻结确认、幂等重试与保存会话。只读状态展示实际天数，来源/修改记录/版本按需展开；进入编辑解锁天数并显示原因及核对动作。降低仍需勾选清理影响，确认使用 Ant Modal，成功复读当前策略，错误使用 Alert 或 Form.Item。读取失败不回填默认值，无权清除事实；路由变化、取消、卸载清除会话与提示，迟到响应不得恢复旧状态。
- 普通日志范围 7–365 天，默认 30 天；SQLite 覆盖优先，尚未覆盖时继承部署配置。显示下批清理生效、无需重启，明确已删除或已登记清理不能撤回。没有立即清理入口，不开放任务历史或审计日志保留。技术边界见[保留设置契约](../../docs/03-technical/log-retention-settings-contract.md)。
- 保存结果不确定时，原值只显示为“最近读取期限（当前值待核对）”，不得继续冒充当前生效值。允许同一载荷/幂等键重试；取消编辑仍保留待核对状态，重新读取当前值后才恢复新的编辑。
- 调度并发由 `workbench/scheduling/useSchedulingPolicy.ts` 唯一持有策略、表单、冻结确认与写事务。未配置时显示“尚未配置平台上限”，编辑不预填猜测值；配置后限定 1–1024。首次设置或降低要求勾选影响确认，提高仍核对差异；保存后仅影响后续新领取，不取消既有任务。未保存输入离开、更新路由或退出登录前确认放弃，保存中禁止离开；未知保存结果显示最近读取/待核对，取消后仍须重新读取。技术边界见[调度契约](../../docs/03-technical/scheduling-policy-contract.md)。
- 调度页的全平台占用/运行数仅在已有全局任务读取权限时显示，带 UTC 采样时间；普通系统管理员明确显示数量未返回，不显示 0 或本人数量。占用沿用可靠进程释放证据，可能包含启动、取消和待核对执行。
- 时间策略由 `workbench/scheduling/useSchedulingTiming.ts` 独立持有事实、表单、确认、写事务和离开保护，不共用并发上限的版本或编辑状态。心跳显示实际启动来源或平台覆盖；启动期限与检查间隔未配置时明确为空，编辑不预填数值，配置后不能清空重置。心跳 60–3600 秒、启动 15–3600 秒、检查 1–60 秒；缩短心跳、首次/缩短启动及改变检查频率须勾选影响。心跳用于当前观察，启动期限只影响新领取，检查间隔仅限制控制面检查且不改变 Agent 本机网络/续租规则。保存不确定、冲突、权限撤销与迟到边界沿用并发策略的反馈原则。
- 节点选择保持固定的显式选择方式，候选顺序独立编辑“保持现有顺序”或“在线节点优先”，不代选或改派，也不将在线解释为可执行。按 [DEC-063](../../docs/01-product/decisions.md#dec-063-节点并发沿用-jvm-内存预算) 取消新节点任务数默认项；页面说明节点并发由 JVM 内存预算约束，预算在执行节点维护，不在调度页复制预算表单或推算固定任务数。
- 工具页签按[只读状态契约](../../docs/03-technical/tool-compatibility-contract.md)读取实际内置目标与目录，取代仅展示产品目标说明的历史状态。`workbench/tools/useToolCompatibility.ts` 唯一持有事实和读取会话，失败、撤权、路由及卸载撤下目录；复用设置分组，工具说明与目标/模块目录分别呈现。导出按配置选择与仅历史重放分别显示，普通/旁路固定目录独立；来源时间不是发布时间，目标不是节点安装或全部组合通过。不提供目录激活、工具安装、统一表单或通用配置引擎。
- 安全策略首批按[只读状态契约](../../docs/03-technical/security-policy-contract.md)读取当前启动事实，取代上条安全页仅说明的历史状态。`workbench/security/useSecurityPolicy.ts` 是唯一读取所有者；加载、无权、失败或坏响应不显示猜测状态，路由、卸载及迟到结果隔离。采用原有 Alert/Descriptions/Button 和平面分组，无私有样式或配置写入口。仅显示非秘密密钥版本别名，不显示材料、摘要或路径；审计期限明确未配置、当前无自动清理。
- 页面进入定位复用 `usePageEntryPosition`：无有效锚点时回到标题，有效锚点仅限当前正文并避开固定顶栏；非法片段或其他区域 ID 按无锚点处理，不调整其他业务页面的滚动策略。
- 权限配置继续持有用户授权，存储凭据继续持有短时秘密输入；两者不并入这四页。

## 验证

2026-10-24 调度候选顺序独立读取、编辑、核对和保存的业务边界保留；2026-10-26 按用户整改要求将 Select 改为 Radio.Group，直接展示“保持现有顺序”“在线节点优先”两项。在线仍只作排序依据，已有选择不变且下次候选读取生效，来源/版本/最近修改均来自真实策略。三种独立事务不能合并成一次全页提交；保存未知、冲突、撤权、迟到、离开及缩放状态按各自会话验收。

按 P0 八项视觉门槛检查三档视口、键盘和原生 200%；共享导航与设置样式变更同步复查数据源标准页及受影响参考页。补验四页签深链接、刷新、前进/后退、侧栏唯一高亮、拒绝切换保留输入、保存中禁止切换和确认离开后重进清空。普通日志、调度并发与时间策略另验证加载/失败关闭、字段错误、影响确认、保存与复读、取消、未知失败重试、旧版本和历史回执；调度还验证未配置、受限计数和独立事务。原生缩放截图须等勾选、按钮可用及有限动画稳定，不把过渡状态当最终证据。其他不可编辑内容验证无写请求、无秘密输入及无猜测值。
