# 模板中心 · Template Center Page Specification

> Authority：**P1 — 模板中心页面规则**\
> Status：**本地实现、合成及页面验收通过；未用户定版或安装**\
> 日期：2026-11-02；对应路由：`/templates`\
> 设计依据：用户要求“按现役产品状态，重新定义设计模板中心”。\
> 业务范围：[模板中心设计](../../docs/02-design/template-center-module.md)；实现进度只查[任务地图](../../docs/03-technical/development-task-map.md#template-center-redesign)。

## 1. 页面目标与复用

用户从已保存的导出或普通导入模板中选择一个，重新绑定数据源与执行节点，创建可编辑草稿并进入对应向导。页面选择 Management / Table Archetype，复用[数据源标准页](data-sources.md#11-后续页面复用规则)的单一工作面、操作层级、控件和列表 Footer。

沿用 [MASTER](../MASTER.md)、[DESIGN](../DESIGN.md)、[Tables](../patterns/tables.md)、[Drawers](../patterns/drawers.md)、[Forms](../patterns/forms.md)、[Action Hierarchy](../patterns/action-hierarchy.md) 与[状态反馈](../patterns/status-feedback.md)。不新增全局 Token，不修改 Shell 或 Archetype，不复制数据源业务字段与整份 CSS。

## 2. 首屏结构

| 顺序 | 区域 | 内容与层级 |
| --- | --- | --- |
| 1 | 页面标题 | 唯一 h1“模板中心”；不增加标语、统计卡或重复功能说明 |
| 2 | 单一管理工作面 | 左侧 h2“模板列表”，右侧 utility“刷新”；无独立“新建模板”主按钮 |
| 3 | 筛选行 | 可见标签“模板名称”与搜索输入、“任务类型”与 Select；有条件时显示“清除筛选” |
| 4 | 反馈及表格 | 首次加载/失败/无权/空态或当前可信摘要 |
| 5 | Footer | 左侧“共 N 条”；右下角“10 条/页 → 上一页 → 第 N 页 → 下一页” |
| 6 | 上下文弹层 | 使用抽屉、改名弹窗、删除确认；默认全部关闭，业务写入会话互斥 |

没有页面级创建动作是有意设计。创建模板的唯一来源是成功任务；该说明只在首次空态出现，不占据有数据页面的常驻 Alert。刷新成功保留原位反馈，不弹 Message。

搜索仅匹配名称，类型为“全部类型 / 导出 / 普通导入”。不增加旁路禁用选项、兼容筛选、数据源策略或标签筛选。搜索、筛选与分页均是完整授权摘要集合的本地浏览，不发送不存在的查询参数。

## 3. 表格与操作

| 列 | 优先级 | 呈现 |
| --- | --- | --- |
| 模板名称 | 必须 | 左对齐，主文字；长名称省略时提供键盘可达完整值；不常驻重复 ID |
| 任务类型 | 必须 | “导出”或“普通导入”，中性 Ant Tag；不用成功色表达资格 |
| 来源任务 | 次级 | 只用接口返回的 sourceTaskId；任务 ID 等宽、可截断并查看完整值；链接仍受任务详情授权 |
| 更新时间 | 次级 | 复用现有时间格式；可查看完整时间，不能从坏值生成假时间 |
| 操作 | 必须 | 直接显示“使用模板”；低频“改名、删除”收进“更多”菜单 |

sourceTaskId 缺失显示“—”，不得写“手工创建”“已删除”或“无权查看”。不在列表额外请求来源任务名称或源/节点来拼摘要。

表格主工作面使用既有 36px 表头与约 42px 行基线，多行按内容增高；名称/来源左对齐，操作右对齐。行内“使用模板”采用现有紧凑文本/链接动作，只有抽屉 Footer 的“创建草稿”为当前写入主动作。菜单、图标和焦点采用 Ant 原生能力。

不展示“能力版本”主列；capabilityVersion、revision、创建时间及模板 ID 放入使用抽屉内默认折叠的“技术信息”。configFingerprint 默认不展示，不以技术值作为成功或兼容标识。

### 3.1 排序与分页

- 当前 GET config-templates 返回完整授权集合，后端按创建时间倒序、ID 倒序排列。前端保序筛选与每页 10 条切片；不显示“按更新时间排序”的假图标。
- 总数取本次成功授权集合筛选后的长度；不能使用上一授权范围、旧查询或未加载数据推算总量。
- 条件变化回第一页；手动刷新保留条件和合法页码，删除导致当前页为空时回到最后一个有效页；零条时显示第 1 页、上下页均禁用。
- Footer 随工作面自然排版，可换行，不固定到窗口或遮挡表格；上下页图标有可访问名称，当前页变化可被辅助技术感知。
- 当前没有服务端 nextCursor/total，不绘制伪游标或总页数。以后接口分页时须同步改造筛选和计数，不保留“当前一页就是全集”的实现。

## 4. “使用模板”抽屉

抽屉使用既有 Ant Drawer 与产品焦点处理，宽度复用现有 drawer token，受视口宽度约束；不为本页新建尺寸 Token。Header 与 Footer 固定，Body 独立滚动。

| 区域 | 内容 |
| --- | --- |
| Header | 标题“使用模板”，关闭控件 |
| 身份摘要 | 模板名称、任务类型；仅一组，不在正文反复显示同一身份 |
| 绑定表单 | 必填“数据源”、必填“执行节点”，按决策顺序单列；节点展示“名称 · Windows/Linux · CPU 架构” |
| 候选反馈 | 就近 loading、无候选、读取失败及“刷新候选”；不弹错误模态框 |
| 当前边界 | 一条紧凑说明“创建后进入向导重新检查”；导出另在需要处说明对象存储凭据须重新绑定 |
| 技术信息 | 默认折叠，只展示当前安全摘要已有的 ID、能力版本、revision、创建时间 |
| Footer | “取消”与唯一 primary“创建草稿”；不出现“执行”“保存并运行” |

### 4.1 状态与操作

- 打开即进入候选读取，数据源和节点都不预选；首次未触碰不报“请选择”错误，也不自动 POST。
- 两份候选原子发布；加载、部分失败、缺少有效选择、模板会话失效时不能创建。未满足原因在字段/候选区可读，不仅依靠 disabled 或 hover。
- 节点下拉展开重读当前候选，保留控件；同 ID 改名保留、ID 消失清空。刷新按钮放在候选区，不重复增加顶部刷新。
- 跨平台路径和参数适用性由创建接口/向导判定；抽屉不展示“兼容通过”“预检查通过”或绿色成功状态。
- 创建在途时按钮显示“创建中…”，锁定选择、关闭和重复提交；不因请求慢切到成功、空态或超时后自动重试。
- 明确拒绝留在抽屉显示 Ant Alert，保留仍有效的选择；缺失候选则先重读。当前绑定不适用时不静默修改模板或自动清除参数。
- 结果未知切为“创建结果待确认”：停止 loading，保留上下文，禁止再次创建；提供前往任务中心“我的草稿”核对与显式关闭。当前已接入同一会话的原请求重试；期间冻结绑定，不开放新键创建。
- 成功后进入对应向导第 1 步；导航失败留存 draftId，改为“草稿已创建”与“打开草稿”，不再发起创建。
- 未创建前取消只清除绑定，无需额外确认；关闭、切换模板、撤权、路由变化和卸载清除会话与提示，迟到响应不打开旧抽屉或导航。

## 5. 改名与删除

改名使用 Ant Modal + Form.Item，标题“改名”，显示当前模板身份，仅一个“模板名称”字段，Footer 为“取消 / 保存”。未修改不请求，成功用 Message；明确失败保留输入，字段问题定位字段；revision 冲突用 Alert 指明先刷新，不提供强制覆盖。

名称按 P3 的 UTF-8 字节上限验证，不把 256 字节实现为 256 个汉字。正常状态不堆叠技术长度说明；过长时提示“模板名称过长，请缩短后重试”。允许重名，不增加唯一性校验接口。

删除复用 OrchDangerConfirm，明确名称、不可恢复及已有草稿/任务不受影响。默认焦点位于取消；处理中阻断重复提交与关闭。成功后更新当前列表并发一次 Message，失败保留对象与安全原因，冲突重读后重新确认。

## 6. 保存入口与跨页承接

“保存为模板”仍属于任务列表/详情的现有受权动作，本页不增加“手工新建”或“导入模板”。命名弹窗只展示来源身份、名称及必要保存边界，不呈现模板参数编辑器。

保存成功留在任务页，通过现有导航进入模板中心；不依赖跨页面全局通知状态。本页使用成功后以对应向导实际草稿承接，不能拿 Message 代替草稿保存事实。

没有来源版本持久关系时，不绘制“关联任务”“使用次数”“最近使用时间”“原始模板版本”或模板变更时间线。

## 7. 页面与弹层反馈矩阵

| 状态 | 呈现与恢复 |
| --- | --- |
| 首次加载 | 保持工作面和列几何，Spin/Skeleton，不闪现可信空态 |
| 首次成功空集合 | Empty“暂无模板”；说明“在成功任务中保存模板后，可在这里复用。”；“前往任务中心”进入 /tasks |
| 名称/类型零匹配 | Empty“没有匹配的模板”；保留条件，提供“清除筛选”；不重复首次引导 |
| 首次读取失败 | 保留标题和工具区，工作面 Alert 与“重试”；不显示 0 条 |
| 刷新失败且有可信摘要 | 保留旧行与条件，Alert 指明读取失败；不把旧摘要当新授权或新兼容结论 |
| 401/403 | 清旧行、弹层与绑定，明确“无法访问模板”；不能伪装为暂无模板 |
| 对象 404/撤权 | 统一“模板当前不可用，请刷新列表”；不推断删除或隐藏对象详情 |
| 无候选/候选读取失败 | 抽屉内就近反馈；无数据源和无节点分开说明当前缺项；读取失败不伪装为无候选 |
| 422 配置/绑定不适用 | 抽屉内安全原因及可行动恢复；不提供越过校验继续 |
| 版本冲突 | 当前弹层 Alert，保留安全输入，提供刷新；不自动保存 |
| 写结果未知 | Alert“保存结果待确认”/“创建结果待确认”，引导核对；不弹成功，不新键盲重试 |
| 成功 | 改名/删除/保存各一次短时 Message；刷新原位；创建草稿用目标向导或“打开草稿”承接 |

现役列表已提供只读 availableActions，分别裁剪使用与管理入口；缺失时只读，未知或重复事实拒绝。不能从目录 READ 推导写权限，多用户模板创建仍未准入；本页不虚构角色授权或失败原因。

## 8. 响应式与可访问性

| 验证视口 | 页面处理 |
| --- | --- |
| 1920×1080 | 完整 Shell 与单一管理工作面；五列、筛选、Footer 均可达 |
| 1440×1024 | 保持完整导航，筛选按需换行，来源长值截断但可读完整值；不压缩名称与操作字号 |
| 1280×720 | 沿用 48px 图标轨；优先将类型与时间并入名称次行，保留名称、来源、使用与更多；必要横滚仅在表格内部 |
| 原生 200% | 控件及文字不缩小；抽屉正文可滚、Footer 可达，筛选/分页可换行，不隐藏错误或主要动作 |

类型/时间从独立列收敛时，不在名称次行重复已经可见的信息。断点依据实际工作面宽度和既有容器机制，实施时通过三档取证确定，不为塞满列而新增全局密度。

页面一个 h1，表格有可访问名称，筛选标签可见。操作按钮/菜单的 accessible name 包含当前模板名；名称、来源 ID 和技术值可通过键盘查看完整内容。Drawer/Modal 打开移入安全焦点、约束 Tab、关闭返回触发控件；失去触发控件时回到表格标题或刷新。不以颜色作为类型、错误或资格的唯一表达。
