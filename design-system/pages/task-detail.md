> 范围：`/tasks/:id`。业务字段、状态与证据规则以 [任务中心设计](../../docs/02-design/task-center-module.md) 与日志、凭据、Agent 契约为 P3 权威。

## 1. 页面结构

`稳定对象头 → 结果/失败/核对横幅 → 五个内容 Tab`

不使用卡片网格或 Wizard 骨架；不设常驻 Inspector 或固定 Footer。Tab 用 Ant Tabs，当前 Tab 写入 `?tab=`，默认 `overview`；切换只换视图，不请求第二份详情事实。

## 2. 对象头

- 标题为派生展示名（规则同[任务中心](task-center.md#3-表格列)），次行依次为可复制任务 ID、类型、环境 Tag、状态 Badge；状态核对中附 warning Tag。
- 存在来源任务时，次行追加“由 {来源任务链接} {派生方式}”；存在派生任务时追加“已派生 N 个任务”，点击展开列表。不单独设来源卡片。
- 右上角：`返回任务中心`（Text，返回时恢复列表 query）、`刷新`（Utility，原位反馈）、至多一个状态主操作、More 菜单。

| 状态 | 主操作 | More |
| --- | --- | --- |
| 等待调度 / 启动中 / 运行中 | `取消任务`（Danger default） | 复制脱敏命令 |
| 取消中 | 无 | 复制脱敏命令 |
| 成功 | `保存为模板` | 基于原配置新建、复制脱敏命令 |
| 失败 | 检查点资格成立时 `从检查点继续`，否则 `基于原配置新建` | 其余派生操作、复制脱敏命令 |
| 已取消 | `基于原配置新建` | 从头重新执行、复制脱敏命令 |

所有操作的出现由服务端资格决定（取消使用 `cancelAvailable`）；确认框、反馈与迟到响应规则同[任务中心第 4 节](task-center.md#4-行操作)。取消确认额外写明当前验证边界：受控取消仅完成合成验证，真实进程终止取证仍待完成；工具名称按任务类型显示 OBDUMPER 或 OBLOADER，不交叉套用验证结论。

## 3. 横幅

横幅位于对象头下、Tab 上，所有 Tab 可见；同一时刻按优先级只显示一条。

| 优先级 | 条件 | 呈现 |
| --- | --- | --- |
| 1 | 计划/实际命令摘要不一致 | error Alert：说明结果不能视为成功，引导核对命令 Tab |
| 2 | 失败 | error Alert：错误分类、错误码、安全错误摘要、发生阶段与时间；操作“查看错误日志”切到日志 Tab 并定位首条错误 |
| 3 | 状态核对中 | warning Alert：最后可信状态与时间；核对完成前不暴露取消 |
| 4 | 取消中 | info Alert：取消请求时间与截止时间，说明不回滚已写入内容 |

成功、等待与运行不设横幅。

## 4. Tab 内容

### 4.1 运行概览

导出与普通导入共用对象头、主工作面、五个 Tab 与三组 Ant Descriptions，窄屏单列。主工作面复用任务中心的现有 Surface、边框、圆角和阴影，类型差异只影响字段语义与服务端操作资格，不另建页面骨架：

- **执行**：状态、当前阶段、执行进度、提交/开始/结束时间、耗时、最后核对时间、执行编号。进度与列表共用安全摘要及 `TaskProgress.vue`：可靠数值用 Ant Progress，仅有阶段显示阶段，无证据显示“—”；失败、取消、缺口或核对中的已有事实标明最后记录。100% 不代替终态与结果核验，Tooltip 展示子任务计数和更新时间，可键盘聚焦及 Escape 关闭。未发生的时间显示“—”。
- **等待原因**：仅等待调度且服务端返回固定原因时，作为执行 Descriptions 中的条件字段显示“平台并发上限暂时阻止新增执行”或“调度策略暂不可用”，附其他领取条件仍须满足的说明。不显示全局计数、上限或其他任务，不增设等待横幅；此字段是当前约束观察，不承诺容量恢复后立即启动。见[调度契约](../../docs/03-technical/scheduling-policy-contract.md)。
- **对象与位置**：数据源快照名称与环境、执行节点快照名称及对象摘要。导出显示输出类型和授权裁剪后的输出位置；普通导入显示目标数据源、导入对象、输入格式与冻结输入位置。导入位置只消费服务端已裁剪的 `input.filePath`，缺失显示“—”，不借用执行输出或推断路径。
- **结果**：导出显示结果结论、文件数与字节数、`dump.ckpt` 是否存在、观察时间及可展开文件清单。对象存储在远端取证接入前显示“远端对象未逐项核验”，文件数和字节数保持“—”。普通导入仅显示完成证据结论、退出码、观察时间及尚无可靠证据的 `load.ckpt`，不显示导出文件指标或清单；明确不代表目标数据库已逐行核验，恢复资格仍未开放。

### 4.2 配置快照

按各自原向导五步分组，每组一个 Descriptions。导出为数据源与执行节点、导出对象与内容、数据格式、输出与性能、预检查与提交；普通导入为选择数据源、导入文件与格式、对象与映射、执行参数、预检查与命令。每项显示生效值与来源标记（用户设置 / 平台派生 / 工具默认 / 未生效）；未生效项默认折叠为一行“N 项未生效”。组末显示工具版本、参数元数据版本、配置指纹、预检查时间与结论、风险确认摘要。秘密只显示“已脱敏”。快照不随数据源、节点、模板或元数据后续变化。

### 4.3 命令

- 计划执行命令：technical evidence surface，等宽、可横滚，`复制脱敏命令`。
- 启动后增加实际启动命令、启动时间、启动目录、工具版本与执行节点；与计划一致时一句说明，不一致时列出平台运行时包装差异来源。
- 不提供显示或复制敏感命令（[DEC-050](../../docs/01-product/decisions.md#dec-050-任务中心重构范围与收窄规则)）。

### 4.4 执行日志

- 工具栏：关键字过滤、来源过滤（标准输出 / 标准错误 / Agent 事件）、跳转首条错误、暂停自动滚动 / 跳到最新、实时连接状态、刷新。过滤只作用于当前任务已加载日志。
- 日志区为 technical evidence surface，每行时间、来源、内容；错误行有非颜色标识。完整性缺口在区内用 warning Alert 说明，不清空已加载内容。
- 不提供日志下载；跨任务检索链接到日志中心并带入任务 ID。

### 4.5 操作记录

按时间倒序的轻量时间线：时间、操作人（用户 / Agent / 系统）、动作、结果、安全摘要。覆盖提交、领取、启动、取消请求与结果、派生、保存模板等任务级事件；只显示任务权限范围内的记录，敏感值脱敏，不替代平台审计。游标分页“加载更多”；空时说明“暂无操作记录”。

## 5. 刷新与生命周期

- 非终态时每 2 秒核对执行事实与增量日志；终态后停止轮询，实时流关闭。页面不可见时暂停。快照与命令成功读取后不再重复请求。
- 路由 ID 变化、授权失效、卸载时清除事实、日志、操作输入与提示；沿用 [任务维护索引](../../web/src/workbench/tasks/README.md) 的会话与连接代隔离。
- 状态文案与列表共用同一映射，覆盖八种状态；不得出现列表与详情对同一状态说法不同。

## 6. 加载、空态与错误

- 首次加载：对象头与 Tab 骨架保留几何，不显示假数据。
- 任务不存在或无权：同一受限状态，不区分两者，不泄露任务是否存在。
- 单区读取失败：只在该 Tab 内 error Alert + 重试，其余 Tab 不受影响。

## 7. 无障碍

单一 `h1` 为展示名；Tabs 支持方向键、Home/End；横幅使用 Alert 语义；“查看错误日志”切 Tab 后焦点移到首条错误行；复制、刷新、More 等图标或文字按钮均有可访问名称；日志新行不逐条朗读。

### 当前证据边界

- 历史快照没有逐字段的用户/派生/默认来源、未生效标记、完整预检查时间或风险摘要。来源为 `UNKNOWN`，显示“来源未记录”；不把空值猜成工具默认，不虚构未生效项数量。长值用 Ant Typography 折叠三行，可展开。
- 实际启动只保存摘要核对、开始/结束时间和固定进程事实；完整实际命令、启动目录未保存，命令 Tab 明示缺口，不用计划命令补造。
- 错误定位只识别已脱敏日志中的明确 `[ERROR]`，stderr 不自动视为错误；无错误行时聚焦日志区。定位会清除本地过滤。
- 对象存储显示“远端对象未逐项核验”，文件数、字节数及清单为空展示，不把进程成功外推为逐对象核验。
- 操作记录只投影任务审计白名单与执行事件元信息，被拒绝事件标记 `DENIED`；不下发原始差异/载荷。派生数量与链接只含授权范围，展开最近 100 个。
- 以上为证据可用性与 P1 的收缩实现，不变更 P0，不提升 EX-V1 或 G3/G4 门禁。
- 2026-10-19 修正普通导入沿用导出类型、输出字段、检查点及最小快照分组的 implementation debt；统一主工作面的现有样式，保留两类任务的业务语义。布局与验证记录见[任务中心收尾证据](../../docs/03-technical/evidence/task-center-phases2-3-2026-10-14.md#2026-10-19-导出与普通导入详情一致性修正)。

## 2026-10-19 操作闭环与刷新验收

普通导入的保存模板、基于原配置新建及从头重跑使用独立后端资格和正确类型路由，和导出共用对象头及确认呈现；load.ckpt 仍不开放。手动刷新可加入现有单链读取，在途按钮 loading、disabled 与 aria-busy 一致，成功显示“已刷新”；自动读取不发布手动成功，任务切换或授权失效清除反馈。五个 Tab 与执行节点详情共用无状态键盘导航，方向键及 Home/End 同步焦点、选中项与 URL，不接管面板输入。
