## 1. 页面结构

单张工作面，沿用数据源标准页的外壳、字体、控件、菜单与弹层，不新增 Token、Inspector 或固定 Footer：

`工作区标题与上下文 → 列表标题及刷新/新建 → 基础筛选（可展开） → 活动筛选摘要 → 表格与反馈 → 左侧页数/右下角分页`

- 工作区标题 `任务中心`，一句说明：“定位授权范围内的任务并进入详情排障，列表不展开命令、完整参数或日志。”不设 KPI 条。
- 列表标题右侧：最后成功更新时间、`刷新`（Utility）、`新建任务`（唯一 Primary，Ant Dropdown）。
- `新建任务` 菜单固定三项：导出、普通导入、旁路导入。未经任务地图准入的类型显示为 disabled 并在菜单项内写明“尚未开放”，不跳转占位向导。

## 2. 筛选

全部筛选、排序与分页由服务端在当前授权范围内执行；候选值只来自用户有权任务中出现的历史快照值，不通过候选值或计数泄露无权任务。

| 区域 | 控件（顺序） | 规则 |
| --- | --- | --- |
| 基础 | 关键字、任务类型、任务状态、创建时间 | 关键字匹配任务 ID 与派生展示名；类型多选；状态多选，候选为七种已提交状态（草稿进入列表前不显示该项）；创建时间为日期范围，按浏览器本地时区展示并以 RFC 3339 提交 |
| 展开 | 数据源、环境、执行节点、创建人、开始时间 | 默认收起；有展开项生效时自动展开。数据源/节点按快照名称显示，已删除对象保留历史名称；环境取数据源快照；创建人只在有可信全局范围时可选，否则固定为本人；开始时间对未开始任务不命中 |
| 动作 | `展开筛选` / `收起筛选`、`清除筛选` | 条件即时生效（输入防抖），不设单独“查询”按钮；清除只在有活动条件时显示，焦点回到关键字 |

- 不提供标签筛选（[DEC-050](../../docs/01-product/decisions.md#dec-050-任务中心重构范围与收窄规则) 推迟）、保存视图、自定义列或批量选择。
- 活动筛选摘要位于筛选区下方，以可关闭 Ant Tag 列出所有生效条件，包括从执行节点页带入的 `nodeId` 与 `scope`；无条件时不占位。
- 筛选、页码与每页条数写入路由 query。从详情返回、浏览器后退或刷新页面时恢复原条件、页码与条数；条件变化清空游标栈回到首页。

## 3. 表格列

列固定，不提供自定义列。名称/身份类左对齐，状态与时长类居中。

| 列 | 内容 | 规则 |
| --- | --- | --- |
| 任务 | 主文本为派生展示名（链接到详情）；次行为可复制任务 ID 与环境 Tag | 展示名由快照对象摘要派生：单表 `库.表`，多对象 `库（N 个对象）`，结果集 `库 · 查询结果集`；无摘要时为 `导出任务`。环境沿用数据源页 Tag 配色，生产保持明确识别 |
| 类型 | 导出 / 普通导入 / 旁路导入 | 稳定文案，不使用合并的“导入” |
| 数据源 / 对象 | 数据源快照名称；次行对象摘要 | 超长截断 + Tooltip；数据源已删除时名称后附“（已删除）” |
| 状态 / 阶段 | Badge + 状态文案；次行当前阶段 | 状态核对中为附加 warning Tag，不替换状态；取消已请求时附“取消请求中”；无可靠阶段时次行不显示，不写“暂无可靠阶段” |
| 进度 | 可靠百分比用 Ant Progress；仅有阶段时写阶段；都没有时显示破折号 | 破折号有 Tooltip“工具未提供可靠进度”；不显示 ETA |
| 执行节点 | 节点快照名称 | 未分配显示“待分配”；节点已删除保留历史名称 |
| 创建人 | 创建人显示名 | 当前用户附“（我）” |
| 时间 | 已开始：开始时间 + 耗时；未开始：提交时间 | 运行中耗时随刷新更新，终态固定；时间缺失显示“—”，不显示“尚未发生” |
| 操作 | 一个主操作文字链接 + 三点 More 菜单 | 见第 4 节 |

容器宽度不超过 1120px 时，“类型”并入任务次行，“创建人”并入时间次行；不超过 900px 时表格内部横滚。状态、操作列始终可见。

## 4. 行操作

可用操作只来自服务端逐行返回的资格集合，前端不按状态自行推断，也不在列表预取命令文本。

| 状态 | 主操作 | More 菜单（出现条件均由服务端资格决定） |
| --- | --- | --- |
| 等待调度 / 启动中 / 运行中 | 查看详情 | 查看日志、取消任务 |
| 取消中 | 查看详情 | 查看日志 |
| 成功 | 查看详情 | 复制脱敏命令、基于原配置新建、保存为模板 |
| 失败 | 查看错误 | 查看日志、复制脱敏命令、基于原配置新建、从头重新执行、从检查点继续 |
| 已取消 | 查看详情 | 查看日志、基于原配置新建、从头重新执行 |

- `查看错误` / `查看日志` 打开详情对应 Tab（`?tab=overview` 定位失败摘要，`?tab=logs`）。
- `取消任务` 使用 `OrchDangerConfirm`：列出任务 ID、展示名、类型、当前状态、执行节点；写明“取消只终止工具进程，不回滚已写入的文件或数据”。确认后行内显示处理中，结果以 Message 确认“已提交取消请求”，状态以服务端投影为准。
- `从头重新执行` 与 `从检查点继续` 使用普通确认 Dialog，写明“生成新任务 ID、不可修改参数、提交前重新复验”；成功后跳转新草稿或新任务。`保存为模板` 打开命名 Dialog。`复制脱敏命令` 点击时读取一次并复制，结果用 Message。
- 写操作期间该行 More 菜单禁用；迟到响应不得跳转或发布反馈。

## 5. 刷新与反馈

- 当前页存在等待调度、启动中、运行中或取消中任务时，每 10 秒自动读取当前页；全部为终态时停止。页面不可见时暂停，恢复可见立即读取一次。不暴露轮询间隔设置。
- 慢请求不重叠；写事务期间跳过；401/403 停止周期读取。自动刷新不弹 Message。
- 手动刷新沿用执行节点页原位反馈：按钮 loading“刷新中”，完成后“已刷新”保持到下次读取；失败保留旧行与上次成功时间，在表格上方显示 error Alert + 重试。

## 6. 空态与错误

| 情境 | 呈现 |
| --- | --- |
| 首次使用无任务 | 产品空态：说明当前授权范围内没有任务，提供“新建导出任务” |
| 筛选无结果 | 保留条件，说明没有符合条件的任务，提供“清除筛选” |
| 无权限 | 受限状态，不显示行数、候选值或新建入口 |
| 首次加载失败 | 表格区替换为 error Alert + 重试 |
| 刷新失败且有可信行 | 保留行，error Alert + 重试 + 上次成功时间 |

## 7. 分页

右下角：`每页 10/20/50 条 → 上一页 → 第 N 页 → 下一页`，上下页为带可访问名称的图标按钮，当前页经 live region 宣告；左侧 `共 M 页`。M 来自服务端同一授权筛选范围与当前每页条数，不显示全局任务总数，不提供任意跳页。

## 8. 无障碍

单一 `h1`；表格 caption 描述当前范围与生效条件；筛选控件均有可见标签；行 More 菜单的可访问名称含任务展示名；Dropdown 支持键盘进入、方向键、Escape 与焦点归还；状态同时用文字、形状与颜色表达。

## 10. 草稿入口与日期整改（2026-10-14）

- 用户授权“按顺序完成日志清理、任务详情、草稿列表”；同一 `/tasks` 工作区采用 Ant Tabs：`已提交任务 / 我的草稿`，同一时刻一个管理工作面，草稿为 `?tab=drafts`。所有权范围和计数分开，全局任务读取资格不扩大到草稿配置。
- 草稿仅当前主体可见，服务端排除已提交和已删除对象；关键字、条数、游标和页数均在该范围生效。行内只含对象摘要、ID、修订、来源、数据源/节点标识和时间，不读完整配置、路径、命令或凭据引用。
- `继续编辑` 进入现有向导步骤 1；`提交执行` 进入步骤 5 重新预检查，不由列表启动工具。从头执行派生草稿保持步骤 5 及原参数锁定语义。
- 删除用 Ant Modal 产品确认。领域短事务复验所有权、版本、提交和活动租约后标记删除、失效预检查、登记审计和幂等回执；历史引用保留。
- 时间用 Ant RangePicker：今天、昨天、最近 7 天、最近 30 天、本月及部分区间；注册 `zh-cn`，日历月份、星期及预设中文，输入为 `YYYY-MM-DD`。错误归 Form.Item，模板名称也沿用字段校验。
- 入口：[TaskDraftList.vue](../../web/src/workbench/tasks/TaskDraftList.vue)、[useTaskDraftList.ts](../../web/src/workbench/tasks/useTaskDraftList.ts)、共用确认 [TaskActionDialogs.vue](../../web/src/workbench/tasks/TaskActionDialogs.vue)。未修改 Product Shell、Archetype 或全局 Token。
