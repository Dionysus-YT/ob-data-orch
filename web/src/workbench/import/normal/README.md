## 范围与事实边界

五步为选择数据源、导入文件与格式、对象与映射、执行参数、预检查与命令。前四步的“下一步”只校验本页输入，不代表文件发现或执行资格。2026-10-17 按用户要求移除第二步“发现输入文件”按钮及独立发现提示；文件核对统一由第五步完整预检查执行，既有文件发现协议保留。五步共用一份表单；用户继续实现后接入服务端草稿，保存当前活动格式与参数，URL 的 `draft` 可刷新恢复。非活动格式仍只在本页暂存，不写入浏览器存储或服务端快照。

引用读取继续使用既有两个授权列表，不使用导出候选资格。草稿、命令和检查使用独立 `/normal-import-drafts` 与 `/normal-import-prechecks`，唯一命令生成器加载普通导入自己的 72 条定义；四项受管 sys/字符集/会话说明不作为任务覆盖。文件发现只签发文件用途租约，不能解析数据库密码或替代六项完整预检查。连接、写权限与映射已接入独立固定只读 JDBC v10，装配受本机显式开关、固定运行时及完整租约约束；逐表权限和细化原因独立于导出，未知事实及独立执行门禁持续阻断提交。冻结提交、独立普通导入领取、执行与结果已在 Windows 执行切片接通，旧导出 Worker 不能领取普通导入；`load.ckpt` 继续仍未接入。详细边界见[技术契约](../../../../../docs/03-technical/normal-import-contract.md)。

## 维护规则

- 新字段进入唯一表单与相应规则/步骤/摘要，并同步独立 DTO、服务端规则与命令映射。活动投影同时用于校验和证据失效，不维护第二份监听字段名单；参数目录冻结后须发布新版本。
- 名称不属于预检查必填条件。提交时才在弹窗填写或留空，名称独立冻结；不能把弹窗输入写回唯一配置使检查失效。第五步配置就绪后自动生成完整脱敏命令并检查，保留复制和显式重检，不恢复手动生成按钮或无限自动重试。
- 与旁路模块保持解耦：不引用旁路的状态、参数、规则或资格，不创建共享导入业务模型。`WizardFrame` 接收步骤标题、本地完整度及已配置步骤，不依赖业务模块；普通导入最后一步无真实预检事实时完整度保持 0%，旁路自己的六步不受影响。
- 只有 CSV、CUT、SQL 三个格式命名空间，只投影当前格式；越界格式或 MIX 输入被校验阻断，不进入活动解析或映射。gzip/snappy 清除等级，控制文件/自动映射/显式列名单严格单选；当前仅 CSV 可用自动映射。默认压缩算法继承 zstd，不自动写成显式覆盖。
- 参数设计沿用导出展示标准，业务含义独立。字符集和会话配置归受管连接上下文，不进入任务表单或活动投影；文件编码仍可配置。第四步错误处理常用，性能/JVM/NLS/数据行为高级；数据写入类只对含数据内容适用，DDL 保留线程和 JVM。显式包含列和排除列按平台规则择一，冲突不投影名单并阻断，原输入保留供修正。
- 页面只负责错误定位与焦点：继续配置失败时，按唯一校验结果定位首个错误字段；高级区内的错误自动展开以供修正，不复制校验规则。
- 数据源、内容或范围变化需要删除既有对象或风险配置时先确认，取消不清值。内容清值与格式暂存是不同规则，不能靠步骤卸载清理业务输入。
- 本地“已阅读影响”只表达阅读状态，不授予执行权限，不生成 `--yes`。活动配置、源/凭据修订、兼容模式、环境或节点事实变化后立即失效，A → B → A 不恢复旧确认。
- 引用读取只由 references 管理。新会话、较新请求与卸载使旧成功、错误和 finally 失效；页面 HTTP AbortSignal 只取消等待，不声称撤销服务端操作。草稿读写与检查分别由 draft / review 管理，不把引用列表成功当作运行资格。
- 离开页面或改变 draft 业务会话前保护未保存输入，步骤 query 变化保留输入。有效 draft 从服务端恢复并按修订更新；读取失败或无权时隐藏旧表单，禁止沿用旧草稿保存或继续。
