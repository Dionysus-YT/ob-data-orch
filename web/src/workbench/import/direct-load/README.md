# 旁路导入维护索引

旁路按 2026-10-20 用户采纳的 DEC-056 使用独立五步 Task Builder：数据源与连接 → 导入目标 → 文件与格式 → 执行参数 → 预检查与提交。与导出、普通导入共用顶部水平 Steps、Ant 字段、单层留白的分组摘要 Drawer、固定底栏及 Message/Alert/Form.Item；不修改 Shell 或 Token，不引用普通导入的业务状态或资格。

## 当前能力与边界

连接场景在选择器与任务摘要统一显示为“通过 ODP 连接”“直连 OBServer”，由 `directLoadScenarioLabels` 唯一提供。DEC-058 由登记数据源的 ODP / OBSERVER_DIRECT 自动带出场景，`directLoadScenarioForSource` 是唯一映射；恢复历史配置不静默改写，不匹配时只提供显式应用当前方式。两种本地路径均需租户，直连不携带集群。

已接独立服务端草稿、修订、刷新恢复、只读脱敏命令、文件发现协议、九项完整预检查、强制最终风险确认和统一任务中心草稿导航。配置为 `direct-load-v1`；参数为 `obloader-4.3.5-direct-v1`，能力为 `direct-load-local-v1`。浏览器只通过 `api/directLoad.ts` 请求；CSRF、幂等、If-Match 与 AbortSignal 沿用 `browser.ts` 注入。

执行默认关闭。服务端显式启用独立执行策略后，仍须草稿、命令和完整预检查同时允许执行，并包含当前节点三键安全配置指纹；SQL/RPC、版本、写权限、目标表结构与节点配置缺少专用 Probe 证据时明确显示无法确认。命令、列表成功或本地字段完整不授予执行资格。不提供 checkpoint/retry、旁路取消或旁路模板。replace-data 可在第四步记录替换意图；第五步必须重新取得真实表空状态/索引/LOB 证据，结构不允许或无法确认时阻断提交。配置意图不授予写入资格，不能绕过唯一索引风险确认。DEC-057 将活动范围限定为本地私有 ODP / OBServer 和 CSV；其余未确认解析、格式、压缩、文件过滤、映射、远程输入、JVM 等参数仅在本地 102 项目录说明状态，不创建可执行字段。官方 103 项研究目录及摘要保留冻结；历史读取不静默转换旧场景或格式。

**检查时序：** 目标数据库和唯一表在第二步、节点/文件/格式在第三步确定。前四步仅校验当前输入并明确事实待检查，第五步自动保存、预览和完整检查；入口阅读确认不能替代实际检查。DEC-056 已收敛原六步前置检查的时序差异，分段真实探针仍须按准入接入，不在本轮增设。

首步有效继续时集中确认适用边界，明确继续才写入既有四项阅读确认；取消不记录，同一已确认草稿往返不重复弹。弹窗绑定当前配置与引用，切换、变化及卸载后旧确认失效。RPC 场景默认值为私有 ODP 2885、OBServer 2882，均可编辑；切换只替换空值或原场景默认值，恢复不改写草稿。来源仍为用户提交配置 `MANUAL`，不伪装为已检查。固定 ODP 是建议，F5/VIP 须同一源地址提供 SQL/RPC 转发并另行验证，不据名称硬禁用。

## 唯一能力所有者

| 入口 | 职责 |
| --- | --- |
| `views/DirectLoadWizardView.vue` | 路由与 AbortController、Ant 装配、离开/卸载/退出登录保护、错误定位 |
| `directLoadForm.ts` | 唯一表单、场景切换的默认 RPC 填写、当前格式活动投影、配置语义签名及恢复；无浏览器持久存储 |
| `directLoadRules.ts` | 五步标题、旁路独立数据源资格、登记方式到场景的唯一映射、本地场景/格式/端口默认值、目录适用投影、单表与路径语法、本地校验 |
| `directLoadPrecheckPresentation.ts` | 固定九项预检行、总览严重性、有效通过进度和当前证据的修正入口；探针未配置只提示管理员处理，业务失败才返回输入，失效/等待/未知原因不沿用旧入口；不授予执行资格 |
| `useDirectLoadReferences.ts` | 授权数据源/节点、名称/环境筛选及完整参数目录，独立请求代、失败和卸载清理 |
| `useDirectLoadDraft.ts` | 草稿读取/保存、修订、dirty、保存期间编辑与路由会话 |
| `useDirectLoadReview.ts` | 预览、检查轮询/过期、复制、独立名称与最终风险确认、提交防重 |
| `useDirectLoadWizard.ts` | 能力组合、五步导航、入口阅读与来源清值确认及每配置一次自动准备；`goToNode` 将查看意图导航到当前节点，未选定时进入节点列表，沿用路由离开保护 |
| `directLoadStepModels.ts` | 引用组合状态的类型端口；步骤没有 API 客户端 |
| `steps/DirectLoadSourceStep.vue` | 首步授权来源列表和连接输入，仅消费已有模型；三模块共用 `wizard-source-*` 布局 |
| `steps/` 其余组件 | 目标/文件/执行三步输入、最终检查和摘要，仅消费唯一模型与意图 |
| `components/DirectLoadParameterCatalog.vue` | 本地 102 项目录和 3 个节点键的展示、搜索和定位，复用原生焦点栈 |
| `api/directLoad.ts` | 严格配置与响应白名单、固定九项证据及唯一目标表文件清单校验 |

配置与数据源/凭据/节点修订变化立即撤销旧命令、检查与确认；A → B → A 不恢复旧资格。请求成功、失败、finally、复制及写入后导航均校验当前代。卸载停止轮询和计时器、唤醒等待并取消浏览器 HTTP，不能据此声称撤销了服务端事务。任务名称只在最终确认中短时持有，必填且不进入配置指纹。一次确认的提交意图由 review 持有原名称、草稿/预检绑定和幂等键；响应不确定时锁定名称、停止新预检/步骤切换并优先读取同一预检的 submittedTaskId，重试只发原请求。原键可找回已提交结果，换键由服务端拒绝；明确拒绝后才撤销证明并开放重检。配置/路由代与卸载继续隔离迟到核对和导航，已接受任务的导航失败不重新提交。

步骤栏前四步只表示当前有效输入完整度，目录跳步不补齐前序配置；第五步仅统计九项有效预检通过项，过期与失效清零。失败/无法确认总览为 error，过期为 warning，等待为 info；独立执行门禁另行说明。环境、测试时间和节点平台复用 sources/nodes 展示函数，不改变资格判断。

任务派生沿用 tasks 能力的唯一写事务与路由：`REBUILD_FROM_CONFIG` 从第 1 步编辑；`RERUN_FROM_SCRATCH` 强制只读第 5 步，重新获取当前事实与最终确认。旧最终步 `step=6` 兼容进入第五步。草稿来源及 `parametersLocked` 必须一致，旧响应缺少锁字段时仍按 RERUN 保守锁定。相同配置 PATCH 仅重绑当前引用，值变化、响应来源或锁定漂移均拒绝；不引入旁路模板、检查点或普通导入阶段解析器。

## 验证入口

`api/directLoad.test.ts` 验证冻结目录与历史读取、配置污染、九项检查证据、秘密拒绝与最终提交字段；`directLoadLifecycle.test.ts` 验证本地目录投影、默认端口/自定义值/恢复、路径/单表/场景、未确认格式阻断、保存并发、迟到及门禁/确认/防重；`tests/direct-load.spec.ts` 使用隔离 Vite 与合成 API 覆盖五步、入口确认/取消/不重复弹、来源筛选、RPC 预填、自定义值保留、旧最终步链接、保存刷新、离开保护、本地 102 项目录、历史场景/格式门控、无权、三档视口和原生 200% 缩放，并验证最终名称与风险确认仍不可绕过。实际检查结果见[开发证据](../../../../../docs/03-technical/evidence/direct-load-development-2026-10-19.md)；合成通过不表示真实工具或数据库可用。

三模块共用数据源选择的既有几何和 Ant 呈现，样式由 `platform/archetypes.css` 持有，无状态或资格共享。冻结快照仍保留六个既有证据分组，不与页面五步一一对应。模板继续只接纳导出与普通导入，不降低失败关闭断言。
